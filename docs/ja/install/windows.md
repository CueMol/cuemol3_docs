# Windows へのインストール

対象: **Windows (x64)**。配布物は `CueMol3-<version>-Windows-x64-Setup.exe` (NSIS インストーラー) です
(入手方法は [ダウンロード](index.md#ダウンロード) を参照)。

!!! warning "配布物は未署名です"
    現在の `.exe` は Authenticode によるコード署名を行っていません。
    実行時に SmartScreen の警告が表示されます。下記の手順で回避してください。

!!! warning "AVX2 対応の CPU が必要です"
    x86-64 版は AVX2 命令を使ってビルドされています。Intel Haswell / AMD Zen 以降
    (おおむね 2013 年以降) の CPU が必要で、これより古い CPU では**分子表面を生成したときに
    異常終了します** (→ [インストール](index.md#配布物一覧))。

## 手順

`CueMol3-<version>-Windows-x64-Setup.exe` はウィザード型の NSIS インストーラーです。実行すると次のように進みます。

1. ようこそ画面
2. インストール先の選択
3. インストールの実行 (全ユーザー向けに `C:\Program Files\CueMol3\` へインストールするため、
   UAC の昇格確認が表示されます)
4. 完了

インストール後、スタートメニューとデスクトップにショートカットが作成され、
「アプリと機能 / プログラムの追加と削除」に登録されます。あわせて、CueMol3 が扱える
ファイル形式がエクスプローラーの**「プログラムから開く」**に登録されます
(既定のアプリケーションは変更されません → [インストール](index.md#ファイルの関連付け))。
ファイルをダブルクリックしたり、コマンドラインで渡したりして開くこともできます。

## 初回実行時の警告を回避する

未署名の `.exe` を実行すると、**「Windows によって PC が保護されました」** (発行元不明) と表示されます。

1. ダイアログの **「詳細情報」** をクリックする
2. 表示された **「実行」** ボタンをクリックする

## 外部ツールの同梱について

CI がビルドした Windows 配布物には ffmpeg / APBS・PDB2PQR / POV-Ray が同梱されます。
同梱されていないビルドでは Settings でパスを指定してください。
レイトレーシングに使う Umbreon はライブラリに組み込まれているため、同梱の対象外です。

→ [外部ツールの設定](external-tools.md)

## アンインストール

「設定 &gt; アプリ &gt; アプリと機能」(または「プログラムの追加と削除」) から
**CueMol3** を選んでアンインストールしてください。
