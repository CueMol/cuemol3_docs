# Windows へのインストール

対象: **Windows (x64)**。配布物は `CueMol3-<version>-x64.exe` (NSIS インストーラー) です。

!!! warning "配布物は未署名です"
    現在の `.exe` はコード署名を行っていません。実行時に SmartScreen の警告が表示されます。
    下記の手順で回避してください。

## 手順

`CueMol3-<version>-x64.exe` はウィザード型の NSIS インストーラーです。実行すると次のように進みます。

1. ようこそ画面
2. インストール先の選択
3. インストールの実行 (全ユーザー向けに `C:\Program Files\CueMol3\` へインストールするため、
   UAC の昇格確認が表示されます)
4. 完了

インストール後、スタートメニューとデスクトップにショートカットが作成され、
「アプリと機能 / プログラムの追加と削除」に登録されます。

## 初回実行時の警告を回避する

未署名の `.exe` を実行すると、**「Windows によって PC が保護されました」** (発行元不明) と表示されます。

1. ダイアログの **「詳細情報」** をクリックする
2. 表示された **「実行」** ボタンをクリックする

<!-- TODO(screenshot): SmartScreen の警告ダイアログと「詳細情報」を開いた状態 -->

!!! info "将来の予定"
    コード署名 (EV/OV 証明書または Azure Trusted Signing) を導入すればこの警告は解消されます。
    導入は今後の作業として計画されています。

## 外部ツールの同梱について

CI がビルドした Windows 配布物には POV-Ray / ffmpeg / APBS・PDB2PQR が同梱されます。
同梱されていないビルドでは Settings でパスを指定してください。

→ [外部ツールの設定](external-tools.md)

## アンインストール

「設定 &gt; アプリ &gt; アプリと機能」(または「プログラムの追加と削除」) から
**CueMol3** を選んでアンインストールしてください。
