# macOS へのインストール

対象: **macOS / Apple Silicon (arm64)**。配布物は `CueMol3-<version>-macOS-arm64-Installer.dmg` です
(入手方法は [ダウンロード](index.md#ダウンロード) を参照)。

!!! warning "アドホック署名のみで、配布元は証明されていません"
    アプリには **アドホック署名** (`codesign --sign -`) が付いています。これは Apple Silicon で
    アプリを起動可能にするために必要なもので、**配布元を証明するものではありません**。
    Developer ID 署名と notarization は行っていないため、Web からダウンロードした dmg には
    quarantine 属性が付き、そのままでは起動できません。下記の手順で回避してください。

## 手順

1. `CueMol3-<version>-macOS-arm64-Installer.dmg` をダブルクリックしてマウントする
2. 表示された `CueMol3.app` を `Applications` フォルダにドラッグしてコピーする
3. 初回起動は次のいずれかの方法で行う (下記参照)

## 初回起動時の警告を回避する

初回起動時に「"CueMol3" は開いていません」という主旨のダイアログが出て、
**「ゴミ箱に入れる」と「完了」しか選べません**。次のどちらかの方法で起動できます。

!!! warning "右クリックからの「開く」は使えません"
    macOS 14 以前にあった、アプリを右クリック (++ctrl++ + クリック) して
    **「開く」**を選ぶ回避方法は、**macOS 15 (Sequoia) 以降では廃止されました**。
    右クリックしても「ゴミ箱に入れる」しか選べません。
    macOS 26 (Tahoe) も同様です。

### 方法 A: システム設定から許可する (推奨)

1. `/Applications/CueMol3.app` をダブルクリックして**一度起動を試みる**
   (ダイアログが出たら **「完了」** を押して閉じる。**「ゴミ箱に入れる」は押さない**)
2. アップルメニュー &gt; **システム設定** を開く
3. **「プライバシーとセキュリティ」** を選び、**「セキュリティ」**の項目まで下にスクロールする
4. 「"CueMol3" は…ブロックされました」という行の横の **「このまま開く」** を押す
5. Touch ID またはログインパスワードで認証する
6. 確認のダイアログが出たら、もう一度 **「このまま開く」** を押す

手順 1 を行っていないと、手順 4 のボタンは現れません。ボタンが見当たらない場合は、
起動を試みるところからやり直してください。

一度この方法で起動すれば、次回以降は通常どおりダブルクリックで起動できます。

### 方法 B: quarantine 属性を除去する

ターミナルで次を実行します。実行後は、そのままダブルクリックで起動できます。

```sh
xattr -dr com.apple.quarantine /Applications/CueMol3.app
```

「"CueMol3" は壊れているため開けません」と表示されて方法 A のボタンが出ない場合も、
この方法で起動できます。

!!! note
    ローカルで自分でビルドした dmg には quarantine 属性が付かないため、この警告は出ません。

## 外部ツールの同梱について

CI がビルドした macOS 配布物には ffmpeg / APBS・PDB2PQR / POV-Ray が同梱されます。
手元でパッケージングした場合など、同梱されていないビルドでは Settings でパスを指定してください。
レイトレーシングに使う Umbreon はライブラリに組み込まれているため、同梱の対象外です。

→ [外部ツールの設定](external-tools.md)

## アンインストール

`/Applications/CueMol3.app` をゴミ箱に移動してください。
