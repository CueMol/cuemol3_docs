# 更新履歴

リリースごとの主な変更点です。お使いのバージョンは **Help &gt; About CueMol3** で確認できます。

!!! info "詳細は GitHub のリリースノートにあります"
    このページは、ふだん使ううえで知っておくとよい点だけをまとめたものです。
    修正の一件一件や内部の変更まで含む完全な記録は
    [GitHub の Releases](https://github.com/CueMol/cuemol2/releases) にあります。

    CueMol3 と CueMol2 は同じリリースで一緒に配布されるため、リリースノートには
    CueMol2 (UXP 版) の変更も含まれています。

このページには直近の 5 リリースを載せています。それより前は
[過去のリリース](releases-archive.md)を参照してください。

## 2.3.15.530 (2026-09-18)

### プラグイン

- **機能ごとに有効・無効を切り替えられるようになりました。** **Settings &gt; Plugins &gt;
  Installed** に一覧が並び、スイッチで切り替えます。切り替えた結果は自分で触ったものだけが
  記録されるので、一度も触っていない機能はそのつど既定に従います
  → [プラグイン](reference/plugins/index.md)
- **文章で指示するとシーンを組み立てる AI Agent パネルが追加されました** (既定は無効)。
  「1CRN を読み込んで cartoon で表示して」のように書くと、モデルが GUI と同じ操作を順に
  呼び出します。1 回の指示は 1 回の Undo で戻せます。OpenAI と Anthropic のどちらでも動き、
  API キーは OS の安全な保管領域に保存されます
  → [AI Agent](reference/plugins/ai-agent.md)
- **PyMOL 互換のコマンドライン PyM Console が追加されました** (既定は無効)。
  `fetch 1crn` や `bg_color white` のような、PyMOL で使っていたコマンドをそのまま打てます。
  コマンドの解析と ++tab++ 補完は PyMOL の実装を移植したものです
  → [PyM Console](reference/plugins/pymconsole.md)
- **MD トラジェクトリの GUI が既定で無効になりました。** **File &gt; Open MD
  Trajectory...** と下部パネルの **Trajectory** タブは **MD Tools** プラグインの
  一部になり、Settings &gt; Plugins &gt; Installed で有効にしないと現れません。
  すでにシーンに入っている Trajectory は今までどおり描画されます
  → [プラグイン](reference/plugins/index.md)

### 分子表面

- **dsurf2 が dsurface に統合され、メッシュの作り方を選べるようになりました。**
  2 つは同じプロパティを持つ同じ Renderer で、違いはメッシュの作り方だけだったのに、
  New Renderer の一覧は両方を並べるだけでどちらを選べばよいかを示していませんでした。
  dsurface の **Algorithm** で **Distance field** (既定) / **MeshMS (analytic SES)** /
  **EDTSurf (voxel)** から選びます
  → [dsurface](reference/renderers/dsurface.md#algorithm)
- **解析的に溶媒排除表面を作る MeshMS が選べるようになりました。** 格子をたどらずに
  メッシュを作るため、細かい設定では距離場より大幅に高速です。溶媒排除表面専用なので、
  それ以外の表面では距離場に切り替わり、理由が Output パネルに出ます
- **Detail の意味が 3 つのアルゴリズムで揃いました。** 既定の 6 ではどれを選んでも
  ほぼ同じ細かさになります。選べる段に **24** が加わりました (16 から 32 への跳びが
  大きすぎたためです) → [dsurface](reference/renderers/dsurface.md#surface)
- **分子表面の生成ダイアログの Point density の既定が 2 /A になりました** (従来は 1)。
  1 /A は粗すぎて、そのまま使うことがほとんどなかったためです

### カメラ

- **カメラがシーンツリーから独立し、専用のパネルになりました。** アクティビティバーに
  **View** が加わり、その中の **Camera** パネルに一覧が表示されます。カメラは視点の
  一覧であって Object の階層ではないためです。**View** パネル (視点の数値操作) も
  Explorer からこちらへ移り、Explorer には Scene と Color が残ります
  → [サイドパネル](ui/side-panels.md#camera-パネル)
- **カメラの主な操作がツールバーのボタンになりました。** 新規作成・保存・適用
  (表示フラグ付きを含む)・削除の 6 つです。従来は右クリックメニューからしか行えませんでした
  → [カメラ](reference/camera.md#カメラの操作)
- **カメラの順序を行のドラッグで変えられるようになり、シーンファイルに保存されます。**
  `__current` は先頭に固定されます
- カメラの右クリックメニューから、選んでも何も起きなかった **Properties** が消えました

### 3D ビュー

- **分子表面 (dsurface) をクリック・ホバーできるようになりました。** 表面はこれまで
  当たり判定の対象に入っておらず、クリックしても何も起きませんでした。描画モードが
  **Fill** のときが対象で、網目と点は対象外です。矩形選択・投げ縄選択は従来どおり
  表面を対象にしません。**Tools &gt; Mol surface generation... で生成した分子表面
  (molsurf) は対象になりません** — 分子 (MolCoord) とは別の Object (MolSurfObj) を
  描いているためです → [ピッキングとホバー表示](ui/mouse-input.md#ピッキングとホバー表示)
- **暗い背景でホバーの強調表示が見えるようになりました。** 縁取りの外側が常に暗い色
  だったため、黒い背景に simple のような線の Renderer を出していると何も見えませんでした。
  背景の明るさに応じて白と暗い色を切り替えます
- **クリックが透過する不透明度のしきい値が 0.6 になりました** (従来は 0.5)。不透明度 0.6
  の表面は向こう側が見えているのに自分が拾われていました。0.6 ちょうども透過します
  → [ピッキングとホバー表示](ui/mouse-input.md#ピッキングとホバー表示)

### 画面と操作

- **分子ビューのツールパレットを折りたためるようになりました。** 上端のつまみを押すと
  つまみだけの形になり、もう一度押すと戻ります。**View &gt; Tool palette**
  (++cmd+shift+p++) でも切り替えられ、状態は次回の起動にも引き継がれます
  → [ツールバーとツールパレット](ui/toolbar-tools.md#ツールパレット)
- **ファイルを新しいシーンで開けるようになりました。** これまで Object のファイルは
  必ず現在のシーンに加えられていました。**Settings &gt; General &gt; Files** の
  **Drag and drop opens into** と **File manager opens into** で、経路ごとに選べます
  (どちらも既定は現在のシーン)。**Open File...** と **Open Recent** は常に現在のシーン、
  `.qsc` は対象外です → [設定項目](reference/settings.md#files)

!!! warning "既存のシーンで見え方が変わることがあります"
    - **dsurface で保存したシーンは、距離場によるメッシュで描かれます。** 従来の
      dsurface はボクセルによる実装でしたが、アルゴリズムの設定はそれ自体が新しいため
      ファイルに記録されておらず、開くと新しい既定になります。メッシュの見え方と
      Detail の効き方が変わります。以前の見た目に戻すには、Algorithm に
      **EDTSurf (voxel)** を指定してください。`dsurf2` で保存したシーンは
      **Distance field** になるので、見た目は変わりません
    - **MD トラジェクトリの GUI は、有効にするまで出てきません。**
      設定を触ったことがない場合は無効になります。Settings &gt; Plugins &gt; Installed の
      **MD Tools** を有効にしてください
    - **カメラの順序は CueMol2 (UXP 版) では保たれません。** 順序を付けたシーンを
      CueMol2 で保存し直すと、カメラは名前順に戻ります

## 2.3.14.525 (2026-09-12)

### 3D ビューの操作

- **描かれた形状のとおりにクリックが当たるようになりました。** cartoon / ribbon / tube では
  帯の中央をクリックしても当たらず、残基の CA の近くしか拾えていませんでした。矩形 / 投げ縄
  選択と対称分子は、これまでどおり原子の位置で判定します
  → [ピッキングとホバー表示](ui/mouse-input.md#ピッキングとホバー表示)
- **ポインタの下にあるものが分子ビューの左下に表示され、その場で強調されるようになりました。**
  チェインと残基 (原子単位の Renderer では原子名も)、それが属する Object と Renderer が
  出ます。強調表示のためにシーンを描き直さないので、アンビエントオクルージョンや
  アンチエイリアシングの蓄積は巻き戻りません。**Settings &gt; Input &gt; Mouse &amp; Navigation** の
  **GPU Picking** / **Hover Info** / **Hover Highlight** で切り替えられます
  → [設定項目](reference/settings.md#mouse--navigation)

### 描画 (レンダリング)

- **半透明が重なった部分で、暗いものが明るく反転する不具合が修正されました。** 半透明の
  表面越しの黒いエッジ線が白く描かれていました。画素ごとに合成する
  **Per-pixel transparency** が既定になります。半透明が 1 枚しか掛かっていない画素は
  従来と同じ絵で、変わるのは重なった部分だけです
  → [レンダリング](reference/rendering.md#transparency)
- **ウィンドウを覆ったり最小化したりするとレンダリングが数倍遅くなる不具合が修正されました。**
  一度遅くなるとアプリケーションを再起動するまで戻りませんでした。レンダリング中は
  システムがスリープしないようにもなりました
- **レンダリングウィンドウが、レンダリングをまたいで表示倍率とスクロール位置を保つように
  なりました。** 履歴を行き来しても保たれるので、2 つの結果を同じ倍率で見比べられます。
  `+` / `-` / `100%` / `Fit` は表示領域の中心を基準に拡大縮小します
  → [レンダリングウィンドウ](ui/rendering-window.md#画像領域)
- **大域照明の光の配分の段を引き直しました。** 段が動かすのは正面からの光と照り返しの配分
  だけになり、キーライトの強さはどの段でも変わらなくなりました
  → [レンダリング](reference/rendering.md#gi-lighting)

### 画面と操作

- **分子表面で Solid coloring が効くようになりました。** 色に `$molcol` を選んでも半透明の
  灰色になり、dsurface / dsurf2 では Solid coloring を選んでも CPK のままでした
  → [Coloring](reference/coloring.md#solid)
- **リストの行をクリックしても、名前の変更やセルの編集に入らなくなりました。**
  シーンツリーでは選択済みの行をもう一度クリックすると名前の変更が始まってしまい、Paint の
  表ではクリックするとテキスト入力欄にフォーカスが入るため ++cmd+c++ / ++cmd+v++ /
  ++cmd+z++ がそちらに吸われていました。編集は ++f2++ ・ダブルクリック・右クリック
  メニューから始めます。シーンツリーの右クリックメニューに **Rename...** が加わりました
  → [サイドパネル](ui/side-panels.md)
- **Paint の行のコピー &amp; ペーストが、選んだ行に効くようになりました。** 複数行を選んでから
  右クリックすると、選択が 1 行に戻ってしまっていました
- **選択の Named の先頭に `all (*)` が並ぶようになりました。** 一覧の高さは、Selection
  パネルではパネルの残りいっぱい、ポップオーバーでは開いた側の空きに合わせます
  → [選択ビルダー](ui/selection-builder.md#named)

!!! warning "既存のシーンで見え方が変わることがあります"
    - **以前のビルドで保存したシーンの GI lighting は Custom と表示されます。** 段の値が
      変わったため、保存されている値がどの段とも一致しません。段を選び直すと新しい値に
      なります
    - **半透明の合成が既定で画素ごとになります。** 半透明が 1 枚しか掛かっていない画素は
      同じ絵になり、2 枚以上重なった画素だけが変わります (それが修正の内容です)。
      blendpng や POV-Ray と揃えたいときは Transparency を OFF にしてください

## 2.3.13.523 (2026-09-06)

### 描画 (レンダリング)

- **レンダリングウィンドウの設定がシーンに保存されるようになりました。** これまでは
  設定がメモリ上にしかなく、すべてのシーンで共有され、ウィンドウを閉じると失われて
  いました。シーンファイルに書き込まれ、シーンごとに復元されます。設定の変更は Undo の
  対象で、レンダリングウィンドウ内でも ++cmd+z++ が効きます。結果の履歴からは
  **Use settings** でそのときの設定に戻せます → [レンダリング](reference/rendering.md#設定の保存)
- **大域照明の光の配分が見直されました。** Global Illumination では開けた面が明るく平坦に
  なり、白いチューブの陰影が消えていました。Quality に **GI lighting** の 5 段階が加わり、
  0 はレイトレースと同じ配光、4 (既定) は正面光をキーライトと照り返しに移した配光です。
  すべての方式に効く **Lights** (Light intensity / Flash fraction) が加わり、GI intensity /
  GI environment はウィンドウから外れ、GI quality は GI samples (8 / 32 / 64 / 256) の
  選択になりました → [レンダリング](reference/rendering.md#gi-lighting)
- **Renderer どうしが交わる線 (Contact edges) を、エッジ線の設定が異なる Renderer の間に
  描くようになりました。** ribbon に刺さる ballstick の結合などの交線です。エッジ線の設定
  (種類・太さ・色) が同じ Renderer はひとまとまりとして扱われ、その間には描かれません。
  すべての Renderer が同じエッジ設定 (既定のままなど) のシーンでは、これまでどおり交線は
  描かれません → [レンダリング](reference/rendering.md#edges)
- **Silhouette の輪郭が、フォグで薄れた面の奥でも描けるようになりました。** Umbreon が
  分子ビューと同じ奥行きで描画を打ち切るようになり、輪郭を描き始める深さを
  **Outline far depth** で指定します。**Crease angle** は折れ線として描く角度の段階
  (Off / 15〜120°) になり、POV-Ray 専用だった Edge rise は Umbreon の設定から外れました
- **Umbreon のエッジ線で、大きく拡大すると原子の内側に斑点状の線が描かれる不具合が
  修正されました。** ballstick などの結合の端が原子の球とちょうど同じ面にあったため、
  エッジ線の検出がそこを細かな段差と誤認していました
- **コマンドライン (`cuetty --render`) と Python モジュールが、シーンに保存された設定で
  描画するようになりました。** 設定のないシーンは既定値 (Global Illumination、1200×1200) で
  描画されます。`--width` / `--height` は保存されたサイズを上書きします
  → [レンダリング](reference/rendering.md#コマンドラインでのレンダリング)

### 密度マップと分子表面

- **等高線レベルの単位が、マップの種類に応じたものになりました。** 結晶学的マップでは σ、
  クライオ電子顕微鏡マップでは格子点の値の上位何 % かで、既定はそれぞれ 1.1σ と上位 1 % です。
  **Reset to default** でクライオ電顕マップの既定に戻るようになり (従来は 1.1σ に戻って
  いました)、Density map パネルの **Level** はどちらの単位でも絶対値でも指定でき、
  もう一方の値が下に表示されます。**Map type** を変えると Renderer のスタイル
  (Default / Cryo-EM) も入れ替わります → [DensityMap](reference/objects/densitymap.md#マップの種類-map-type)
- **マップを開いても視点が原点に飛ばなくなりました。** モデルの上に 2Fo-Fc マップを開くと、
  視点が原点に移動してマップも原点の周りにしか描かれませんでした。ファイルを開くダイアログに
  **View after loading** (Auto / Set map center / Move view center) が加わりました。BRIX /
  mmCIF / QDF / X-PLOR のマップに、分子と同じ原子選択の欄が出なくなりました
  → [File メニュー](menu/file.md)
- **マップの種類がインスペクタに表示されます。** DensityMap の Properties タブに
  **Density map** セクション (Map type の変更と Effective kind)、マップの Renderer に
  **Map kind** が加わりました。等値面には **Cap mode** (Auto / On / Off) が付き、既定の色が
  飽和した青から明るい灰色になりました → [isosurf](reference/renderers/isosurf.md)
- **dsurface / dsurf2 で Multi-gradient が使えるようになりました。** molsurf と同じく、
  静電ポテンシャルによる着色、ストップの編集、シーンへの保存ができます
  → [Coloring](reference/coloring.md#multi-gradient)
- **APBS elepot calculation... の Charge method** がドロップダウン (**Method**) になりました
  → [分子表面を静電ポテンシャルで着色する](tutorials/surface-elepot.md)

### 画面と操作

- **アニメーションの時刻を、タイムコードの桁ごとに編集できるようになりました** (Blender /
  After Effects 風)。桁をクリックしてドラッグ、++up++ / ++down++、数字の打ち込み、++enter++ で
  式の入力ができます。インスペクタの Start time / Duration はドラッグ中にストリップが追従し、
  1 回の Undo で戻せます。Animation パネルの現在時刻も打ち込んで移動できます。開始時刻の
  基準が循環したり、名前が重複・欠落したりする指定は理由を示して拒否され、解決できない要素は
  斜線付きで表示されて直すまで再生できません → [時刻の入力](ui/inspector.md#時刻の入力)
- **New Tab ダイアログで、新しいシーンの表示設定を決められるようになりました。**
  アンチエイリアシング / アンビエントオクルージョン / 背景色 / CMYK プルーフィングを指定でき、
  確定した値が以後の新しいシーン (起動時やファイルのドロップで作られるものを含む) の既定に
  なります → [File メニュー](menu/file.md)
- **重ね合わせたあとに原子のクリックがずれる不具合が修正されました。** tube / ribbon /
  cartoon で、原子が移動前の位置で選ばれていました
- **Paint の着色が Renderer に効くようになりました。** Color パネルは Renderer を選んでいても
  Object に書き込んでいたため、ribbon / cartoon / tube では何も起きませんでした。対象は
  シーンツリーの選択に追従し、Paint の **Default** が二次構造ごとの標準の塗り分けになりました
  (従来 "Default" と表示されていたスタイルは **Molecule color**) → [サイドパネル](ui/side-panels.md)
- **Renderer グループの名前を変えるとアプリケーションが固まる不具合が修正されました。**
  Generic タブの Name の default チェックを入れると、グループが名無しになっていました。
  Name と Selection (`sel`) は既定値に戻せなくなり、Generic タブは名前を変えても開いたままに
  なります → [プロパティインスペクタ](ui/inspector.md#generic-タブ)
- **選択の履歴が、選択を適用するすべての操作から記録されるようになりました。**
  インスペクタの選択欄、New Renderer、シーンツリー / 配列パネル / 右クリックメニューの選択、
  矩形 / 投げ縄選択、Molecular structure パネルが対象です。件数は 100 件 (従来 40 件) に
  なりました → [選択ビルダー](ui/selection-builder.md#history)
- **Windows / Linux で、シーンツリーや Paint の表に対する ++ctrl+c++ / ++ctrl+v++ などが
  効くようになりました。** テキスト入力欄の外ではメニューのショートカットが働いていませんでした
  → [キーボードショートカット](reference/shortcuts.md)
- **そのほか:** ダークテーマの補助的な文字が暗すぎて、シーンツリーの開閉マークなどが無効に
  見えていたのが直りました。atomintr のラベルのフォントは、インストールされているフォントから
  選ぶ形になりました。Scene のインスペクタはすべてのセクションを同時に表示します。
  Windows / Linux のアプリケーションアイコンが新しくなりました。

- Electron 42.5.1 になりました

!!! warning "既存のシーンで見え方が変わることがあります"
    - **2.3.11.507 / 2.3.12.517 で保存したクライオ電子顕微鏡マップの等高線レベル。**
      レベルの数値が σ ではなく上位 % として読まれます。Density map パネルでレベルを
      動かしていたシーンは見た目が変わるので、レベルを一度調整してください。動かして
      いなかったものは既定 (上位 1.1 %) になります。結晶学的マップは変わりません
    - **エッジ線の設定が同じ Renderer はひとまとまりとして扱われます。** Edge type が
      Silhouette のとき、まとまりの外周だけが描かれるため、すべてのチェインが同じエッジ設定の
      シーンでは、チェインどうしが重なる部分の輪郭が描かれなくなります。エッジ設定が異なる
      Renderer の間には、交線 (Contact edges) が新たに描かれます
    - **Umbreon は分子ビューと同じ奥行きで描画を打ち切ります。** フォグの終端より奥に
      あって薄く描かれていたものは描かれなくなります
    - **`cuetty` / Python は、設定のないシーンを Global Illumination で描画します。**
      従来のレイトレースだけの描画より時間がかかります

## 2.3.12.517 (2026-08-31)

### ファイルを開く

- **圧縮された `.pdb.gz` / `.cif.gz` が開けるようになりました。** 拡張子の照合が
  最後のドット以降しか見ていなかったため、対応する読み込み処理が見つからず開けません
  でした。同じ理由で、名前にドットを含むフォルダに Object を保存すると、
  選んだ形式と違う形式で書き出されることがありました
  → [File メニュー](menu/file.md)
- **大きな GROMACS の `.gro` ファイルが読めるようになりました。** 残基番号は 5 桁で
  書かれるため 99999 の次が 0 に戻り、溶媒の最初の残基がタンパク質の残基 1 に
  混ざって、読み込み自体が途中で止まっていました。
- **BRIX / DSN6 マップの等高線レベルが決まらない問題が修正されました。** 統計値の
  計算が誤っていたため σ が求まらず、レベルが決まりませんでした。DSN6 は値の範囲も
  誤っていました。

### Renderer とプロパティ

- **New Renderer の一覧に disorder と atomintr が並ぶようになりました。** disorder は
  作成した時点で、シーンにある主鎖 Renderer が Target に設定されるので、そのまま
  描画されます → [disorder](reference/renderers/disorder.md)
- **数値をドラッグして端から端まで動かせるようになりました。** 従来は変化の速さが
  一定で、エッジ線の太さのように範囲の狭い設定は端まで動かすのに 400 ピクセル以上の
  ドラッグが必要でした。++shift++ で細かく、++esc++ でドラッグの取り消しができます
  → [プロパティインスペクタ](ui/inspector.md#数値の入力)
- **ポリゴンの分割数 (Detail) が段階の選択になりました。** 数値を打ち込む代わりに
  2 の冪から選びます。
- **分子表面や等高線の着色を元に戻せるようになりました。** dsurface / dsurf2 /
  contour を静電ポテンシャルや Multi-gradient に切り替えると、以後どの着色を選んでも
  表示が変わらなくなっていました → [Coloring](reference/coloring.md)
- **インスペクタから開いた選択ビルダーにも、原子数が表示される**ようになりました
  → [選択ビルダー](ui/selection-builder.md#原子数の表示)

### 画面と操作

- **シーンツリーと Paint の表をキーボードで操作できるようになりました。**
  ++up++ / ++down++ / ++home++ / ++end++ での移動と、++shift++ を併用した範囲選択、
  シーンツリーでは ++left++ / ++right++ での開閉ができます
  → [サイドパネル](ui/side-panels.md)
- **Renderer を別の Renderer に貼り付けられるようになりました。** 同じ Object の
  同じグループの中に貼り付けられ、右クリックメニューに **Paste Renderer** が
  加わりました → [サイドパネル](ui/side-panels.md)
- **ノードの名前を変更している途中の ++backspace++ で、そのノードが削除される
  不具合が修正されました。**
- **New Renderer やファイルを開くダイアログで、シーンに定義した名前付きの選択が
  効くようになりました。** これまでは選択が無視され、全原子を表示する Renderer が
  作られていました → [選択式の文法](reference/selection.md)
- **Scene メニューの Background に色見本が付き、Use color proofing にチェックが
  付くようになりました** → [Scene メニュー](menu/scene.md)

### 安定性

- **保存していないシーンを失う 2 つの経路を塞ぎました。** ウィンドウを閉じるときの
  「Save changes?」の確認に 10 秒以上かかると強制的に閉じられていたこと、および
  CueMol3 を 2 つ起動すると、後から起動したほうが先に起動したほうの作業ファイルを
  消していたことです。
- **File &gt; Reload Scene がシーンを二重にしなくなりました。** 読み込む前にシーンを
  空にしていなかったため、すべての Object が 2 つずつになっていました。
  開けなかったシーンファイルは、空のタブを残さずエラーを表示します
  → [File メニュー](menu/file.md)
- **アプリケーションが異常終了する 2 つの不具合が修正されました。** プリセットの
  Renderer グループごとコピーした分子を新しいシーンに貼り付けたときと、
  他の要素が時刻の基準にしているアニメーション要素を削除したときです。
- **共通ライブラリの点検で 132 件の不具合が修正されました。** CueMol2 と共通の部分で、
  原子名の照合 (`name C1'` が `C1*` と命名された原子にマッチするようになりました
  → [選択式の文法](reference/selection.md#名前リスト))、二次構造の判定、
  PDB の MODEL の扱い、Undo / Redo、壊れたファイルの読み飛ばしなどが含まれます。

## 2.3.11.507 (2026-08-27)

### 密度マップ

- **クライオ電子顕微鏡のマップに対応しました。** ファイルのヘッダからマップの種類を
  判別し、クライオ電顕マップでは**マップ全体**を表示します。従来はビュー中心の周りの
  立方体だけを表示していたため、箱の端を越えると反対側の密度が折り返して描かれていました。
- **拡大すると表示が細かくなります。** 全体を細かく描くと面の数が膨大になるため、
  全体は粗く描き、拡大した部分だけを細かく描き直します (**Level of detail** /
  **Refine on zoom**)。等値面でも等高線メッシュでも働きます。
- **大きなマップを開けるようになりました。** メモリの使い方を改めたことで、一辺 1300 格子
  ほどのマップも読み込めます。CCP4/MRC を開くときは、ダイアログにマップの大きさと必要な
  メモリが表示され、大きすぎる場合は **Subsample** (格子の間引き) が提案されます。
- **判別の結果と表示範囲は手で変えられます。** ファイルを開くときの **Map type** で
  結晶学的マップかクライオ電顕マップかを指定でき、表示範囲は Renderer の **Region** で
  **Box around center** (中心の周りだけ) と **Full map** (全体) を選べます。
- **MRC の ORIGIN を読むようになりました。** 原点が 0 でないマップが、そこに当てはめた
  モデルと正しく重なるようになりました。
- **クライオ電顕マップは、読み込んだ時点で見える状態になります。** 等値レベルが自動で
  決まり、マップ全体が画面に収まるように視点も合わせられます。
- **gpu_mapmesh が描画されるようになりました。** シェーダが動いていなかったため、
  これまでは何も表示されていませんでした。ただし線の太さを変えられず
  [contour](reference/renderers/contour.md) より遅いため、Renderer の新規作成の
  選択肢からは外れています → [gpu_mapmesh](reference/renderers/gpu_mapmesh.md)

!!! warning "既存のシーンで見え方が変わることがあります"
    外部の CCP4/MRC ファイルを参照しているシーンで、そのマップがクライオ電顕マップと
    判別された場合、中心の周りだけの表示から全体の表示に変わります。元に戻すには、
    Renderer の **Region** を **Box around center** にするか、マップの **Map type** を
    *Crystallographic* にしてください (プロパティインスペクタの **Generic** タブから
    変更できます)。

### ファイルを開く

- **手元の mmCIF ファイルが開けるようになりました。** 最近の PDB の mmCIF はヘッダが長く、
  座標が数百 KB 先から始まるため、形式を判別できず開けないことがありました
  → [File メニュー](menu/file.md)

### 画面と操作

- **シーンツリーの複数選択が実際に働くようになりました。** ++shift++ + クリックの範囲選択が
  これまで反応していませんでした。**Delete** ボタンは選んだノードすべてを削除するようになり、
  ++delete++ / ++backspace++ キーでも削除できます → [サイドパネル](ui/side-panels.md)
- **Paint の表も複数選択できるようになりました。** ++cmd++ / ++ctrl++ + クリックと
  ++shift++ + クリックで選び、削除・Cut・Copy が選んだ行すべてに効きます。ツールバーは
  行の追加・削除と並べ替えの 4 つになり、**Delete all** と **Cut / Copy / Paste** は
  行の右クリックメニューに移りました → [サイドパネル](ui/side-panels.md)
- **ダイアログの中でコピー &amp; ペーストができるようになりました (macOS)。** ダイアログを
  開いている間はアプリケーションメニューが無効になっていたため、**Get PDB...** の入力欄
  などに ++cmd+v++ で貼り付けられませんでした。
- **アンビエントオクルージョンの Medium / High が軽くなりました。** 視点を動かしている間は
  半分の解像度で計算し、止めると元の解像度で描き直します。書き出す画像は常に元の解像度です
  → [Scene](reference/scene.md#ambient-occlusion)
- **待機カーソルがちらつかなくなりました。** すぐ終わる処理では出なくなりました。
- **数値の設定がスライダーになりました。** レイトレーサのアンビエントオクルージョン
  (サンプル数・距離・強さ・直接光の割合)、分子表面 Renderer の **Detail**、
  Tools &gt; **Mol surface generation...** の **Probe radius** です。
