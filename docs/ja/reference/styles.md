# スタイル

**スタイル**は、Renderer のプロパティをプリセットとして一括指定するしくみです。
Renderer には多数のプロパティがあるため、よく使う組み合わせに名前を付けて
まとめて適用できるようになっています。

## 値の優先順位

プロパティの値は 3 つの層から決まります。下の層ほど優先されます。

1. **既定値** — 実装レベルで決まっている値。変更できません
2. **スタイル値** — スタイルを適用すると、既定値がスタイルで定義された値に置き換わります
3. **ユーザー指定値** — インスペクタで直接指定した値。既定値もスタイル値も無視されます

たとえばあるプロパティの既定値が 0.5、スタイルの定義値が 0.1 で、
インスペクタで 1.0 を指定した場合、実際に使われるのは 1.0 です。

!!! tip "スタイルを適用しても表示が変わらないとき"
    そのプロパティにユーザー指定値が入っていて、スタイル値を上書きしているためです。
    プロパティを既定値に戻すと、スタイルの値が効くようになります。
    インスペクタの各項目は個別に既定値へ戻せます
    (→ [プロパティインスペクタ](../ui/inspector.md))。

## スタイルの種類

形状に関するスタイルと、Coloring に関するスタイルは独立に定義されており、
別々に適用できます。

形状のスタイル
:   Renderer の形に関するプロパティ群。シーンツリーで Renderer を右クリックして適用します。
    たとえば [ribbon](renderers/ribbon.md) には Default / Fancy1 / Round があります

Coloring のスタイル
:   着色に関するプロパティ群。Color パネルから適用します
    (→ [Coloring](coloring.md))

## スタイルの操作

シーンツリーの右クリックメニューから、スタイルの適用・作成・編集ができます。
スタイルセットはシーンツリーのノードとしても表示され、
ファイルへの読み書きができます (→ [サイドパネル](../ui/side-panels.md))。
