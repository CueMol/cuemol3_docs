# CamMotion (カメラ移動)

保存しておいたカメラの位置・向き・拡大率へ、視点を滑らかに移動させる
アニメーションです。

!!! info "準備中"
    このページは骨組みのみです。各項目の詳細は今後追加されます。

## プロパティ

共通のプロパティ (名前・開始時刻・継続時間など) は
[アニメーション](index.md#共通のプロパティ) を参照してください。

Target camera
:   移動先のカメラ。あらかじめシーンツリーにカメラとして
保存しておく必要があります (→ [カメラ](../camera.md))

Ignore rotation
:   ON にすると視点の向きを変化させません

Ignore center
:   ON にすると視点の中心を変化させません

Ignore zoom
:   ON にすると拡大率を変化させません

Ignore slab
:   ON にするとスラブ (表示する奥行きの範囲) を変化させません
