# SimpleSpin (スピン)

視点を指定した軸のまわりに回転させるアニメーションです。
分子を回して見せる、もっとも基本的な要素です。

!!! info "準備中"
    このページは骨組みのみです。各項目の詳細は今後追加されます。

## プロパティ

共通のプロパティ (名前・開始時刻・継続時間など) は
[アニメーション](index.md#共通のプロパティ) を参照してください。

Rotation angle
:   回転する角度

Spin axis
:   回転軸のベクトル (X / Y / Z)
