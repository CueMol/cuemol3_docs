# MolSurfObj (分子表面)

分子の溶媒排除表面 (SES) のポリゴンデータを保持する Object です。

!!! info "準備中"
    このページは骨組みのみです。プロパティの一覧は今後追加されます。

## 作成

Tools メニューの **Mol surface generation...** で分子から生成するか、
MSMS の表面ファイル (`.face` / `.vert`) や PLY ファイルを読み込みます
(→ [Tools メニュー](../../menu/tools.md))。

生成後は Tools &gt; **Mol surface cutter...** で平面による切断、
シーンツリーの右クリックメニューから再生成ができます。

### 生成アルゴリズム (Algorithm)

生成・再生成のダイアログでは、SES を計算する方法を選べます。

| Algorithm | 内容 |
|---|---|
| Auto | MeshMS を使います (**既定**) |
| MeshMS | 解析的に SES メッシュを作る新しい実装 |
| BALL | CueMol が従来使ってきた実装 |

配布されているビルドには両方が組み込まれています。*Auto* のとき、MeshMS が
その入力で失敗した場合は自動的に BALL に切り替わるため、表面は必ず生成されます。

同じ密度・プローブ半径でも、2 つのアルゴリズムが作るメッシュは一致しません。
MeshMS は表面全体に 1 つの目標辺長を適用し、頂点を統合してから法線を求めるため、
一般により滑らかになります。密度の目盛りは BALL に合わせて較正してあるので、
同じ密度の値からは同程度の細かさが得られます。

生成のたびに、どちらのアルゴリズムが動いたか・所要時間・頂点数と面数が
Output パネルのログに 1 行出力されます。

!!! tip "密度だけを変える再生成は速くなります"
    再生成では、密度に依存しない部分の計算結果がキャッシュされます。Regenerate ダイアログで
    **密度だけ**を変えた場合はメッシュ化だけがやり直されます。座標・選択範囲・原子半径の
    いずれかが変わるとキャッシュは無効になるため、古い表面が使い回されることはありません。

!!! note "既存のシーンの見た目は変わりません"
    シーンファイルの形式は変わっていないため、保存済みのシーンは従来どおり読み込まれます。
    表面が変わるのは、再生成したときだけです。
