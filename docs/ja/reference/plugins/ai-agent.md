# AI Agent

見たい状態を文章で指示すると、モデルが CueMol3 の操作を順に呼び出してシーンを
組み立てるチャットパネルです。**既定では無効**のプラグインで、利用には
OpenAI または Anthropic の API キーが必要です (費用は利用者の負担になります)。

## 有効にする

**Settings &gt; Plugins &gt; Installed** で **AI Agent** を有効にします
(→ [プラグイン](index.md))。有効にすると、アクティビティバーに **AI Agent** の
アイコンが追加されます。パネルはこのアクティビティビューからのみ開けます
(メニューやコマンドからは開けません)。

## モデルと API キーの設定

設定は **Settings &gt; Plugins &gt; AI Agent** にあります
(このページはプラグインを有効にすると現れます)。

| 項目 | 既定値 | 説明 |
|---|---|---|
| Model | `openai:gpt-5.6` | 使用するモデルを `プロバイダ:モデル名` の形式で指定します。候補から選ぶほか、自分のアカウントで使える ID を直接入力できます。プロバイダの部分で、下のどちらの API キーを使うかが決まります |
| Reasoning effort | low | 回答前に考える時間の長さ。上げるほど遅くなり、費用も増えます |
| Pressing Enter | start a new line | メッセージ入力欄で ++enter++ を押したときの動作。*start a new line* (改行) のときは ++cmd+enter++ / ++ctrl+enter++ で送信します。*send the message* を選ぶと逆になります |
| OpenAI API key | (未設定) | `openai:` のモデルを使うときのキー |
| Anthropic API key | (未設定) | `anthropic:` のモデルを使うときのキー |

!!! note "API キーの保存先"
    API キーは OS の安全な保管領域 (macOS はキーチェーン、Windows は DPAPI、
    Linux はデスクトップのキーリング) で暗号化して保存され、設定ファイルには
    平文で書かれません。保存されたキーが無い場合は、環境変数
    `OPENAI_API_KEY` / `ANTHROPIC_API_KEY` が使われます。

    入力欄を空のまま離れても、保存済みのキーは消えません。消すときは **Clear**
    を押します。OS がキーを暗号化できない環境では保存せず、環境変数を使うよう
    案内されます。

## 使い方

- 入力欄に「1CRN を読み込んで cartoon で表示して」のように書いて送信します。
  既定では ++enter++ が改行、++cmd+enter++ / ++ctrl+enter++ が送信です
  (上の **Pressing Enter** で入れ替えられます)。
- 実行中は **Send** が **Stop** に変わり、途中で止められます。
- ++up++ / ++down++ で、送信済みの指示を呼び戻せます。
- **1 回の指示が 1 回の Undo にまとまります。** ++cmd+z++ 1 回で、その指示による
  変更をすべて取り消せます。
- パネル右上の **Clear chat** で会話を消去します。

## 制限事項

- **対象は 1 つのシーンだけ**です。指示を始めた時点のアクティブなシーンに対して
  操作します。「新しいシーンで」と指示しても、現在のシーンに読み込まれます。
- 実行中に手で加えた変更は、その指示の Undo に巻き込まれます。
- 会話はアプリケーションを終了すると失われます。
- 会話の途中でプロバイダを切り替えた場合の動作は確認できていません。
