# 構造変化のモーフィング (Mol morphing animation)

同じ分子の異なる 2 つの構造の間の変化 (変形 = morphing) を、アニメーションとして表示します。
線形補間による変形で、局所的な構造変化のアニメーションに向いています。

モーフィングは次の 2 段階で作ります。

1. **Tools &gt; Mol morphing animation...** で、分子 (MolCoord) を **MorphMol** に変換し、
   補間する構造 (フレーム) を追加します。このページで説明します。
2. 下部パネルの **Animation** タブに **MolAnim** の要素を追加し、いつ・どれだけの時間をかけて
   変形させるかを決めます (→ [MolAnim (構造変化)](../animation/molanim.md))。

具体的な手順の例は
[アニメーションを作って動画に出力する](../../tutorials/animation-movie.md) を参照してください。

## 前準備: 構造を重ね合わせる

モーフィングの補間は座標をそのまま使います。2 つの構造の位置がずれている場合は、
先に[分子の重ね合わせ](superpose.md)で揃えておきます。

## Morph animation tool ダイアログ

**Tools &gt; Mol morphing animation...** で **Morph animation tool** ダイアログを開きます。
ダイアログでの操作はその場でシーンに反映され、操作ごとに Undo できます。
ダイアログは **Close** で閉じます (OK / Cancel はありません)。

**Target** で対象の分子を選びます。

### MolCoord を MorphMol に変換する

選んだ分子がまだ MorphMol でないときは、**Setup** に **Convert to MorphMol** ボタンが表示されます。
押すと、その分子が MorphMol に変換されます。

- 変換した分子は、変化の**始点**の構造 (基準のフレーム) になります。
- 分子はシーン内で置き換えられますが、名前と Renderer はそのまま引き継がれます。
- 変換は Undo できます。

### フレームを追加・削除する

MorphMol を選ぶと、**Frames** に保持している構造 (フレーム) の一覧が表示されます。
変換した直後は、基準のフレーム `(this)` だけがあります。

| ボタン | 内容 |
|---|---|
| **Add PDB file...** | PDB ファイル (`.pdb` / `.ent` / `.pdb.gz`) を選んでフレームとして追加します。複数選べます。ファイルはシーンには読み込まれません |
| **Add mol...** | シーンにある別の分子をフレームとして追加します。**Molecule to add** で分子を選び、**Add as frame** を押します |
| **Delete** | 選んだフレームを削除します。`(this)` は削除できません |

追加したフレームは、一覧で選んでいる行の後ろに入ります。選んでいなければ末尾に入ります。
一覧の最初のフレームが補間の始点、最後のフレームが終点になります。

MorphMol をあとから編集するときも、同じダイアログで Target に MorphMol を選びます。

## 注意点

### 構造の対応

始点・終点・中間のフレームの間で、対応する残基・原子が存在しない場合、それらの原子は
モーフィングの計算から除外されます。

- 基準のフレーム `(this)` にある原子が、ほかのフレームに無い場合は、アニメーションの間
  その原子は静止したままです。
- 基準のフレームに無い原子がほかのフレームにある場合は、読み込むときに無視されます。

このため、同じ分子を異なる状態で決定した構造の間のモーフィングは簡単にできますが、
似ているが異なるホモログの間の変形はそのままではうまくいきません。ホモロジーモデリングなどで
残基番号などを揃えたモデル構造を作ると、正しくモーフィングできます。

### 大きな構造変化

線形補間では、ドメインレベルの非常に大きな変化を表すのは困難です。ほかのソフトウェアで
中間構造をいくつか作り、それらをフレームとして並べてつなぐことで、アニメーションを作れます。

## Console から使う

[Console](../plugins/console/index.md) の native モードでは、`convert_to_morph` /
`list_morph_frames` / `add_morph_frame` / `remove_morph_frame` で同じ操作を行えます
(→ [Console のコマンド一覧](../plugins/console/commands.md))。
