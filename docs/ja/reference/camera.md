# カメラ

**カメラ**は視点の状態 (位置・向き・拡大率・スラブ) を名前を付けて保存したものです。
サイドパネルの **Explorer &gt; Camera** に一覧表示され、いつでも呼び出して同じ視点に戻せます。

## カメラの操作

アクティビティバーの **Explorer** を選ぶと現れる **Camera パネル**で操作します
(→ [サイドパネル](../ui/side-panels.md#camera-パネル))。
よく使う 7 つはツールバーのボタンに、それ以外は行の右クリックメニューにあります。

下表の「右クリック」の列はメニューの項目名、「ツールバー」の列はボタンのツールチップです。

| 右クリックメニュー | ツールバー | 内容 |
|---|---|---|
| New Camera... | New camera from view | 現在の視点から新しいカメラを作ります。同じ名前のカメラがあると確認なしで上書きされます。 |
| Save from view | Save from view | 選んでいるカメラに現在の視点を上書きします。 |
| Save from scene (with vis flags) | Save from view with show/hide | 同上。表示フラグも一緒に保存します。 |
| Apply to view | Apply to view | 保存した視点に戻します。 |
| Apply to scene (with vis flags) | Apply to view with show/hide | 同上。表示フラグも復元します。行のダブルクリックでも行えます。 |
| Delete | Delete | カメラを削除します。++delete++ / ++backspace++ キーでも行えます。 |
| Rename... | — | 名前を変更します。++f2++ でも行えます。 |
| Copy / Paste Camera | — | カメラをコピー・貼り付けます。Edit メニューと ++cmd+c++ / ++cmd+v++ でも行えます。 |
| Camera file &gt; Load... / Reload / Save / Save As... | — | カメラファイル (`.cam`) を読み書きします。**Reload** はファイルから読み込んだカメラでのみ選べます。 |
| Edit vis flags / Clear vis flags | — | 表示フラグを編集・消去します。**Edit vis flags** はインスペクタの **Visibility** を開きます。**Clear vis flags** はフラグを持つカメラでのみ選べます。 |
| Properties... | Property | カメラを[インスペクタ](../ui/inspector.md)に表示します。 |

一覧の順序は行をドラッグして変更でき、シーンファイルに保存されます。
`__current` は先頭に固定され、並べ替えの対象外です。

## `__current`

`__current` は現在の視点を表す特別なカメラです。どのシーンにも作成時からあり、
シーンの保存・画像の書き出し・レンダリングの開始などの直前に、現在の視点で更新されます。
アニメーションの開始カメラの既定もこのカメラです。

- 削除・名前の変更・上書き・適用・コピーはできません。右クリックメニューの
  **Camera file &gt; Save As...** で `.cam` ファイルに保存することは可能です。
- 視点だけを持ち、表示フラグは持ちません。
- Undo の対象ではありません。**File &gt; Save current view...** で保存しても、
  シーンは変更ありにならず、Redo も消えません。

!!! note "CueMol2 (UXP 版) ではカメラの順序が保たれません"
    順序は CueMol3 で導入されたものです。順序を付けたシーンを CueMol2 で保存し直すと、
    カメラは名前順に戻ります。

## カメラが保持する情報

ツールバーの **Property** か右クリックメニューの **Properties...** で、カメラを
[インスペクタ](../ui/inspector.md)に表示します。インスペクタを表示している間は、
Camera パネルで別の行を選ぶとインスペクタもそのカメラに切り替わります。

| セクション | 内容 |
|---|---|
| Camera | **Name** (名前。ここで変更することも可能です) と **Source** (カメラファイルから読み込んだカメラはそのパス、それ以外は `Embedded in the scene`)。カメラファイルから読み込んだカメラには **Reload** / **Save** ボタンが付きます。 |
| View | 保存した視点 (Center / Rotation / Zoom / Distance / Slab / Projection / Center mark)。表示だけで、編集はできません。 |
| Visibility | 表示フラグ (下記) |

`__current` では Camera セクションだけが表示され、ボタンは **Save As...** だけです。

## カメラファイル (`.cam`)

カメラは、1 つずつ `.cam` ファイルに書き出したり、読み込んだりすることができます。
Camera パネルの右クリックメニューの **Camera file** から操作します。

| 項目 | 内容 |
|---|---|
| Load... | `.cam` ファイルを選んで、カメラとしてシーンに追加します。追加したカメラはすぐに現在のビューに適用され、表示フラグを持つカメラでは表示・非表示も復元されます。同じ名前のカメラがあるときは、`copy1_<名前>` のように名前を変えて追加します。 |
| Reload | カメラを、読み込んだファイルから読み込み直します。 |
| Save | カメラを、読み込んだファイルに上書き保存します。ファイルから読み込んだカメラでないときは、Save As... と同じ動作になります。 |
| Save As... | カメラを、新しいファイルに保存します。 |

ファイルから読み込んだカメラや、ファイルに保存したカメラは、そのファイルと**リンク**した状態になり、
Camera パネルの行にリンクのアイコンが付きます (インスペクタの **Source** にファイルのパスが表示されます)。

- シーンファイル (`.qsc`) には、リンクしたカメラはファイルへの参照として保存され、シーンを開くとその
  ファイルから読み込まれます。
- **シーンを保存すると、リンクしたカメラはそのファイルにも書き込まれます。** ほかのシーンと共有している
  `.cam` ファイルも上書きされるので注意してください。

現在の視点は、File メニューの **Save current view...** で `.cam` ファイルに書き出すこともできます
(→ [File メニュー](../menu/file.md))。この場合、シーンのカメラは増えず、ファイルとのリンクもできません。

## 表示フラグ

カメラには、そのカメラを適用したときに各 Renderer を表示するかどうかの
フラグを持たせられます。視点ごとに見せる要素を切り替えたい場合に使います。

表示フラグは、インスペクタの **Visibility** セクションで編集します。シーンの Object と
Renderer が並び (Renderer は Object の下に字下げして表示されます)、各行のチェックボックスで
そのカメラに含めるかどうかを、目のボタンで適用したときに表示するか隠すかを指定します。

- **Capture**: すべての行を含め、シーンの現在の表示・非表示の状態を記録します (視点は変えません)。
- **Clear**: 表示フラグを消去します。
- 変更はその場で反映され、1 回の変更が 1 回の Undo で戻ります。
