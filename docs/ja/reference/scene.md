# Scene

**Scene** はシーンツリーの最上位にある要素で、[Object](objects/index.md) や
[Renderer](renderers/index.md)、[カメラ](camera.md)、スタイルセット、
[アニメーション](animation/index.md)をまとめて保持します。
シーン全体に関わる表示設定も Scene のプロパティとして持ちます。

シーンは 1 つのタブに 1 つ表示されます。同じシーンを複数のタブ (ビュー) から
表示することもできます (→ [File メニュー](../menu/file.md) の New Tab)。
新しいシーンの表示設定 (アンチエイリアシング / アンビエントオクルージョン / 背景色 /
カラープルーフィング / [Legacy mode](#compatibility)) は New Tab ダイアログの **New Scene** の
下で指定でき、確定した値が以後の新しいシーンの既定になります。出荷時の設定では、新しいシーンは
アンチエイリアシングが **High**、アンビエントオクルージョンが**有効** (Preset は **Medium**) で作られます。
以下で「既定」と書いているのは、プロパティの既定値です (アンチエイリアシングとアンビエント
オクルージョンは、New Tab ダイアログの値ではなくこちらです)。

## プロパティの開き方

Scene メニューの **Properties...**、またはシーンツリーのシーン行を選ぶと、
プロパティインスペクタの **Properties** タブに表示されます
(→ [プロパティインスペクタ](../ui/inspector.md))。
変更は分子ビューに即座に反映されます。セクションは折りたたまれず、すべて同時に表示されます。

CueMol2 のようなモーダルダイアログはありません。

## Ambient occlusion

画面空間アンビエントオクルージョンの設定です。
分子の凹んだ部分に陰影を落として立体感を強調します。

Enabled
:   アンビエントオクルージョンの有効・無効。既定は**無効**です。

Method
:   陰影の求め方。**Fast GI** (既定) と **GTAO** から選びます。無効のときは選べません。
    切り替えると、Preset はその方式の **Medium** になります (1 回の Undo で戻すことができます)。

Preset
:   陰影の付き方のプリセット。無効のときは選べません。内容は Method ごとに違います (下記)。

Indirect light
:   Fast GI のときだけ表示されます。近くの面が凹みに照り返す光の強さ (0〜2、既定 0.5)。
    0 にすると陰影だけになります。

Baked occlusion
:   Fast GI のときだけ表示されます。大きな凹みやサブユニットの間の暗がりの強さ (0〜1、既定 0.8)。
    0 にすると、画面の範囲で求める陰影だけになります。

### Fast GI

Blender の同名の機能にならった方式で、陰影を環境光にだけ掛けます。画面の範囲で求める細かな陰影に、
シーンの 3 Å の格子に焼き込んだ大きな凹みの陰影を組み合わせます。焼き込みは、分子の形や表示が
変わったときにやり直し、視点を回しているだけではやり直しません。分子表面・CPK・cartoon では、
GTAO よりはっきりした奥行き感が出ます。

| Preset | 内容 |
|---|---|
| Low | 陰影を探す範囲が狭く、サンプルが少なめです。 |
| Medium | 中間 (既定) |
| High | 陰影を探す範囲が広く、サンプルが多めです。 |

どの Preset も、視点を動かしている間は半分の解像度で計算し、視点が止まると元の解像度で
描き直します (拡大しているときは半分の解像度のままです)。画像の書き出しは常に元の解像度です。

### GTAO

以前からの方式です。

| Preset | 内容 |
|---|---|
| Low | 陰影の届く範囲が狭く、細かい凹凸が強調されます (既定) |
| Medium | 中間 |
| High | 陰影の届く範囲が広く、分子全体の形が強調されます。 |

プリセットは、陰影の到達距離・サンプリング数・濃さを 1 組にまとめたものです。
到達距離を広げるとサンプリングが粗くならないようステップ数が増え、
広い範囲で暗くなりすぎないよう濃さが下がるように調整されています。

**Medium** と **High** は計算量が多いため、視点を動かしている間だけ半分の解像度で
計算し、視点が止まると元の解像度で描き直します。画像の書き出しは常に元の解像度です。

!!! note "Fast GI より前に保存したシーンは GTAO で開きます"
    3.0.3.565 以前に保存したシーンファイルは、GTAO と当時の既定値で開きます。保存し直しても、
    同じ見た目のまま保存されます。

### 個別の調整

!!! note "個別の調整は Generic タブから"
    半径・濃さ・スライス数・ステップ数・半解像度描画といった個々の値は、
    Properties タブには出てきません。インスペクタの **Generic** タブから
    編集できます。Generic タブで値を変えると、Preset の表示は **Custom** に変わります。

Generic タブで編集できる項目は次のとおりです。

| プロパティ名 | 既定値 | 説明 |
|---|---|---|
| `aoEnabled` | false | 有効・無効 (Properties タブの Enabled と同じ) |
| `aoMethod` | fastgi | 方式。`fastgi` / `gtao` (Properties タブの Method と同じ) |
| `aoRadius` | 10.0 | 陰影を探す範囲 (Fast GI) / 陰影を計算する球の半径 (GTAO) |
| `aoIntensity` | 2.2 | コントラスト。大きいほど陰影が浅くなります。GTAO だけで使います。 |
| `aoSlices` | 8 | 水平方向のスライス数。大きいほど滑らかで低速 |
| `aoSteps` | 8 | スライスあたりのサンプル数 |
| `aoHalfRes` | true | 視点の移動中だけ半解像度で計算し、静止したら全解像度で描き直します。書き出し時は常に全解像度です。 |
| `aoBounce` | 0.5 | Fast GI の照り返しの強さ (Properties タブの Indirect light と同じ) |
| `aoProbeStrength` | 0.8 | Fast GI の焼き込んだ陰影の強さ (Properties タブの Baked occlusion と同じ) |

## Lighting

Brightness
:   シーン全体の明るさ (0.5〜1.5、既定 1.0)。すべての光に同じ倍率を掛けるので、陰影の付き方
    (アンビエントオクルージョンによる奥行き感) を保ったまま明るさだけが変わります。
    アンビエントオクルージョンの有無によらず効きます。

## Anti-aliasing

分子ビューの輪郭のギザギザを抑える後処理の設定です。
アンビエントオクルージョンとは独立に設定できます。

Quality
:   アンチエイリアシングの品質

| Quality | 内容 |
|---|---|
| Off | 後処理を行いません (ハードウェア MSAA による直接描画) |
| Standard (FXAA) | FXAA による輪郭の平滑化 (既定) |
| High (FXAA + 8x SS) | FXAA に加え、8 サンプルのスーパーサンプリング |
| Ultra (FXAA + 32x SS) | FXAA に加え、32 サンプルのスーパーサンプリング |

!!! tip "スーパーサンプリングは視点が静止してから効きます"
    High / Ultra のスーパーサンプリングは、**視点が止まっている間にだけ**
    サンプルを蓄積します。視点を動かしている間の描画が重くなることはなく、
    止めてから画質が上がっていく形になります。視点を動かすと蓄積はやり直しになります。

Generic タブで編集できる項目は次のとおりです。

| プロパティ名 | 既定値 | 説明 |
|---|---|---|
| `aa_method` | fxaa | 手法。`none` / `fxaa` / `smaa` から選びます。 |
| `aaJitterLevel` | 0 | スーパーサンプリングの段階。0 で無効、1〜5 が 2 / 4 / 8 / 16 / 32 サンプル |
| `aaSmaaThreshold` | 0.05 | SMAA のエッジ検出のしきい値。小さいほど多くの輪郭が対象になります。 |

SMAA は Quality のプリセットに含まれていないため、使う場合は Generic タブで
`aa_method` を `smaa` にします。このとき Quality の表示は **Custom** になります。

## Background

Color
:   背景色。既定は黒です。

Scene メニューとシーンツリーの右クリックメニューには白 / 黒の切り替えがありますが、
任意の色を指定する場合はここで設定します (→ [Scene メニュー](../menu/scene.md))。

## Color proofing

CMYK 出力の色再現をシミュレートする表示です。印刷したときの色味を画面で確認できます。

Enabled
:   カラープルーフィングの有効・無効。既定は無効です。
    ICC プロファイルが未設定のまま有効にすると、既定の CMYK プロファイルが
    割り当てられます。

Profile
:   使用する ICC プロファイル

Intent
:   レンダリングインテント。**Perceptual** (既定) / **Relative colorimetric** /
    **Saturation** / **Absolute colorimetric** から選びます。

無効に戻してもプロファイルとインテントの設定は保持されます。

## Compatibility

シーンの見た目を、CueMol3 のものにするか CueMol2 と同じもの (Legacy mode) にするかを切り替えます。

Legacy mode (CueMol2 look)
:   ON にすると、シーンが CueMol2 と同じ見た目になります。OFF (CueMol3 の見た目) では、
    ribbon が細く、nucl の塩基が小さく、nucl の骨格のチューブが角の丸い四角の断面になります。
    切り替えは 1 回の Undo で戻すことができます。

- 新しいシーンは CueMol3 の見た目で作られます。New Tab ダイアログの
  **Legacy mode (CueMol2 look)** か、Settings &gt; Display &gt; Compatibility の
  **Legacy mode for new scenes** を ON にすると、以後の新しいシーンが Legacy mode で作られます
  (どちらも同じ設定です。開いているシーンは変わりません)。
- CueMol2 で作ったシーンファイルは Legacy mode で開き、CueMol2 で表示したときと同じ見た目になります。
- 見た目はスタイルで決まるので、切り替えると既にある Renderer の見た目もすぐに変わります
  (Renderer ごとに値を設定し直した項目はそのままです)。
- 分子を読み込んだときや Paint の **Default** を選んだときの色も見た目に従い、CueMol3 の見た目では
  分子ごとの色、Legacy mode では CueMol2 の 4 色 (sheet が SteelBlue、helix が khaki、nucleic が
  yellow、それ以外が FloralWhite) になります。すでに塗ってある分子の色は変わりません
  (→ [Coloring](coloring.md#paint))。
- CueMol3 の見た目は、シーンの読み取り専用のスタイルセット `cuemol3_look` として持ちます
  (→ [スタイル](styles.md))。

## シーンの情報

次の項目は読み取り専用で、Generic タブに表示されます。

| プロパティ名 | 説明 |
|---|---|
| `name` | シーン名 |
| `src` | シーンの読み込み元のパス |
| `srctype` | 読み込み元の形式 |
| `basePath` | 相対パス解決の基準になるディレクトリ |
