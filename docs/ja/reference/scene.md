# Scene

**Scene** はシーンツリーの最上位にある要素で、[Object](objects/index.md) や
[Renderer](renderers/index.md)、[カメラ](camera.md)、スタイルセット、
[アニメーション](animation/index.md)をまとめて保持します。
シーン全体に関わる表示設定も Scene のプロパティとして持ちます。

シーンは 1 つのタブに 1 つ表示されます。同じシーンを複数のタブ (ビュー) から
表示することもできます (→ [File メニュー](../menu/file.md) の New Tab)。
新しいシーンの表示設定 (アンチエイリアシング / アンビエントオクルージョン / 背景色 /
カラープルーフィング) は New Tab ダイアログの **Scene settings** で指定でき、確定した値が
以後の新しいシーンの既定になります。以下で「既定」と書いているのは、出荷時の値です。

## プロパティの開き方

Scene メニューの **Properties...**、またはシーンツリーのシーン行を選ぶと、
プロパティインスペクタの **Properties** タブに表示されます
(→ [プロパティインスペクタ](../ui/inspector.md))。
変更は分子ビューに即座に反映されます。セクションは折りたたまれず、すべて同時に表示されます。

CueMol2 のようなモーダルダイアログはありません。

## Ambient occlusion

画面空間アンビエントオクルージョン (GTAO) の設定です。
分子の凹んだ部分に陰影を落として立体感を強調します。

Enabled
:   アンビエントオクルージョンの有効・無効。既定は**無効**です

Preset
:   陰影の付き方のプリセット。無効のときは選べません

| Preset | 内容 |
|---|---|
| Low | 陰影の届く範囲が狭く、細かい凹凸が強調されます (既定) |
| Medium | 中間 |
| High | 陰影の届く範囲が広く、分子全体の形が強調されます |

プリセットは、陰影の到達距離・サンプリング数・濃さを 1 組にまとめたものです。
到達距離を広げるとサンプリングが粗くならないようステップ数が増え、
広い範囲で暗くなりすぎないよう濃さが下がるように調整されています。

**Medium** と **High** は計算量が多いため、視点を動かしている間だけ半分の解像度で
計算し、視点が止まると元の解像度で描き直します。画像の書き出しは常に元の解像度です。

!!! note "個別の調整は Generic タブから"
    半径・濃さ・スライス数・ステップ数・半解像度描画といった個々の値は、
    Properties タブには出てきません。インスペクタの **Generic** タブから
    編集できます。Generic タブで値を変えると、Preset の表示は **Custom** に変わります。

Generic タブで編集できる項目は次のとおりです。

| プロパティ名 | 既定値 | 説明 |
|---|---|---|
| `aoEnabled` | false | 有効・無効 (Properties タブの Enabled と同じ) |
| `aoRadius` | 4.0 | 陰影を計算する球の半径 |
| `aoIntensity` | 2.2 | コントラスト。大きいほど陰影が浅くなります |
| `aoSlices` | 9 | 水平方向のスライス数。大きいほど滑らかで低速 |
| `aoSteps` | 3 | スライスあたりのサンプル数 |
| `aoHalfRes` | false | 視点の移動中だけ半解像度で計算し、静止したら全解像度で描き直します。書き出し時は常に全解像度です。Preset の Medium / High はこれを有効にします |

## Anti-aliasing

分子ビューの輪郭のギザギザを抑える後処理の設定です。
アンビエントオクルージョンとは独立に設定できます。

Quality
:   アンチエイリアシングの品質

| Quality | 内容 |
|---|---|
| Off | 後処理を行いません (ハードウェア MSAA による直接描画) |
| Standard (FXAA) | FXAA による輪郭の平滑化 (既定) |
| High (FXAA + 8x SS) | FXAA に加え、8 サンプルのスーパーサンプリング |
| Ultra (FXAA + 32x SS) | FXAA に加え、32 サンプルのスーパーサンプリング |

!!! tip "スーパーサンプリングは視点が静止してから効きます"
    High / Ultra のスーパーサンプリングは、**視点が止まっている間にだけ**
    サンプルを蓄積します。視点を動かしている間の描画が重くなることはなく、
    止めてから画質が上がっていく形になります。視点を動かすと蓄積はやり直しになります。

Generic タブで編集できる項目は次のとおりです。

| プロパティ名 | 既定値 | 説明 |
|---|---|---|
| `aa_method` | fxaa | 手法。`none` / `fxaa` / `smaa` から選びます |
| `aaJitterLevel` | 0 | スーパーサンプリングの段階。0 で無効、1〜5 が 2 / 4 / 8 / 16 / 32 サンプル |
| `aaSmaaThreshold` | 0.05 | SMAA のエッジ検出のしきい値。小さいほど多くの輪郭が対象になります |

SMAA は Quality のプリセットに含まれていないため、使う場合は Generic タブで
`aa_method` を `smaa` にします。このとき Quality の表示は **Custom** になります。

## Background

Color
:   背景色。既定は黒です

Scene メニューとシーンツリーの右クリックメニューには白 / 黒の切り替えがありますが、
任意の色を指定する場合はここで設定します (→ [Scene メニュー](../menu/scene.md))。

## Color proofing

CMYK 出力の色再現をシミュレートする表示です。印刷したときの色味を画面で確認できます。

Enabled
:   カラープルーフィングの有効・無効。既定は無効です。
    ICC プロファイルが未設定のまま有効にすると、既定の CMYK プロファイルが
    割り当てられます

Profile
:   使用する ICC プロファイル

Intent
:   レンダリングインテント。**Perceptual** (既定) / **Relative colorimetric** /
    **Saturation** / **Absolute colorimetric** から選びます

無効に戻してもプロファイルとインテントの設定は保持されます。

## シーンの情報

次の項目は読み取り専用で、Generic タブに表示されます。

| プロパティ名 | 説明 |
|---|---|
| `name` | シーン名 |
| `src` | シーンの読み込み元のパス |
| `srctype` | 読み込み元の形式 |
| `basePath` | 相対パス解決の基準になるディレクトリ |
