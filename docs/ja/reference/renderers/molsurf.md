# molsurf (分子表面・計算済み)

生成済みの分子表面 Object を描画する Renderer です。
対象 Object: 分子表面 (MolSurfObj) — 分子 Object 以外を対象とする唯一の分子系 Renderer です。

分子表面 Object は Tools メニューの **Mol surface generation...** で生成します
(→ [Tools メニュー](../../menu/tools.md))。
