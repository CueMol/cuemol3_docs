# 選択式の文法

分子の一部を指定するための**選択式**の文法リファレンスです。
CueMol2 の選択式と共通で、シーンファイル (`.qsc`) の互換性が保たれています。

選択式は**選択リテラル**と**選択演算子**から構成されます。
選択リテラルの一部は、[名前リスト](#名前リスト)や[数値リスト](#数値リスト)を引数に取ります。

!!! tip "選択式を入力する場所"
    - **Selection パネル** — 選択式を直接入力して適用します。入力中に妥当性が検証され、
      過去に使った式は **History** から再利用できます
    - **Renderer の `sel` プロパティ** — プロパティインスペクタ、または New Renderer
      ダイアログの Selection 欄で、その Renderer が描画する範囲を指定します
    - **各種ダイアログの選択欄** — 分子表面の生成、相互作用の検出などの対象指定

    → [サイドパネル](../ui/side-panels.md)

## 選択リテラル

選択リテラルは、それ単独で選択命令として機能します。
後述の演算子で組み合わせたり、修飾したりできます。

### 全選択

```
all
*
```

分子中のすべての原子を選択します。

### 空選択

```
none
```

何も選択しないことを表します。

### 元素による選択

```
elem [名前リスト]
e; [名前リスト]
```

[名前リスト](#名前リスト)で示される**元素名**を持つ原子が選択されます。
`e;` は `elem` の省略形です。省略形の場合は `;` の後の空白文字を省略できます
(以下の他の省略形でも同様)。

**例:**

```
e; C,N,O
```

分子中の炭素、窒素、酸素原子が選択されます。

### 原子名による選択

```
name [名前リスト]
n; [名前リスト]
```

[名前リスト](#名前リスト)で示される**原子名**を持つ原子すべてが選択されます。

**例:**

```
n; CA,N,O
```

分子中の、CA、N、O という原子名を持つ原子すべてが選択されます。
通常は、タンパク質主鎖の α 位炭素、アミド窒素、カルボニル酸素原子です。

### 残基名による選択

```
resn [名前リスト]
r; [名前リスト]
```

[名前リスト](#名前リスト)で示される残基名を持つ残基中の原子すべてが選択されます。

**例:**

```
r; ARG,LYS
```

分子中の ARG (アルギニン) と LYS (リジン) 残基が選択されます。

名前リストには正規表現も使用できます (→ [名前リスト](#名前リスト))。

```
r; /^A/
```

残基名が A から始まる ARG、ALA、ASN などが選択されます。

### 残基番号による選択

```
resi [数値リスト]
resid [数値リスト]
i; [数値リスト]
```

[数値リスト](#数値リスト)で示される残基番号を持つ残基中の原子すべてが選択されます。

**例:**

```
i; 3,5,10:20
```

残基番号 3、5、10〜20 をもつ残基がすべて選択されます。

### チェイン名による選択

```
chain [名前リスト]
c; [名前リスト]
```

[名前リスト](#名前リスト)で示される名前を持つチェイン中の全原子が選択されます。

**例:**

```
c; A,B
```

チェイン A と B が選択されます。

### 階層表記 (hierarchical notation)

以下のようなドットで区切られた表記です。

```
チェイン名.残基番号.原子名
```

**チェイン名** (名前リスト形式で複数指定可) で示される名前を持つチェイン中の、
**残基番号** (数値リスト形式で複数指定可) の範囲の残基の、
**原子名** (名前リスト形式で複数指定可) の原子名を持つ原子が選択されます。
`*` を指定した場合は、すべてのチェイン / 残基 / 原子が選択対象になります。

この表記法は

```
chain "チェイン名" and resid "残基番号" and name "原子名"
```

と全く同じ意味になります。

**例:**

```
A.1:100.CA,CB
```

チェイン A の残基番号 1〜100 の、α・β 位炭素が選択されます。

```
*.5,6,7.*
```

全チェインの残基番号 5、6、7 の残基中の全原子が選択されます。
すなわち `resid 5,6,7` と等価です。

### 残基プロパティによる選択

```
rprop [名前1]=[名前2]
```

[名前1] で示される残基プロパティが、[名前2] で示される値である残基中の原子すべてが
選択されます。

**例:**

```
rprop secondary=helix
```

残基プロパティ `secondary` が `helix` である残基中の全原子が選択されます。

### 温度因子による選択

```
bfac <比較演算子> <数値>
<比較演算子> := "<" | ">" | "="
```

比較演算子と数値で指定した条件を満たす温度因子を持つ原子が選択されます。
数値は実数で指定できます。

**例:**

```
bfac>50
```

温度因子が 50 より大きい原子が選択されます。

### 占有率による選択

```
occ <比較演算子> <数値>
<比較演算子> := "<" | ">" | "="
```

比較演算子と数値で指定した条件を満たす占有率を持つ原子が選択されます。

**例:**

```
occ>0.5
```

占有率が 0.5 より大きい原子が選択されます。

### Alternate conformation による選択

```
alt [名前リスト]
```

[名前リスト](#名前リスト)で示される alternate conformation ID を持つ原子が選択されます。

**例:**

```
alt A,null
```

alternate conformation が A の原子と、alternate conformation を持たない
(PDB ファイル中では空白文字になっている) 原子が選択されます。
残基の側鎖のみ alternate conformation がある場合などは、このようにしないと
側鎖しか選択されないので注意してください。

```
A.7.* & alt B, null
```

チェイン A の残基番号 7 の残基中で、alternate conformation が B の原子と、
alternate conformation を持たない原子が選択されます。

### 原子 ID による選択

```
aid [数値リスト]
```

[数値リスト](#数値リスト)で示される内部原子 ID を持つ原子が選択されます。
原子 ID は分子を読み込んだときに内部で振られる通し番号で、
シーンを保存・再読み込みしても保たれる保証はありません。
通常は上記の他の選択リテラルを使ってください。

## 選択演算子

### AND 演算子

```
[式1] and [式2]
[式1] & [式2]
```

式1と式2で表される選択集合の積集合からなる選択集合を作成します。
`&` で表記した場合は前後の空白はなくてもかまいません。

**例:**

```
chain A and resn ALA
c;A&r;ALA
```

分子中の、チェイン A に属する ALA 残基のみが選択されます。

### OR 演算子

```
[式1] or [式2]
[式1] | [式2]
```

式1と式2で表される選択集合の和集合からなる選択集合を作成します。

**例:**

```
chain A or resn ALA
```

分子中のチェイン A 全体と、すべての ALA 残基が選択されます。

### NOT 演算子

```
not [式1]
! [式1]
```

式1で表される選択集合の補集合からなる選択集合を作成します。

**例:**

```
not resn ALA
```

分子中の ALA 残基以外すべてが選択されます。

### AROUND 演算子

```
[式1] around [実数値]
[式1] around ["分子名"] [実数値]
a; ... (around の省略形)
```

式1で表される選択集合から実数値 Å 以内にある原子が選択されます。
式1自体の選択集合は含まれない点に注意してください。

第 2 の書式では、分子名で示される他の分子中で、式1で表される選択集合から
実数値 Å 以内にある原子が選択されます。

**例:**

```
chain A around 3
```

チェイン A から 3 Å 以内にある原子の集合が選択されます。チェイン A 自体は選択されません。

```
chain A around ["1CRN.pdb"] 3
```

分子名が 1CRN.pdb で示される分子中の chain A から 3 Å 以内にある原子の集合が
選択されます (同じシーン中に 1CRN.pdb という名前の分子 Object がないと選択は空になります)。

### EXPAND 演算子

```
[式1] expand [実数値]
ex; ... (expand の省略形)
```

式1で表される選択集合から実数値 Å 以内にある原子が選択されます。
AROUND と異なり、式1自体の選択集合も含まれる点に注意してください。

**例:**

```
chain A expand 3.5
```

チェイン A 自身と、それから 3.5 Å 以内にある原子の集合が選択されます。

### BYRES 演算子

```
byres [式1]
br; [式1]
```

式1の選択集合が残基単位に拡張されます。

**例:**

```
byres name SD
```

原子名 SD を持つ原子の集合が、残基単位の選択に拡張されます。
タンパク質の場合、結果としてメチオニン (Met) 残基がすべて選択されます。

### BYSIDECH 演算子

```
bysidech [式1]
```

式1の選択集合が側鎖のみに限定されます。
タンパク質の場合、表示が見やすいように bysidech で選択される領域には Cα も含まれます。

**例:**

```
bysidech A.10:100.*
```

チェイン A の残基番号 10〜100 の側鎖 (と Cα) のみが選択されます。

### BYMAINCH 演算子

```
bymainch [式1]
```

式1の選択集合が主鎖のみに限定されます。

### NEIGHBOR / EXTEND 演算子

```
neighbor [実数値]
extend [実数値]
```

文法としては受け付けられますが、**選択処理が実装されていないため常に空の選択になります**。
使用しないでください。

## 名前付きマクロ

よく使う選択式には、あらかじめ名前が付けられています。
選択式の中でそのまま名前を書いて使えます。

| 名前 | 定義 | 内容 |
|---|---|---|
| `protein` | `rprop type=prot` | タンパク質 |
| `nucleic` | `rprop type=nucl` | 核酸 |
| `water` | `rprop type=water` | 水分子 |
| `sugar` | `rprop type=pyranose` | 糖 (ピラノース) |
| `ligand` | `!rprop type=prot and !rprop type=nucl and !rprop type=water` | タンパク質・核酸・水以外 |
| `hydrogen` | `elem H` | 水素原子 |
| `helix` | `rprop secondary=helix` | α ヘリックス |
| `sheet` | `rprop secondary=sheet` | β シート |
| `coil` | `!rprop secondary=helix and !rprop secondary=sheet` | ヘリックス・シート以外 |

**例:**

```
protein and !hydrogen
```

タンパク質のうち水素以外の原子が選択されます。

## 名前リスト

```
name [, name, ...]
```

名前リストは name あるいは name をカンマで区切ったリストからなります。
カンマの前後の空白は複数あっても、なくてもかまいません。

name は、アルファベット、数字、アンダースコア (`_`) からなる文字列です。
アルファベットに関しては、大文字・小文字は区別されません。

name にこれら以外の文字 (ドットなど) を含む場合は、`"` (ダブルクォーテーション文字) で
囲む必要があります。ダブルクォーテーション文字で囲んだ場合は、
アルファベットの大文字小文字が区別される点に注意してください。

### 正規表現

名前リストとして正規表現を使用できます。

```
/^A[0-9][0-9]$/
```

上記だと、はじめの 1 文字が A、残りの 2 文字が数字の 3 文字、A01 などが選択されます。
全体にマッチさせるには、この例のように初めに行頭にマッチする `^`、
最後に行末にマッチする `$` をつける必要があります。

普通の名前リストのカンマ区切り表記と正規表現を混ぜることもできます。

```
ABC,/^A[0-9][0-9]$/
```

ABC と、A + 2 桁数値が選択されます。

正規表現中のアルファベット文字に関しては、大文字・小文字が区別されるので注意してください。

## 数値リスト

```
<range> [, <range>, ...]
<range> := <number> | <number1>:<number2>
```

数値リストは range あるいは range をカンマで区切ったリストからなります。
range は単独の整数値 (number) あるいは 2 つの整数値 `number1:number2` からなります。
後者は、number1 以上 number2 以下の整数の範囲を表します。

```
1, 3:10, 51
```

上記は 1、3、4、…、9、10、51 の整数値の集合を表します。

### 残基番号の場合の特例 (insertion code)

残基番号を指定する場合には、insertion code を含めることができます。
例えば、残基番号 20A と 20B を選択したい場合は、

```
i; 20A, 20B
```

と表記できます。上記のような範囲表記 (20A:20Z など) も可能です。
ただし、insertion code を含む残基番号の大小関係が微妙なので、
思いがけない部分が選択されてしまう場合があります。
