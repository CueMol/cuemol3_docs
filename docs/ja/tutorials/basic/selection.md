# 分子の一部を選択する

CueMol では、分子の一部分に対して操作を行うとき (一部だけ表示方法を変える、
色を塗るなど)、まずその部分を**選択**してから操作します。選択のやり方は
複数あるので、このページでまとめて練習します。
前のページ ([構造の読み込みと表示](loading.md)) の `lysozyme` を使います。

!!! info "撮影予定"
    このページには操作の流れを示すスクリーンショットを追加予定です。

選択された部分は、分子ビュー上で半透明のハイライトで強調表示されます。

## 1. ダブルクリックで選択する

分子ビューで原子をダブルクリックすると、その**残基**が選択されます。
続けて別の残基をダブルクリックすると選択に追加され、選択済みの残基を
もう一度ダブルクリックすると解除されます。

## 2. 右クリックメニューで選択する

原子の上で右クリックすると、選択に関する項目が並んだメニューが開きます。

| 項目 | 選択されるもの |
|---|---|
| **Select Atom** / **Select Residue** / **Select Chain** | クリックした原子 / 残基 / チェイン |
| **Select Molecule** | クリックした分子の全体 |
| **Add Select Atom / Residue / Chain** | 現在の選択を保ったまま追加 |
| **Unselect** | 選択をすべて解除 |
| **Invert Selection** | 選択を反転 |
| **Around** / **Around Byres** | クリックした位置の周囲 (3〜10 Å) を原子単位 / 残基単位で |

「ともかく分子全体を選択したい」ときは **Select Molecule**、
「まっさらに戻したい」ときは **Unselect** が手早い方法です。

## 3. Molecular structure パネルで選択する

残基番号や原子名から選びたいときは、左サイドパネルの
**Selection &gt; Molecular structure** パネルを使います
(→ [サイドパネル](../../ui/side-panels.md))。

1. パネル上部で対象の分子 (`lysozyme`) を選びます
2. ツリーがチェイン → 残基 → 原子の階層で表示されるので、残基 Val2 と Phe3 を
   選びます (++cmd++ / ++ctrl++ + クリックで複数選択、++shift++ + クリックで範囲選択)
3. パネルの **Select** ボタンを押すと、分子の対応する部分が選択されます

ツリーで項目を選んだだけでは、分子はまだ選択されていません。
**Select** を押して初めて選択に反映される点に注意してください。

**Center** ボタンは選んだ範囲をビュー中央へ、**Zoom** は中央に寄せたうえで
範囲の大きさに合わせて拡大します。

## 4. Selection パネルと選択ビルダー

選択を組み立てる専用パネルが、左サイドパネルの **Selection &gt; Selection**
パネルです (→ [サイドパネル](../../ui/side-panels.md))。

1. **Molecule** で対象の分子 (`lysozyme`) を選びます
2. **Selection** 欄に、その分子の**現在の選択**が選択式として表示されます。
   ここまでの手順で作った選択も、式になって入っているはずです

このパネルでの操作は分子の選択に即座に反映され、Undo で戻せます。

### 選択ビルダーで組み立てる

Selection 欄の下の**選択ビルダー**を使うと、選択式を書かずに選択を組み立てられます。
4 つのタブがあります。

- **Named** — `protein` や `water` などの定義済み選択を**クリック 1 回**で適用します
- **History** — 過去に使った式をクリックで再適用します
- **Term** — チェイン・残基番号・残基名などの条件を 1 つ作り、**Set** (置き換え) /
  **Add** (追加) / **Sub** (除外) / **Intsec** (共通部分) で現在の選択に合成します。
  値の候補は読み込んだ分子から自動で補完されます
- **Mod** — 現在の選択を変換します。**Invert** (反転) / **Byres** (残基単位に拡張) /
  **Sidech** / **Mainch** (側鎖・主鎖だけに) / **Arnd** / **Expn** (指定距離の周囲へ)

各ボタンには、適用した場合に選択される**原子数**が表示されるので、
結果を予想しながら操作できます。試しに、**Named** タブで `protein` をクリックし、
続けて **Mod** タブで **Invert** を押してみてください。タンパク質の選択が反転して、
水分子だけが選択された状態になります。

この選択ビルダーは、New Renderer の Selection 欄など、選択式を入力する
ほかの場面でも ▼ ボタンから同じものが開きます。

### 選択式を直接書く

**Selection** 欄は手で編集することもできます。たとえば、手順 3 と同じ
Val2〜Phe3 は次の式です。

```
A.2:3.*
```

「chain A の残基番号 2〜3 の全原子」という意味です。入力中に式の妥当性が
検証され、誤りがあると警告表示になります。手で入力した式は **Select** ボタンで
適用します。ビルダーで組み立てた式もこの欄にそのまま現れるので、
文法を覚える近道にもなります (→ [選択式の文法](../../reference/selection.md))。

!!! note "CueMol2 との違い"
    CueMol2 の選択パネルにあった階層型エディタ (Hierarchical / Terminal /
    Around-Expand) は、上記の**選択ビルダー**に置き換わりました。定義済み選択の
    ワンクリック適用や原子数のプレビューなど、機能は強化されています。
