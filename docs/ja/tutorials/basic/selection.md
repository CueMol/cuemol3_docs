# 分子の一部を選択する

CueMol では、分子の一部分に対して操作を行うとき (一部だけ表示方法を変える、
色を塗るなど)、まずその部分を**選択**してから操作します。選択のやり方は
複数あるので、このページでまとめて練習します。
前のページ ([構造の読み込みと表示](loading.md)) の `lysozyme` を使います。

!!! info "撮影予定"
    このページには操作の流れを示すスクリーンショットを追加予定です。

選択された部分は、分子ビュー上で半透明のハイライトで強調表示されます。

## 1. ダブルクリックで選択する

分子ビューで原子をダブルクリックすると、その**残基**が選択されます。
続けて別の残基をダブルクリックすると選択に追加され、選択済みの残基を
もう一度ダブルクリックすると解除されます。

## 2. 右クリックメニューで選択する

原子の上で右クリックすると、選択に関する項目が並んだメニューが開きます。

| 項目 | 選択されるもの |
|---|---|
| **Select Atom** / **Select Residue** / **Select Chain** | クリックした原子 / 残基 / チェイン |
| **Select Molecule** | クリックした分子の全体 |
| **Add Select Atom / Residue / Chain** | 現在の選択を保ったまま追加 |
| **Unselect** | 選択をすべて解除 |
| **Invert Selection** | 選択を反転 |
| **Around** / **Around Byres** | クリックした位置の周囲 (3〜10 Å) を原子単位 / 残基単位で |

「ともかく分子全体を選択したい」ときは **Select Molecule**、
「まっさらに戻したい」ときは **Unselect** が手早い方法です。

## 3. Molecular structure パネルで選択する

残基番号や原子名から選びたいときは、左サイドパネルの
**Selection &gt; Molecular structure** パネルを使います
(→ [サイドパネル](../../ui/side-panels.md))。

1. パネル上部で対象の分子 (`lysozyme`) を選びます
2. ツリーがチェイン → 残基 → 原子の階層で表示されるので、残基 Val2 と Phe3 を
   選びます (++cmd++ / ++ctrl++ + クリックで複数選択、++shift++ + クリックで範囲選択)
3. パネルの **Select** ボタンを押すと、分子の対応する部分が選択されます

ツリーで項目を選んだだけでは、分子はまだ選択されていません。
**Select** を押して初めて選択に反映される点に注意してください。

**Center** ボタンは選んだ範囲をビュー中央へ、**Zoom** は中央に寄せたうえで
範囲の大きさに合わせて拡大します。

## 4. 選択式で選択する

もっとも強力なのが、**選択式**を直接書く方法です。左サイドパネルの
**Selection &gt; Selection** パネルに式を入力し、**Select** を押して適用します。

たとえば、手順 3 と同じ Val2〜Phe3 は次の式で選択できます。

```
A.2:3.*
```

「chain A の残基番号 2〜3 の全原子」という意味です。入力中に式の妥当性が
検証され、誤りがあると入力欄が警告表示になります。**History** から過去に
使った式を再利用することもできます。

選択式は Renderer の表示範囲の指定や Paint の塗り分けなど、CueMol の
あらゆる場面で使います。文法の全体は
[選択式の文法](../../reference/selection.md) を参照してください。

!!! note "CueMol2 との違い"
    CueMol2 の選択パネルにあった階層型エディタ (Hierarchical / Terminal /
    Around-Expand) は CueMol3 では提供していません。選択式を直接書く方法を
    お使いください (→ [サイドパネル](../../ui/side-panels.md))。
