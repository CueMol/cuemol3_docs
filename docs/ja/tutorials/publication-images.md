# 論文用の高解像度画像を書き出す

作成したシーンを、論文や発表資料に使える品質の画像として書き出す手順を追います。
[タンパク質のリボン図を作る](ribbon-figure.md) で仕上げたシーンを題材にしますが、
どのシーンでも手順は同じです。

!!! info "撮影予定"
    このページには操作の流れを示すスクリーンショットを追加予定です。

## 1. 2 つの出力方法と使い分け

| 方法 | 特徴 | 向いている用途 |
|---|---|---|
| **Rendering &gt; Export scene &gt; PNG image...** | 画面表示と同じ描画をそのまま書き出す。速い | 作業中の記録、スライド、確認用 |
| **Rendering &gt; Image rendering...** (レンダリングウィンドウ) | レイトレーシングによる高品位な描画。陰影・輪郭線の品質が高い | 論文の図、ポスター |

まず Export scene で構図を確かめ、最終版をレンダリングウィンドウで仕上げる、
という流れが手早く確実です。

## 2. 画面のまま PNG に書き出す

**Rendering &gt; Export scene &gt; PNG image...** を選ぶと、保存先の指定に続いて
オプション画面が出ます。

- **サイズ**と**解像度 (DPI)** を指定できます
- **背景の透過**を有効にすると、背景が透明な PNG になります (スライドの重ね合わせに便利です)

そのほかの出力形式 (POV-Ray SDL / STL / MQO など) は
[Rendering メニュー](../menu/rendering.md) を参照してください。

## 3. レイトレースで仕上げる

**Rendering &gt; Image rendering...** を選ぶと、独立した**レンダリングウィンドウ**が開き、
静止画 (Still) モードになります。ウィンドウはモードレスなので、開いたまま
メインウィンドウで視点を調整できます (→ [レンダリングウィンドウ](../ui/rendering-window.md))。

1. 下部の実行バーで、**Target** にレンダリングしたいビューを選びます。
   **Backend** は既定の **Umbreon** のままで構いません
2. **Image** タブで出力サイズを選びます。プリセット (例: **1200×1200 (600dpi)**) から選ぶか、
   **Custom** で幅・高さを直接指定します
3. **Render** タブの **Quality** セクションで、**Lighting** (陰影の付け方) を
   **Raytrace only** にします。今回のようなリボン図は、これで十分きれいに仕上がります。
   **Supersampling** (基本画質) は既定のままで構いません
4. **Start** を押すとレンダリングが始まり、進捗が表示されます

!!! tip "陰影に奥行き感を出すなら Global Illumination"
    **Lighting** を **Global Illumination** (既定) にすると、大域照明による陰影づけで
    奥行き感のある仕上がりになります。ただし、リボン図のような図では効果は小さめです。
    分子表面のような込み入った形状の図で試してみてください。

各品質項目の意味と使い分けは [レンダリング](../reference/rendering.md) を参照してください。

!!! note "CueMol2 との違い"
    CueMol2 の高品位出力は外部の POV-Ray を呼び出す方式でしたが、CueMol3 では内蔵
    レイトレーサの **Umbreon** が既定になり、外部プログラムの用意もパスの設定も不要です
    (→ [レンダリングウィンドウ](../ui/rendering-window.md))。

## 4. 結果を確認して保存する

レンダリングが完了すると、結果画像がウィンドウ左上の画像領域に表示されます。

- 画像領域のツールバーの **Save** で PNG ファイルとして保存します
- **Copy** でクリップボードにコピーできます
- 矢印ボタンで過去のレンダリング結果の履歴をさかのぼれます。履歴には実行時の設定も
  一緒に記録されており、結果画像を戻すと設定も復元されます

構図や品質が気に入らなければ、メインウィンドウで調整して **Start** し直します。
設定は結果の履歴に残るので、試行錯誤しながら比較できます。

!!! warning "レンダリングウィンドウの設定は保存されません"
    ウィンドウを閉じると設定は初期値に戻り、シーンファイルにも保存されません。
    過去の設定に戻りたいときは結果の履歴を使ってください
    (→ [レンダリング](../reference/rendering.md))。

## 5. コマンドラインからの一括出力

保存済みのシーンファイル (`.qsc`) からは、GUI を使わずにコマンドラインで画像を
書き出すこともできます。多数のシーンをまとめて処理したい場合に便利です。

```sh
cuetty --input scene.qsc --render out.png --width 1920 --height 1080
```

指定できる項目やサイズ・カメラの扱いは
[レンダリング](../reference/rendering.md) を参照してください。
