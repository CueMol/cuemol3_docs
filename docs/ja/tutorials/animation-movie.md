# アニメーションを作って動画に出力する

分子の回転・視点の移動・表示の切り替えをタイムラインに並べてアニメーションを作り、
動画ファイルとして書き出すまでの流れを追います。
前半は [タンパク質のリボン図を作る](ribbon-figure.md) で仕上げたシーン (3UG9) を、
後半のモーフィングでは同梱のサンプルファイルを使います。

!!! info "撮影予定"
    このページには操作の流れを示すスクリーンショットを追加予定です。

## 1. アニメーションのしくみ

アニメーションは、**アニメーション要素** (回転・カメラ移動・表示切り替えなど) を
タイムラインに並べて構成します。1 つの要素が 1 本の帯 (ストリップ) として表示され、
帯の位置が開始時刻、長さが継続時間を表します
(→ [アニメーション](../reference/animation/index.md))。

## 2. Animation パネルを開く

3UG9 のシーンを開いた状態で、下部パネルの **Animation** タブを開きます
(→ [下部パネル](../ui/bottom-panels.md))。

## 3. 分子を回転させる

まず、分子がその場で回り続ける定番のアニメーションを作ります。

1. パネルの追加メニューから **Simple spin** を選びます
2. ストリップが追加されるので、選択して右側のインスペクタを確認します
3. **Rotation angle** (回転角) と **Spin axis** (回転軸) を調整します。
   360° にすると 1 周して元の向きに戻ります (→ [SimpleSpin](../reference/animation/simplespin.md))
4. 帯をドラッグすると開始位置を、端をドラッグすると長さ (回転にかける時間) を変えられます

## 4. 再生して確認する

パネルの再生ボタンを押すと、アニメーションが分子ビュー上で実際に再生されます。
タイムラインの現在位置をドラッグして、任意の時点の状態を確かめることもできます。

## 5. カメラモーションを加える

保存したカメラへ視点を滑らかに移動させます。全体像から注目部位へズームする、
といった演出に使います。

1. 分子ビューで始点にしたい視点に合わせ、シーンツリーの **Cameras** 行を右クリックして
   **New Camera...** で保存します (→ [カメラ](../reference/camera.md))
2. 同様に、終点にしたい視点に合わせて、もう 1 つカメラを保存します
3. タイムラインのヘッダで、**開始カメラ**に始点のカメラを指定します
4. 追加メニューから **Camera motion** を選びます
5. 追加されたストリップを選び、インスペクタの **Target camera** に終点のカメラを
   指定します (→ [CamMotion](../reference/animation/cammotion.md))

再生すると、ストリップの区間で視点が始点から終点へ補間されます。

## 6. 表示の切り替えを加える

途中でリガンドの ballstick を出現させる、といった表示の切り替えです。

1. 追加メニューから **Show** (表示) または **Hide** (非表示) を選びます
2. インスペクタで、対象の Renderer をチェックリストから選びます
   (→ [Show / Hide](../reference/animation/showhide.md))

## 7. モーフィングを加える

原子構成が同じで座標だけが異なる 2 つの構造の間を補間して、
構造変化をアニメーション化します。ここでは同梱のサンプル
(アデニル酸キナーゼの closed / open 構造、PDB 1AKE / 4AKE 由来) を使います。
次の 2 つのファイルをダウンロードしてください。

- [adk-closed.pdb.gz](../../assets/data/morphing/adk-closed.pdb.gz) (閉じた構造)
- [adk-open.pdb.gz](../../assets/data/morphing/adk-open.pdb.gz) (開いた構造)

### 構造を読み込む

1. **File &gt; New Tab** を選び、**New Scene** で新しいシーンを作ります
2. **File &gt; Open File...** で `adk-closed.pdb.gz` を開きます
3. Renderer の指定画面では **tube** を選びます

### MorphMol に変換してフレームを追加する

1. **Tools &gt; Mol morphing animation...** を開きます
2. **Target** で、読み込んだ分子を選びます
3. **Convert to MorphMol** を押します。分子が、複数のフレーム (構造) を保持できる
   **MorphMol** に変換されます
4. **Add PDB file...** を押し、`adk-open.pdb.gz` を選びます
5. フレームの一覧に、元の構造 (`(this)`) と追加した構造が並んだことを確認して、
   ダイアログを閉じます

### タイムラインに載せて再生する

1. Animation パネルの追加メニューから **Mol morphing** を選びます
2. 追加されたストリップを選び、インスペクタの **Target MorphMol** で
   変換した分子を指定します (→ [MolAnim](../reference/animation/molanim.md))
3. 再生すると、閉じた構造と開いた構造の間で分子が変形します

!!! note "自分の構造でモーフィングを作るには"
    フレームに追加する構造は、元の構造と**原子の数・並びが一致**している必要があります。
    水・リガンド・水素や、片方にしかない原子をあらかじめ取り除いて揃えてください。

!!! note "CueMol2 との違い"
    CueMol2 ではメニューを選ぶと対象の選択プロンプトが出て、暗黙のうちに MorphMol へ
    変換されましたが、CueMol3 ではダイアログ内の **Target** で対象を選び、
    **Convert to MorphMol** ボタンで明示的に変換します (Undo で戻せます)。

## 8. 動画に出力する

**Rendering &gt; Movie rendering...** を選ぶと、レンダリングウィンドウが
動画 (Movie) モードで開きます (→ [レンダリングウィンドウ](../ui/rendering-window.md))。

1. **Target** に対象のビューを選びます。**Backend** は既定の **Umbreon** のままで構いません
2. **Image** タブでサイズ (例: **HD1080 (1920×1080)**) を選びます
3. **Start** を押すと、フレームを 1 枚ずつレンダリングし、完了すると
   ffmpeg で動画ファイルにエンコードされます (macOS / Windows の配布物には同梱、
   → [外部ツールの設定](../install/external-tools.md))
4. 出力は既定では一時フォルダに作られます。**Save movie as...** で
   完成した動画を好きな場所に保存します

フレームレートや動画形式などの出力設定は次回も記憶されます。
品質を上げたいときの設定は静止画と共通です
(→ [論文用の高解像度画像を書き出す](publication-images.md))。
