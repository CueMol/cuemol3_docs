# カメラとシーンの保存

気に入った視点を**カメラ**として残す方法と、作業状態全体を**シーンファイル**
(`.qsc`) に保存して再開する方法を学びます。
前のページ ([Renderer を着色する](basics-coloring.md)) の続きから始めます。

!!! info "撮影予定"
    このページには操作の流れを示すスクリーンショットを追加予定です。

## 1. カメラで視点を保存する

分子を見ているうちに「この視点を後でもう一度見たい」ということがよくあります。
視点の位置・向き・ズーム・スラブは、**カメラ**として名前を付けて保存できます。

1. 視点を保存したい状態に合わせます
2. シーンツリーの **Cameras** 行を右クリックし、**New Camera...** を選びます
3. 名前を付けて作成します (既定の名前のままでも構いません)

作成したカメラは Cameras の下に並びます。視点を適当に動かしてから、
カメラ行を**ダブルクリック**してみてください。保存した視点に戻ります。

カメラ行の右クリックメニューからは、名前の変更・削除・コピー &amp; ペースト・
カメラファイル (`.cam`) の読み書き・表示フラグの編集などができます
(→ [カメラ](../reference/camera.md))。

## 2. シーンを保存する

シーン全体 (Object・Renderer・色・カメラ) は **File &gt; Save Scene**
(++cmd+s++ / ++ctrl+s++) で `.qsc` ファイルに保存します。
ここでは `tutorial1.qsc` という名前で保存してください。

保存時には、そのときの視点が `__current` という名前のカメラとして自動で
記録されます。シーンを開くとこのカメラが適用されるので、保存したときの
見た目がそのまま再現されます。

!!! note "リンクと埋め込み"
    `.qsc` には、読み込んだデータファイルへの**リンク**を保存するか、データそのものを
    **埋め込む**かを保存オプションで選べます (→ [File メニュー](../menu/file.md))。
    リンクの場合、元のファイルを移動・削除するとシーンが開けなくなります。
    ネットワークから取得した Object のように元ファイルがないものは埋め込まれます。
    ファイル単体で持ち運びたいときは埋め込みが確実です。

## 3. シーンを読み込む

いったん CueMol3 を終了して起動し直し、**File &gt; Open Scene...** で
`tutorial1.qsc` を開いてみてください。保存した状態がそのまま復元されます
(**File &gt; Open Recent** からも開けます)。

## 4. 複数のシーンをタブで扱う

シーンはウィンドウ上部の**タブ**に対応しており、複数を同時に開けます。
各シーンは独立していて、互いに干渉しません。

1. **File &gt; New Tab** (++cmd+t++) を選び、**New Scene** で新しいシーンを作ります
2. 新しいシーンは空なので、何も表示されません
3. **File &gt; Get PDB...** で `1EHZ` (tRNA の構造) を取得し、**Renderer type** に
   核酸向けの **nucl** を選びます
4. タブをクリックすると、シーンを行き来できます。シーンツリーの内容も
   そのタブのシーンに切り替わります

### タブを閉じる

タブの閉じるボタン (または **File &gt; Close Tab**) でシーンを閉じます。
未保存の変更があるシーンでは、保存するかどうかの確認が表示されます
(→ [File メニュー](../menu/file.md))。

## 5. 同じシーンをもう 1 つの視点で見る

**File &gt; New Tab** で **New View** を選ぶと、新しいシーンではなく、
**現在のシーンを映すもう 1 つのビュー**がタブとして作られます
(現在のカメラを引き継ぐかどうかも選べます)。

どちらのタブで操作してもシーンは共通なので、選択や色の変更は両方に反映されます。
一方、視点はビューごとに独立しているため、2 つの見方を素早く切り替えられます。
視点そのものを残したい場合は、ビューよりもカメラの方が適しています
(カメラはシーンファイルに保存されます)。
