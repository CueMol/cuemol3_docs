# File メニュー

シーンと Object の読み書き、およびタブ操作を行います。

## タブ

| 項目 | 説明 | ショートカット |
|---|---|---|
| New Tab | 新しいタブを作ります。ダイアログで **New Scene** (新規シーン) か **New View** (既存シーンの別ビュー) を選びます。New Scene では新しいシーンの表示設定 (**Scene settings**: Anti-aliasing / Ambient occlusion / Background / CMYK color proofing) も指定でき、確定した値が以後の新しいシーン (起動時やファイルのドロップで作られるものを含む) の既定になります。New View では現在のカメラを引き継ぐかどうかも指定できます | ++cmd+t++ |
| Close Tab | 現在のタブを閉じます。シーンが未保存で、そのシーンを表示しているビューが 1 つだけの場合は、保存するかどうかを確認します | ++cmd+w++ |

## Object の読み込み

| 項目 | 説明 | ショートカット |
|---|---|---|
| Open File... | 分子座標・密度マップ・分子表面などのファイルを開きます。読み込み時に Renderer の種類や形式ごとのオプションを指定できます | ++cmd+o++ |
| Open MD Trajectory... | MD シミュレーションのトラジェクトリを開きます *(CueMol3 で追加)* | |
| Get PDB... | PDB ID を指定して構造をネットワークから取得します。座標 (RCSB の CIF / PDB) と密度マップ (RCSB の cif.gz、EBI の MTZ) に対応します。一時ファイルを介さずに直接読み込み、進捗ダイアログの Cancel で中断できます | |
| Open Recent | 最近開いたファイルの一覧 (最大 10 件) から選んで開きます。**Clear Menu** で履歴を消去します | |

読み込める形式の一覧は [対応ファイル形式](../getting-started/index.md#対応ファイル形式) を参照してください。

拡張子だけでは形式が決まらないファイル (`.cif` のように複数の形式が同じ拡張子を使うもの) は、
**中身を読んで形式を判別**します。最近の PDB の mmCIF のように、ヘッダが長く座標が数百 KB 先から
始まるファイルも開けます。

CCP4/MRC の密度マップを開くときは、オプション画面に格子の大きさと、読み込んだときに
必要なメモリ量が表示されます。**Map type** で結晶学的マップとクライオ電子顕微鏡マップの
どちらとして扱うかを指定でき (既定は *Auto (from header)*、ファイルのヘッダから判別)、
**Subsample** で格子を間引いて読み込めます
(→ [DensityMap](../reference/objects/densitymap.md#マップの種類-map-type))。
格子点が多すぎるマップでは警告が出て、メモリに収まる **Subsample** の値が提案されます。
**Subsample** は読み込むときに格子点を捨てるので、あとから細かくすることはできません。
**Map type** と **Subsample** が表示されるのは CCP4/MRC を開くときだけです。ほかの形式の
マップでは、読み込んだあとにインスペクタで Map type を変えられます。

密度マップを開くときは、Renderer のオプションに原子選択の代わりに **View after loading**
が表示されます。*Auto (by map kind)* (既定) は、クライオ電子顕微鏡マップではマップ全体が
収まるように視点を動かし (*Move view center (fit the map)*)、結晶学的マップでは視点を
動かさずにマップの表示中心を現在のビュー中心に合わせます (*Set map center (keep the view)*)。
どちらの動作も明示的に選べます。

メニューを使わずに、ファイルを **OS からウィンドウにドラッグ &amp; ドロップ**しても開けます
(開けない種類のファイルは、ドロップする前に受け付けを拒否します)。ファイルマネージャで
ダブルクリックしたり、コマンドラインで渡したりして開くこともできます
(→ [ファイルの関連付け](../install/index.md#ファイルの関連付け))。

## Object の保存

| 項目 | 説明 | ショートカット |
|---|---|---|
| Save File As... | シーンではなく **Object 単体**をファイルに保存します。対象になるのは対応する保存形式を持つ Object だけで、それが 2 つ以上ある場合は対象を選ぶ画面が出ます。保存形式は前回使ったものが次回の既定になります | |
| Save current view... | 現在のビューのカメラを `.cam` ファイルに保存します | |

## シーンの読み書き

| 項目 | 説明 | ショートカット |
|---|---|---|
| Open Scene... | CueMol シーンファイル (`.qsc`) を開きます。PyMOL セッション (`.pse`) もここから読み込めます。 | ++cmd+shift+o++ |
| Reload Scene | シーンを元のファイルから読み込み直します。未保存の変更がある場合は先に確認します。 | ++cmd+r++ |
| Save Scene | シーンを上書き保存します。保存先が未設定の場合は Save Scene As... と同じ動作になります。上書き前に `<ファイル名>.bak` のバックアップが自動で作成されます。 | ++cmd+s++ |
| Save Scene As... | 保存先を指定してシーンを保存します。保存オプション (データの埋め込み / 互換性 / 圧縮 / 文字エンコーディング) を指定できます。 | ++cmd+shift+s++ |

## 終了

| 項目 | 説明 | ショートカット |
|---|---|---|
| Quit | CueMol3 を終了します。未保存のシーンがあるタブについて保存するかを確認し、キャンセルすると終了を中止します。**Windows / Linux のみ** (macOS ではアプリケーションメニューにあります) | ++ctrl+q++ |

!!! note "ウィンドウの閉じるボタンも同じ確認を通ります"
    ウィンドウ右上 (macOS では左上) の閉じるボタンと ++cmd+q++ は同じ確認処理を共有しています。
