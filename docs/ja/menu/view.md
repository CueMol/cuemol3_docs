# View メニュー

分子ビューの投影方式や中心マークなど、ビュー単位の設定を扱います。

## 投影方式

| 項目 | 説明 | ショートカット |
|---|---|---|
| Perspective | 透視投影に切り替えます。現在の投影方式にチェックが付きます | |
| Orthographic | 平行投影に切り替えます。現在の投影方式にチェックが付きます | |

## 中心マーク

回転中心を示すマークの表示方法を選びます。

| 項目 | 説明 | ショートカット |
|---|---|---|
| Center mark &gt; Cross | 十字マークを表示します | |
| Center mark &gt; Axis | 座標軸を表示します | |
| Center mark &gt; None | 中心マークを表示しません | |

## ビューのプロパティ

| 項目 | 説明 | ショートカット |
|---|---|---|
| View property... | 現在のビューを [プロパティインスペクタ](../ui/inspector.md) の Generic タブで開きます | |

## 開発者向け

| 項目 | 説明 | ショートカット |
|---|---|---|
| Toggle Developer Tools | 開発者ツールを開閉します。不具合の調査時に使います | |

!!! tip "サイドパネルからも操作できます"
    投影方式と中心マークは、左サイドパネルの **Explorer &gt; View** からも切り替えられます。
    このパネルでは回転・平行移動・ズーム・スラブなどの視点操作も数値で行えます
    (→ [サイドパネル](../ui/side-panels.md))。

!!! info "ハードウェアステレオは廃止されました"
    CueMol2 にあった View &gt; Hardware stereo は CueMol3 では提供していません
    (→ [機能の統合・改名・廃止](../changes/features.md))。
