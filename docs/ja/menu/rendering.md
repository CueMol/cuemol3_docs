# Rendering メニュー

高品位な画像・動画の出力と、シーンの各種形式へのエクスポートを行います。

## レンダリングウィンドウを開く

| 項目 | 説明 | ショートカット |
|---|---|---|
| Image rendering... *(CueMol3 で改名)* | レンダリングウィンドウを開き、**静止画 (Still) モード**にします | |
| Movie rendering... *(CueMol3 で改名)* | レンダリングウィンドウを開き、**動画 (Movie) モード**にします | |

!!! info "CueMol2 からの変更"
    CueMol2 では「POV-Ray rendering...」「Animation rendering...」という、レンダラの名前を冠した
    別々のウィンドウでした。CueMol3 では 1 つの**レンダリングウィンドウ**に統合され、
    メニュー項目は**出力の種類**(静止画 / 動画)を表すようになっています。
    レンダリングバックエンド (Umbreon / POV-Ray) はウィンドウ内で選びます。

    レンダリングウィンドウはモードレス (非モーダル) なので、開いたまま 3D ビューを操作できます。
    詳細は [レンダリングウィンドウ](../ui/rendering-window.md) を参照してください。

    ツールバーの **Render** ボタンも同じウィンドウを開きますが、モードは切り替えません。

## Export scene

現在のシーンを各種ファイル形式に書き出します。サブメニューから形式を選びます。

| 項目 | 説明 |
|---|---|
| PNG image... | 画面表示と同じ描画で PNG 画像を書き出します。サイズ・解像度 (DPI)・背景の透過を指定できます |
| Umbreon ray-traced image... | 内蔵レイトレーサ Umbreon でレイトレースした PNG を書き出します。オプションは PNG image... と共通です |
| POV-Ray SDL... | POV-Ray のシーン記述ファイル (`.pov`) を書き出します。同じ場所に `.inc` ファイルも生成されます |
| STL... | STL 形式 (`.stl`) の形状データを書き出します |
| Metasequoia (MQO)... | Metasequoia のオブジェクトファイル (`.mqo`) を書き出します |

!!! note "表示されない項目がある場合"
    使用中のライブラリに組み込まれていないエクスポータの項目は、起動時の判定により
    **サブメニューから非表示**になります。たとえば `HAVE_UMBREON` を有効にしていないビルドでは
    **Umbreon ray-traced image...** が表示されません。

    CueMol2 にあった LuxRender / Warabi / raw 形式 / QSL への書き出しは CueMol3 では提供していません。
