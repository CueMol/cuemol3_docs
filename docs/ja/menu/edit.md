# Edit メニュー

操作の取り消し、クリップボード、分子構造の編集、アプリケーション設定を扱います。

## 取り消し・やり直し

| 項目 | 説明 | ショートカット |
|---|---|---|
| Undo | 直前の操作を取り消します。取り消せる操作がないときは選べません | ++cmd+z++ |
| Redo | 取り消した操作をやり直します。やり直せる操作がないときは選べません | macOS: ++cmd+shift+z++ / Windows・Linux: ++ctrl+y++ |

!!! tip "複数ステップをまとめて戻す"
    ツールバーの Undo / Redo ボタンには履歴のドロップダウンが付いており、
    数ステップ前までまとめて戻せます (→ [ツールバーとツールパレット](../ui/toolbar-tools.md))。

## クリップボード

| 項目 | 説明 | ショートカット |
|---|---|---|
| Cut | 選択中のテキストを切り取ります | ++cmd+x++ |
| Copy | 選択中のテキストをコピーします | ++cmd+c++ |
| Paste | クリップボードの内容を貼り付けます | ++cmd+v++ |
| Select All | 入力欄にフォーカスがあればその中を、なければアクティブな選択可能領域 (Output パネルのログなど) を全選択します | ++cmd+a++ |

!!! note
    これらはテキスト入力欄などに対する OS 標準の編集操作です。
    シーンツリー上の Object や Renderer のコピー &amp; ペーストは、
    シーンツリーの右クリックメニューから行います。

## 履歴の消去

| 項目 | 説明 | ショートカット |
|---|---|---|
| Clear undo data <span class="badge-wip">開発中</span> | Undo 履歴を破棄します。**現在のバージョンでは動作しません** | |

## 分子構造の編集

いずれもツールダイアログを開きます。

| 項目 | 説明 | ショートカット |
|---|---|---|
| Merge molecule... | 2 つの分子 Object を 1 つに統合します | |
| Delete mol atoms... | 選択した原子を分子から削除します | |
| Change chain ID... | チェイン ID を変更します | |
| Change residue number... | 残基番号を変更します | |

## 設定

| 項目 | 説明 | ショートカット |
|---|---|---|
| Options | Settings タブを開きます (すでに開いていればそのタブに切り替えます)。**Windows / Linux のみ** (macOS ではアプリケーションメニューの Preferences...) | ++ctrl+k++ |

!!! info "設定はダイアログではなくタブです"
    CueMol2 の Options はモーダルのプリファレンスウィンドウでしたが、CueMol3 ではコンテンツ領域の
    タブとして開きます。設定を見ながら分子ビューを操作できます。
    左端アクティビティバー下部の歯車アイコンからも開けます。
