# Edit メニュー

操作の取り消し、クリップボード、分子構造の編集、アプリケーション設定を扱います。

## 取り消し・やり直し

| 項目 | 説明 | ショートカット |
|---|---|---|
| Undo | 直前の操作を取り消します。取り消せる操作がないときは選べません | ++cmd+z++ |
| Redo | 取り消した操作をやり直します。やり直せる操作がないときは選べません | macOS: ++cmd+shift+z++ / Windows・Linux: ++ctrl+y++ |

ショートカットはフォーカスのある場所を見ます。テキスト入力欄で打ち間違いを
++cmd+z++ で戻しても、シーンの操作は巻き戻りません。ツールバーの Undo / Redo
ボタンは、フォーカスによらず常にシーンに作用します。

!!! tip "複数ステップをまとめて戻す"
    ツールバーの Undo / Redo ボタンには履歴のドロップダウンが付いており、
    数ステップ前までまとめて戻せます (→ [ツールバーとツールパレット](../ui/toolbar-tools.md))。

## クリップボード

| 項目 | 説明 | ショートカット |
|---|---|---|
| Cut | 選択中のものを切り取ります | ++cmd+x++ |
| Copy | 選択中のものをコピーします | ++cmd+c++ |
| Paste | クリップボードの内容を貼り付けます | ++cmd+v++ |
| Select All | 入力欄にフォーカスがあればその中を、なければアクティブな選択可能領域 (Output パネルのログなど) を全選択します | ++cmd+a++ |

Cut / Copy / Paste は、**フォーカスのある場所によって対象が変わります**。

| フォーカス | 対象 |
|---|---|
| テキスト入力欄 | 入力中のテキスト (OS 標準の編集操作) |
| シーンツリー | Object / Renderer / Renderer グループ / カメラ / スタイルセットのノード |
| Color パネルの Paint 表 | 表の行 |

シーンツリーの **Cut** は CueMol3 で追加されたものです。クリップボードへの書き出しが
済んでから削除するため、書き出しに失敗しても選択が消えることはなく、削除は 1 回の
Undo で戻せます。シーンツリーの右クリックメニューからも同じ操作を行えます。

!!! info "CueMol2 とコピー &amp; ペーストをやりとりできます"
    コピーは OS のクリップボードを経由します。Renderer / Renderer グループ / Object /
    カメラ / スタイル / Paint の行を CueMol3 でコピーして CueMol2 に貼り付ける、
    またはその逆ができます。貼り付け時に選択範囲と色が貼り付け先のシーンに対して
    解決し直されるため、別の Renderer や別のシーンへの貼り付けも行えます。

    OS のクリップボードを使うことによる副作用が 2 つあります。CueMol3 でコピーすると
    テキストのクリップボードが置き換わること、そして他のアプリケーションでコピーすると
    それまでのコピーが失われることです。

## 履歴の消去

| 項目 | 説明 | ショートカット |
|---|---|---|
| Clear undo data | Undo 履歴を破棄します。Undo / Redo の状態も更新されます | |

## 分子構造の編集

いずれもツールダイアログを開きます。

| 項目 | 説明 | ショートカット |
|---|---|---|
| Merge molecule... | 2 つの分子 Object を 1 つに統合します | |
| Delete mol atoms... | 選択した原子を分子から削除します | |
| Change chain ID... | チェイン ID を変更します | |
| Change residue number... | 残基番号を変更します | |

## 設定

| 項目 | 説明 | ショートカット |
|---|---|---|
| Options | Settings タブを開きます (すでに開いていればそのタブに切り替えます)。**Windows / Linux のみ** (macOS ではアプリケーションメニューの Preferences...) | ++ctrl+k++ |

!!! info "設定はダイアログではなくタブです"
    CueMol2 の Options はモーダルのプリファレンスウィンドウでしたが、CueMol3 ではコンテンツ領域の
    タブとして開きます。設定を見ながら分子ビューを操作できます。
    左端アクティビティバー下部の歯車アイコンからも開けます。
