# Scene メニュー

シーン全体に関わる設定を扱います。

| 項目 | 説明 | ショートカット |
|---|---|---|
| Background &gt; White | 背景色を白にします。現在の背景色に応じてチェックが付きます | |
| Background &gt; Black | 背景色を黒にします。現在の背景色に応じてチェックが付きます | |
| Use color proofing | カラープルーフィング (CMYK 出力の色再現シミュレーション) の有効・無効を切り替えます。ICC プロファイルが未設定の状態で有効にすると既定のプロファイルが割り当てられ、無効にしてもプロファイルの設定は保持されます | |
| Properties... | 現在のシーンをプロパティインスペクタで開きます | |

!!! tip "背景色は右クリックメニューからも変更できます"
    シーンツリーのシーン行を右クリックすると、Background のサブメニューと
    Use color proofing のチェック項目が同じように使えます。

!!! info "Properties... で編集できる項目"
    シーンの Properties は CueMol2 のようなモーダルダイアログではなく、
    [プロパティインスペクタ](../ui/inspector.md) の Properties タブに表示されます。
    アンビエントオクルージョン / アンチエイリアシング / 背景 / カラープルーフィングの設定があり、
    変更は 3D ビューに即座に反映されます。

    任意の背景色を指定したい場合もこちらから設定します
    (メニューの Background は白 / 黒の切り替え専用です)。
