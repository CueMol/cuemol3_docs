止まった分子の図では、どれが手前でどれが奥なのかが伝わりにくいものです。
視点を少し揺らすだけで、奥行きがぐっと読み取りやすくなります。
**RockSpin** は、この揺れをアニメーションの要素 1 つで作る機能です。PyMOL や ChimeraX の
rock / nutate / wobble にあたる動きを、Animation パネルから追加するだけで再生できます。

## 3 つの揺れ方

| Pattern | 動き |
|---|---|
| **Rock** | 軸のまわりに左右に揺れる (既定) |
| **Nutate** | 視線が円を描くように回る |
| **Wobble** | 8 の字を描くように揺れる |

## 使ってみる

1. 分子を表示し、見せたい向きに合わせます。
2. 下部パネルの **Animation** タブを開き、左の列の **Add element** (+) から **Rock** を選びます。
3. ヘッダの **Play** を押します。既定では、Y 軸 (画面の縦) のまわりに左右 15° ずつ、1 秒で 1 往復します。
4. 帯を選ぶと、右側のインスペクタに設定が表示されます。**Pattern** で揺れ方を、
   **Swing angle** で振れ幅を、**Cycles** で繰り返しの回数を変えられます。
   ゆっくり揺らしたいときは、**Duration** で要素の長さを延ばします。
5. ヘッダの **Loop** を ON にすると、繰り返し再生します。Cycles が整数なら要素の終わりで
   元の視点に戻るので、継ぎ目なく揺れ続けます。

ChX console の `rock` / `wobble` や、PyM console の `movie.rock` / `movie.nutate` などからも、
同じ RockSpin の要素を追加できます。
動画として書き出せば、発表のスライドや SNS にもそのまま使えます。
