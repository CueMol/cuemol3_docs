# CueMol2 からの変更点

CueMol3 は可視化エンジン (libcuemol2) を CueMol2 と共有しており、シーンファイル (`.qsc`) の
互換性も保たれています。一方で **GUI は全面的に作り直され**、Mozilla XULRunner ベースから
Electron + React ベースになりました。その結果、操作の流儀が大きく変わっています。

## 最重要の変更点

| # | 変更点 | 内容 | 詳細 |
|---|---|---|---|
| 1 | **シングルウィンドウ + タブ** | 機能ごとに別ウィンドウが開くことはなくなり、シーンやビューはタブとして並びます。File &gt; New Window は廃止 (New Tab を使用) | [画面構成](../ui/index.md) |
| 2 | **インスペクタでライブ編集** | レンダリングの設定は種類ごとのモーダルダイアログではなく、常設のプロパティインスペクタで編集します。値を変えた瞬間に分子ビューへ反映され、取り消しは Undo | [プロパティインスペクタ](../ui/inspector.md) |
| 3 | **レンダリングウィンドウの統合** | 「POV-Ray rendering」「Animation rendering」の 2 つのダイアログが 1 つのモードレスなレンダリングウィンドウに統合され、静止画 / 動画をモードで切り替えます | [レンダリングウィンドウ](../ui/rendering-window.md) |
| 4 | **ツールバーとツールパレット** | 上部のツールバー (即実行するコマンド) と、分子ビュー左端のツールパレット (操作モードの切り替え) に分かれました | [ツールバーとツールパレット](../ui/toolbar-tools.md) |
| 5 | **計測・結合編集のツール化** | 距離 / 角度 / 二面角の計測と結合の追加は、ダイアログではなく分子ビューを直接クリックするツールになりました | [ツールバーとツールパレット](../ui/toolbar-tools.md) |
| 6 | **Animation パネルの新設** | CueMol2 のアニメーション編集は一覧とモーダルの設定ダイアログで、グラフィカルなタイムラインはありませんでした。CueMol3 では下部パネルの Animation タブに、1 要素 = 1 本の帯として並べるストリップ形式のタイムラインが新設されました | [下部パネル](../ui/bottom-panels.md) |
| 7 | **選択 UI の刷新** | 選択式を入力するあらゆる場所 (Selection パネル、New Renderer やツール類のダイアログ、Paint の選択セルなど) で、妥当性の検証・履歴に加えて GUI で選択を組み立てる選択ビルダーが使えるようになりました | [選択ビルダー](../ui/selection-builder.md) |
| 8 | **Options → Settings タブ** | 設定はモーダルのプリファレンスウィンドウではなく、コンテンツ領域のタブとして開きます | [外部ツールの設定](../install/external-tools.md) |

## 変わらないもの

- **シーンファイル (`.qsc`) の互換性**: CueMol2 で作ったシーンを CueMol3 で開けます。
- **可視化エンジン**: Renderer の種類、選択式の文法、対応ファイル形式は共通です。
