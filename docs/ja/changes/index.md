# CueMol2 からの変更点

CueMol3 は可視化エンジン (libcuemol2) を CueMol2 と共有しており、シーンファイル (`.qsc`) の
互換性も保たれています。一方で **GUI は全面的に作り直され**、Mozilla XULRunner ベースから
Electron + React ベースになりました。その結果、操作の流儀が大きく変わっています。

## 最重要の変更点

| # | 変更点 | 内容 | 詳細 |
|---|---|---|---|
| 1 | **シングルウィンドウ + タブ** | 機能ごとに別ウィンドウが開くことはなくなり、シーンやビューはタブとして並びます。File &gt; New Window は廃止 (New Tab を使用) | [画面構成](../ui/index.md) |
| 2 | **インスペクタでライブ編集** | レンダリングの設定は種類ごとのモーダルダイアログではなく、常設のプロパティインスペクタで編集します。値を変えた瞬間に 3D ビューへ反映され、取り消しは Undo | [プロパティインスペクタ](../ui/inspector.md) |
| 3 | **レンダリングウィンドウの統合** | 「POV-Ray rendering」「Animation rendering」の 2 つのダイアログが 1 つのモードレスなレンダリングウィンドウに統合され、静止画 / 動画をモードで切り替えます | [レンダリングウィンドウ](../ui/rendering-window.md) |
| 4 | **ツールバーとツールパレット** | 上部のツールバー (即実行するコマンド) と、3D ビュー左端のツールパレット (操作モードの切り替え) に分かれました | [ツールバーとツールパレット](../ui/toolbar-tools.md) |
| 5 | **計測・結合編集のツール化** | 距離 / 角度 / 二面角の計測と結合の追加は、ダイアログではなく 3D ビューを直接クリックするツールになりました | [ツールバーとツールパレット](../ui/toolbar-tools.md) |
| 6 | **ホイール = ズーム + トラックパッド対応** | ホイールでズームします。トラックパッドの 2 本指スクロール / ピンチにも対応し、デバイスの自動判別が既定です | [マウス・トラックパッド操作](../ui/mouse-input.md) |
| 7 | **タイムラインの刷新** | アニメーション編集がキーフレーム方式から、1 要素 = 1 本の帯というストリップ形式のタイムラインになりました | [下部パネル](../ui/bottom-panels.md) |
| 8 | **カラーピッカーの刷新** | 色の選択画面が刷新され、CueMol2 のカラーメニューのプリセットはカラーピッカーの Palette パネルに統合されました | |
| 9 | **選択 UI の刷新** | 選択式の入力欄に妥当性の検証と履歴が付き、階層から選択を組み立てるポップオーバーが追加されました | [サイドパネル](../ui/side-panels.md) |
| 10 | **Options → Settings タブ** | 設定はモーダルのプリファレンスウィンドウではなく、コンテンツ領域のタブとして開きます | [外部ツールの設定](../install/external-tools.md) |

## 変わらないもの

- **シーンファイル (`.qsc`) の互換性**: CueMol2 で作ったシーンを CueMol3 で開けます。
- **可視化エンジン**: レンダラの種類、選択式の文法、対応ファイル形式は共通です。
