# 開発状況と未実装機能

!!! warning "このページは 2026-08-10 時点のスナップショットです"
    CueMol3 は開発が進行中です。ここに書かれている「動作しません」が、
    お使いのバージョンではすでに解消されている場合があります。

CueMol3 は **dev / internal 配布のみ**で、一般利用向けの正式リリースはまだありません。
安定した動作が必要な場合は CueMol2 をご利用ください
(→ [インストール](../install/index.md))。

## メニューにあるが動作しない項目

メニューには表示されますが、選んでも何も起こりません。

| メニュー項目 | 内容 |
|---|---|
| Edit &gt; Clear undo data | Undo 履歴の破棄 |
| Tools &gt; Mol morphing animation... | 2 構造間のモーフィングアニメーションの作成 |
| Tools &gt; Performance measure | 描画性能の計測 |

ツールバーの **Save** ボタンも現在は動作しません。シーンの保存には **Save Scene** ボタン、
または File &gt; Save Scene をお使いください。

## 一部のみ実装されている機能

| 機能 | 現状 |
|---|---|
| **レンダラ種類ごとの詳細設定** | プロパティインスペクタの Properties タブには共通設定 (Common) のセクションがあり、一部のレンダラ種類には専用のセクションがあります。それ以外の種類固有の設定は **Generic** タブから編集してください |
| **Multi-gradient の塗り分け** | Color パネルの塗り分け方式のうち Multi-gradient は選択できません |
| **Generic タブの入力欄** | 色 / ベクトル / 時刻の値については専用の入力ウィジェットが未整備です |
| **密度マップの Multi-gradient 表示** | Density map パネルでは単色のみ設定できます |
| **スタイルの適用・作成ダイアログ** | Edit style / Create style の動作に不具合が報告されています (調査中) |
| **シーンツリーの範囲選択** | ++shift++ + クリックによる連続選択は未実装です (++cmd++ / ++ctrl++ + クリックの複数選択は動作します) |
| **対称分子の生成 (Create SYMM mol)** | 分子ビューの右クリックメニューからの実行は未実装です。Crystal &gt; Symmetry パネルの **Symm mol** をお使いください |
| **コード署名** | macOS はアドホック署名のみ (Developer ID 署名・notarization なし)、Windows は未署名です。いずれも初回起動時に手動での回避操作が必要です → [インストール](../install/index.md#配布物の署名状況) |

## 既知の問題

| 症状 | 内容 |
|---|---|
| **Sequence パネルの選択反映が遅い** | 配列パネルで選択を変えてから分子ビューのハイライトが更新されるまで、体感で 0.5 秒ほどの遅れが出ることがあります |
| **Molecular structure パネルの初回展開が重い** | ツリーを最初に展開したときに引っかかりを感じることがあります (残基数が多くなくても発生します) |
| **ポインティングデバイスの自動判別の誤り** | スクロールの特徴からの推定のため、マウスとトラックパッドを取り違える場合があります。Settings で明示的に指定してください |

## 動作を確認できている主な機能

参考として、実装が完了している主な範囲を挙げます。

- ファイル / シーンの読み書き、Get PDB によるネットワーク取得、最近使ったファイル
- シーンツリー (表示切り替え / 名前変更 / 並べ替え / 複数選択 / 右クリックメニュー)
- レンダラの作成 (プリセットを含む) と、インスペクタでの設定編集
- 塗り分け (Solid / Paint / CPK / Rainbow / B-factor / 静電ポテンシャル)
- 選択 (選択式・分子構造ツリー・配列パネル・矩形 / 投げ縄ツール)
- 計測 (距離 / 角度 / 二面角) と結合の追加・削除
- 分子表面の生成・切断・再生成、相互作用解析、二次構造の再割り当て、分子の重ね合わせ
- 対称性の変更と対称分子・単位格子の表示、密度マップの表示調整
- APBS による静電ポテンシャル計算 (外部ツールの設定が必要)
- アニメーションのタイムライン編集と再生
- レンダリングウィンドウでの静止画・動画出力 (Umbreon / POV-Ray)
- Export scene (PNG / Umbreon / POV-Ray SDL / STL / MQO)
