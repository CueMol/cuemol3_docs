# サイドパネル

ウィンドウ左側のサイドパネルは、左端の**アクティビティバー**で用途を切り替えます。
選択中のアイコンをもう一度クリックするとサイドパネルが閉じます。

## アクティビティバーの構成

| アイコン | ビュー | 含まれるパネル |
|---|---|---|
| Explorer | シーンの構成と表示設定 | Scene / Color / View |
| Selection | 分子の選択 | Molecular structure / Selection |
| Crystal | 結晶学的な情報 | Symmetry / Density map |
| Component Catalog | UI 部品のカタログ (開発用) | |
| 歯車 (最下部) | Settings タブを開きます (サイドパネルではありません) | |

## Explorer

### Scene パネル (シーンツリー)

シーンの内容をツリーで表示します。CueMol2 のワークスペースパネルに相当します。

- **ノードの種類**: シーン / Object / Renderer / Renderer グループ / カメラ / スタイルセット
- **表示の切り替え**: 各行の目のアイコンで表示・非表示を切り替えます。
  上位のノードが非表示のために描かれていない行は、アイコンがグレー表示になります。
- **選択**: クリックで選択、++cmd++ / ++ctrl++ + クリックで複数選択できます。
- **名前の変更**: 行をゆっくり 2 回クリック、または ++f2++ でその場で名前を編集します。
- **並べ替え**: ドラッグ &amp; ドロップで順序やグループへの所属を変更できます。
- **ダブルクリック**: カメラ行ではそのカメラをビューに適用します。その他の行では
  [プロパティインスペクタ](inspector.md) に内容を表示します。
- **右クリック**: ノードの種類ごとのメニューが開きます (下記)。

パネル上部のツールバーには **Add** / **Focus** / **Delete** / **Property** のボタンがあります。
複数選択中は Focus と Property は使えません。

#### 右クリックメニューの主な操作

| 対象 | 主な操作 |
|---|---|
| シーン | 背景色 (White / Black)、カラープルーフィングの切り替え、Object の貼り付け |
| Object | 選択範囲の指定、コピー &amp; ペースト、Renderer / Renderer グループの新規作成、色の設定、Save As、分子表面の再生成 |
| Renderer | コピー、色の設定、スタイルの適用・作成・編集、選択範囲の変更、表面 Object の生成、Renderer 種類の変更、相互作用リストの編集 |
| Renderer グループ | 表示・非表示 (メンバーに連動)、名前の変更、コピー &amp; ペースト、Renderer の新規作成 |
| カメラ | 新規作成 / 名前の変更 / 削除 / コピー &amp; ペースト、カメラファイルの読み書き、ビューへの適用、表示フラグの編集 |
| スタイルセット | 新規作成 / コピー &amp; ペースト / 削除、読み取り専用の切り替え、ファイルの読み書き、スタイルエディタ |

#### Renderer の新規作成

Object 行や Renderer グループ行の右クリックメニューの **New Renderer** から、
Renderer の種類と対象を選んで作成します。

- **プリセット**を選ぶと、あらかじめ定義された複数の Renderer をまとめたグループが一度に作られます。
- 作成は**既定値で即座に**行われ、細かい設定は作成後にインスペクタで調整します。
  取り消したいときは Undo で戻せます。

### Color パネル

Renderer 単位の **Coloring** を設定します。上部で Renderer を選び (色を扱える Renderer のみが並びます)、
続いて Coloring の種類を選ぶと、その種類に応じた設定欄が下に表示されます。

| 種類 | 設定内容 |
|---|---|
| Solid | 既定色を 1 色指定します |
| Paint | 選択範囲と色の組を表で指定します。行の追加・削除・並べ替えができます |
| CPK | 元素ごとの色 (C / N / O / S / P / H / その他) |
| Rainbow | モード、変化させる基準、開始・終了の色相、明度、彩度 |
| B-factor | モード (B-factor / 占有率 / 距離)、下限・上限の色、下限値・上限値 (Auto が Manual のときのみ入力可) |
| 静電ポテンシャル | 対象のポテンシャルマップ、SAS で色付けするか、低 / 中 / 高の値と色 |
| Multi-gradient | マップのヒストグラムとグラデーションバー上で、ストップ (色の区切り) を直接編集します |

### View パネル

視点を数値で操作します。CueMol2 のフェイクダイヤル (View パネル) に相当します。

| セクション | 内容 |
|---|---|
| Rotation | X / Y / Z の回転。ドラッグで相対的に回します |
| Translation | 平行移動 |
| Zoom / Slab | ズーム、スラブ (表示する奥行きの幅)、距離 |
| Projection | 投影方式 (Perspective / Orthographic) と中心マーク |

!!! note
    視点の変更は Undo の対象外です。
    背景色はシーンの設定なので、このパネルではなく [Scene メニュー](../menu/scene.md) や
    インスペクタから設定します。

## Selection

### Molecular structure パネル

分子をチェイン → 残基 → 原子の階層ツリーで表示し、選択を作ります。

- 上部で対象の分子を選びます。
- ツリーは展開したときに読み込まれます。
- 複数選択に対応しています (++cmd++ / ++ctrl++ + クリック、++shift++ + クリック)。
- ツールバーの **Select** / **Center** / **Zoom** で、選んだ範囲を選択状態にする / 中心に持ってくる /
  拡大表示する、といった操作ができます。

### Selection パネル

分子の選択を表示・編集する専用パネルです。

- **Molecule** で対象の分子を選ぶと、**Selection** 欄にその分子の現在の選択が
  選択式として表示されます。パネルでの操作は選択に即座に反映され、Undo で戻せます。
- **選択ビルダー** (Named / History / Term / Mod の 4 タブ) で、式を書かずに選択を
  組み立てられます。定義済み選択・履歴のワンクリック適用、条件の合成
  (Set / Add / Sub / Intsec)、現在の選択の変換 (Invert / Byres / Sidech / Mainch /
  Arnd / Expn) ができ、各操作には適用した場合の原子数が表示されます。
- **Selection** 欄は手でも編集できます。入力中に式の妥当性が検証され、誤りがあれば
  警告表示になります。手入力した式は **Select** ボタンで適用します。
- 履歴はアプリケーションに保存され、Renderer の選択欄などと共有されます。

!!! note "CueMol2 との違い"
    CueMol2 の選択パネルにあった階層型エディタ (Hierarchical / Terminal / Around-Expand) は、
    選択ビルダーに置き換わりました。

## Crystal

### Symmetry パネル

結晶学的な対称性を扱います。

- 対象の Object (分子座標 / 密度マップ) を選ぶと、格子の種類・空間群・格子定数が表示されます。
- **Change...** で結晶系と空間群を変更できます。「対称性による制限」を有効にすると、
  格子定数の入力が結晶系の制約に従って連動します。
- **Symm mol** から対称分子を表示します。範囲は 20 / 50 / 100 / 200 Å または単位格子から選べます。
- **Unit cell** で単位格子の枠を表示します。

### Density map パネル

密度マップの Renderer (contour / isosurface など) の表示を調整します。

- Renderer を選び、透明度 / 等高線レベル / 表示範囲をスライダで調整します。
- レベルは σ 単位と絶対値のどちらでも指定できます (▼ メニューで切り替え)。
- **Redraw** で表示の中心を現在のビュー中心に更新します。**Cell** で単位格子を表示します。
