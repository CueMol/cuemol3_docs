# プロパティインスペクタ

ウィンドウ右側の**プロパティインスペクタ**は、シーンツリーで選んだ要素の設定を表示・編集する常設パネルです。
CueMol2 の各種プロパティダイアログを置き換えるものです。

## CueMol2 との違い

| | CueMol2 | CueMol3 |
|---|---|---|
| 形式 | Renderer の種類ごとにモーダルダイアログ | 常設パネル 1 つ |
| 分子ビュー | ダイアログが隠す / 操作をブロックする | 常に見えていて操作できる |
| 反映のタイミング | OK / Apply を押したとき | **値を変えた瞬間** |
| 取り消し | Cancel | **Undo** (++cmd+z++) |

編集が即座に反映されるため OK / Cancel ボタンはありません。やり直したいときは Undo を使ってください。

## 表示の切り替え

シーンツリーで要素を選ぶか、要素をダブルクリックするとインスペクタに内容が表示されます。
インスペクタ上部のタブで表示を切り替えられます。

| タブ | 内容 |
|---|---|
| **Properties** | 用途ごとに整理された設定画面。セクションに分かれ、折りたたみできます |
| **Generic** | その要素が持つプロパティを一覧表示する汎用エディタ |

選んだ要素の種類によって、既定で開くタブが変わります。

## 対象ごとの内容

### Renderer

Properties タブに **Common** セクション (基本設定とエッジライン) が表示されます。
不透明度・マテリアル・エッジラインの設定などをここで調整します。

!!! note "Renderer 種類ごとの詳細設定"
    Renderer の種類 (リボン / 棒球モデル / 分子表面など) に固有の設定項目は、現在は一部の種類でのみ
    専用のセクションが用意されており、それ以外の種類ではプレースホルダが表示されます。
    種類固有の設定は **Generic** タブから編集できます。

### Renderer グループ

Name / Visible / Locked のみを表示します。
グループには意味を持たない項目 (不透明度・マテリアル・エッジライン) は表示されません。

### Object

Name / Selection / Visible / Locked / Linked (読み取り専用) を編集できます。

### シーン

Scene メニューの **Properties...** から開きます。
アンビエントオクルージョン / アンチエイリアシング / 背景 / カラープルーフィングの設定があります
(→ [Scene リファレンス](../reference/scene.md))。

### ビュー

View メニューの **View property...** から開きます。Generic タブで表示されます。

## Generic タブ

その要素のプロパティを名前と値の一覧として表示します。

- 文字列 / 整数 / 実数 / 真偽値 / 列挙型の値を編集できます。
- 入れ子になったプロパティも、ドット区切りのキーとして展開され編集できます。
- 各項目は既定値に戻せます。
- 変更は Undo の対象です。

!!! warning "一部の型は編集用の入力欄が未整備です"
    色 / ベクトル / 時刻の値については、専用の入力ウィジェットが未実装です。
