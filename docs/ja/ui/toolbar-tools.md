# ツールバーとツールパレット

CueMol3 には性格の異なる 2 つのボタン列があります。

| | ツールバー | ツールパレット |
|---|---|---|
| 位置 | ウィンドウ上部 | 分子ビューの左端に浮かぶ |
| 性格 | 押すと**すぐ実行される**コマンド | 分子ビューの**操作モード**を切り替える |

## ツールバー

| ボタン | 動作 | 対応するメニュー項目 |
|---|---|---|
| New Tab | 新しいタブを作ります | File &gt; New Tab |
| Open File | ファイルを開きます | File &gt; Open File... |
| Save <span class="badge-wip">開発中</span> | **現在のバージョンでは動作しません** (シーンの保存は下記の Save Scene ボタンをお使いください) | |
| Save As | オブジェクトをファイルに保存します | File &gt; Save File As... |
| Open Scene | シーンファイルを開きます | File &gt; Open Scene... |
| Reload Scene | シーンを読み込み直します | File &gt; Reload Scene |
| Save Scene | シーンを保存します | File &gt; Save Scene |
| Get PDB | PDB ID を指定して構造を取得します | File &gt; Get PDB... |
| Render | レンダリングウィンドウを開きます | Rendering &gt; Image / Movie rendering... |
| Undo | 直前の操作を取り消します | Edit &gt; Undo |
| Redo | 取り消した操作をやり直します | Edit &gt; Redo |

- ウィンドウ幅が足りないときは、ラベルが省略されアイコンのみになります (ツールチップに名前が出ます)。
- シーンが開かれていないときは、シーンを必要とするボタンが無効になります。
- **Render** ボタンはレンダリングウィンドウを開きますが、出力モード (静止画 / 動画) は変更しません。

### Undo / Redo の履歴ドロップダウン

Undo / Redo ボタンには履歴のドロップダウンが付いています。
一覧から選ぶと、そこまでの操作をまとめて取り消し / やり直しできます。

## ツールパレット

分子ビューの左端に縦に並ぶボタンで、分子ビュー上でのクリック・ドラッグの意味を切り替えます。
選んだツールに応じてカーソルの形も変わります。

| グループ | ツール | ショートカット | 動作 |
|---|---|---|---|
| Navigate | Navigate | ++n++ | 視点操作 (既定のモード) |
| Select | Rect Select | ++b++ | 矩形範囲で選択します |
| | Lasso | ++l++ | 投げ縄で選択します |
| Measure | Distance | ++d++ | 2 原子をクリックして距離を計測します |
| | Angle | ++a++ | 3 原子をクリックして角度を計測します |
| | Torsion | ++t++ | 4 原子をクリックして二面角を計測します |
| Edit | Add Bond | ++e++ | 同じ分子内の 2 原子をクリックして結合を追加します |

- ++esc++ を押すと、それまでのクリックの蓄積がリセットされます。
- ツールを切り替えたときやビューを切り替えたときもリセットされます。

### 範囲選択ツール

Rect Select は矩形、Lasso は自由な多角形で囲んだ範囲の原子を選択します。

| 操作 | 動作 |
|---|---|
| ドラッグ | 囲んだ範囲で選択を**置き換え**ます |
| ++shift++ + ドラッグ | 囲んだ範囲を現在の選択に**追加**します (カーソルの形が変わります) |

Rect Select ツールの選択中は、視点操作 (Navigate) も引き続き行えます。

### 計測ツール

Distance / Angle / Torsion では、必要な数の原子をクリックすると計測値が分子ビュー上のラベルとして
追加されます。クリックの途中経過は十字マークで示されます。

計測ツールのグループには**オプションのつまみ**が付いており、開くとラベルを追加する対象の
ラベルセットを選べます。

計測は分子をまたいで行えます。

### Add Bond ツール

**同じ分子内の** 2 原子を順にクリックすると結合が追加されます。追加は Undo で取り消せます。

グループのオプションのつまみを開くと、その分子の非標準結合の一覧が表示され、
行ごとに削除できます。複数まとめて削除しても Undo は 1 回で戻ります。

!!! info "CueMol2 の Mol bond editor の代わりです"
    CueMol2 では Tools メニューからモーダルダイアログを開き、ダイアログを脇にどけながら
    原子 ID を入力欄に入れる操作でした。CueMol3 では分子ビューを直接クリックする方式に変わり、
    メニュー項目はなくなりました。
