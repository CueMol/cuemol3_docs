# Trajectory パネル

下部パネルの **Trajectory** タブで、MD トラジェクトリを再生します。
タイムライン上にフレームのブロックが表示され、再生・コマ送り・シークができます。

このタブは **MD Tools** プラグインの一部で、**既定では無効**です。
Settings &gt; Plugins &gt; Installed で有効にしてください
(→ [プラグイン](../reference/plugins/index.md))。

## トラジェクトリを開く

**File &gt; Open MD Trajectory...** では、トポロジーのファイル (`.gro` / `.prmtop` / `.psf`) と、
座標・トラジェクトリのファイルを順に並べて開きます。

開いている分子に、あとからトラジェクトリを付けることもできます。トラジェクトリのファイル
(`.xtc` / `.dcd` / `.trr` / `.nc`) か座標のファイル (`.rst7` / `.inpcrd` / `.restrt` / `.coor`) を
ウィンドウにドロップすると **Attach Trajectory** ダイアログが出て、原子数の合う分子から付け先を選べます。

- 普通の分子を選ぶと、その分子はトラジェクトリに変換され、元の座標が最初のフレームになります。
- 既にトラジェクトリになっている分子を選ぶと、フレームが後ろに足されます。
- 重ね合わせなどで動かした分子、編集した分子、元のファイルが無い分子は選べません。
- トポロジーだけのファイル (`.prmtop` / `.psf`) は、**Open File...** で座標の無い分子として開けます。
  座標は、そのあと座標やトラジェクトリのファイルをドロップして付けます。

## パネルの構成

| 場所 | 内容 |
|---|---|
| ヘッダ | 対象のトラジェクトリ (**Trajectory**)、再生の操作、現在のフレーム (**Frame**) と最後のフレーム、ループ (**Loop**)、再生の速さ (**Speed**)、表示の拡大・縮小 |
| 中央 | フレームの目盛りと、ファイルごとのブロック |
| 下端 | ブロックを追加・削除・並べ替えるツールバーと、ブロックの数 |

## 再生する

- ヘッダの再生ボタンは、左から **Skip to start** / **Play** (再生中は **Pause**) / **Stop** / **Skip to end** です。
- **Frame** にフレーム番号を入力すると、そのフレームに移動します。目盛りか、ブロックの無い所をクリック・ドラッグしても移動できます。
- **Loop** を ON にすると繰り返し再生します。**Speed** で 1 秒あたりのフレーム数を選びます。
- **Fit** でトラジェクトリ全体をパネルの幅に収め、**-** / **+** で表示を縮小・拡大します。

## ブロックを編集する

1 つのファイルが 1 つのブロックになり、ブロックの順にフレームがつながります。

| ボタン | 動作 |
|---|---|
| **Add...** | ファイルを選んで、ブロックとして末尾に追加します |
| 削除 | 選んだブロックを削除します |
| ◀ / ▶ | 選んだブロックを前 / 後ろに移します。ブロックをドラッグしても並べ替えられます |
