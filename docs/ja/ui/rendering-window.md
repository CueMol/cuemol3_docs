# レンダリングウィンドウ

レイトレーシングによる高品位な静止画と、動画の出力を行う独立したウィンドウです。
**モードレス** (非モーダル) なので、開いたままメインウィンドウで分子ビューを操作できます。

## 開き方

| 操作 | 結果 |
|---|---|
| **Rendering &gt; Image rendering...** | ウィンドウを開き、**静止画 (Still) モード**にします |
| **Rendering &gt; Movie rendering...** | ウィンドウを開き、**動画 (Movie) モード**にします |
| **Window &gt; Rendering Window** | ウィンドウを開く / 前面に出します (モードは変えません) |
| ツールバーの **Render** ボタン | 同上 |

すでに開いている場合、Image / Movie rendering... はモードだけを切り替えます。

## ウィンドウの構成

| 領域 | 内容 |
|---|---|
| 画像領域 (左上) | レンダリング結果のプレビュー |
| Render Settings (右) | 設定パネル。**Image** タブと **Render** タブがあります |
| 実行バー + ログ (下) | Backend / Target の選択、Start / Stop、進捗とログ |

## 実行バー

| 項目 | 内容 |
|---|---|
| **Backend** | レンダリングバックエンドを選びます (Umbreon / POV-Ray) |
| **Target** | どのビューをレンダリングするかを選びます (開いているビューが並びます) |
| **Start** | レンダリングを開始します |
| **Stop** | 実行中のレンダリングを中止します |
| **Encode** (Movie モードのみ) | 出力済みのフレーム画像から動画ファイルを作り直します |

!!! note "Umbreon が選べない場合"
    内蔵レイトレーサ Umbreon が組み込まれていないビルドでは、Backend の選択肢に表示されません。
    POV-Ray を使う場合は Settings で実行ファイルのパスを設定してください
    (→ [外部ツールの設定](../install/external-tools.md))。

## Image タブ

出力画像のサイズなど、バックエンドに依存しない設定です。
サイズはプリセットから選ぶか、Custom で幅・高さを直接指定します。

| モード | サイズプリセット |
|---|---|
| 静止画 (Still) | Custom / Current view / 100×100 (72dpi) / 300×300 (300dpi) / 600×600 (300dpi) / 1200×1200 (600dpi) |
| 動画 (Movie) | Custom / QVGA (320×240) / VGA (640×480) / SVGA (800×600) / XGA (1024×768) / HD720 (1280×720) / HD1080 (1920×1080) |

**Current view** を選ぶと、メインウィンドウの分子ビューと同じサイズになります。

## Render タブ

バックエンドごとの設定です。バックエンドを切り替えると、そのバックエンドが対応しない項目は隠れます。

POV-Ray バックエンドでは、ラジオシティのモード、影の有無、ライティング (既定ライトの使用 /
光源の広がり / 強度) などを指定できます。品質のプリセットが用意されているバックエンドでは、
個別の項目を触らずにプリセットだけで済ませることもできます。

## 動画 (Movie) モード

動画モードでは、上記に加えて出力先のフォルダ・フレームレート・動画形式などを指定します。
出力設定は次回ウィンドウを開いたときにも保持されます。

処理の流れは次のとおりです。

1. **Start** でフレームを 1 枚ずつレンダリングし、出力フォルダに書き出します
2. すべてのフレームが揃うと、ffmpeg で動画ファイルにエンコードします

途中で中止した場合や設定を変えて動画だけ作り直したい場合は、**Encode** ボタンで
出力フォルダにあるフレームから動画を作り直せます。

!!! warning "動画のエンコードには ffmpeg が必要です"
    ffmpeg の実行ファイルのパスを Settings で設定してください
    (→ [外部ツールの設定](../install/external-tools.md))。

アニメーションの内容そのものは、メインウィンドウの下部パネルの **Animation** タブで作ります
(→ [下部パネル](bottom-panels.md))。

## CueMol2 との違い

CueMol2 では「POV-Ray rendering」と「Animation rendering」がそれぞれ別のダイアログでした。
CueMol3 では 1 つのウィンドウに統合され、**出力の種類** (静止画 / 動画) をモードで切り替え、
**バックエンド** (Umbreon / POV-Ray) はウィンドウ内で選ぶ形になっています。
