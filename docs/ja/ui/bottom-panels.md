# 下部パネル

ウィンドウ下部のパネルは 4 つのタブを持ちます。

!!! info "撮影予定"

| タブ | 内容 |
|---|---|
| **Output** | ログ表示とコマンド入力 |
| **Sequence** | 分子のアミノ酸・塩基配列の表示と選択 |
| **Animation** | アニメーションのタイムライン編集 |
| **Trajectory** | MD トラジェクトリの再生 |

## Output

アプリケーションのログを表示します。ファイルの読み込み結果やエラーメッセージがここに出ます。

- ++cmd+a++ (Edit &gt; Select All) でログ全体を選択し、コピーできます。

## Sequence

読み込まれている分子の配列を、チェインごとに 1 行の格子で表示します。
分子ごとの切り替えはなく、シーン内のすべての分子のチェインが並びます。

### 操作

| 操作 | 動作 |
|---|---|
| クリック | その残基の選択を切り替え、分子ビューの表示をその残基の位置に移動します |
| ドラッグ | 始点から終点までの残基の選択を切り替えます |
| ++shift++ + クリック | 直前にマークした位置からクリック位置までを選択します |
| 右クリック | 下記のメニューが開きます |

### 右クリックメニュー

| 項目 | 動作 |
|---|---|
| Toggle sel | その残基の選択を切り替えます |
| Around 3 / 5 / 7 / 10 | 選択範囲から指定距離以内の原子を選択します |
| Around Byresid 3 / 5 / 7 / 10 | 同上。ただし残基単位で選択します |
| Unselect all | 選択をすべて解除します |
| Invert sel | 選択を反転します |
| Copy sequence | 配列を 1 文字表記でクリップボードにコピーします (対応する 1 文字表記がない残基は `*`) |
| Center here | その残基を分子ビューの中心に持ってきます |

左側の名前列と配列の格子の境界はドラッグで幅を変えられます。

!!! warning "既知の問題: 選択の反映が遅れます"
    選択を変更してから分子ビューのハイライトが更新されるまで、体感で 0.5 秒ほどの遅れが出ることがあります。
    調査中の既知の問題です。

## Animation

アニメーションのタイムラインを編集します。Blender のようなストリップ形式で、
1 つのアニメーション要素が 1 本の帯として表示されます。

- 帯をドラッグして開始位置を移動、端をドラッグして長さを変更できます。
- 帯の追加・削除・並べ替えができます。
- 再生ボタンで、アニメーションを実際に分子ビュー上で再生できます。
- 帯を選ぶと右側のインスペクタにその要素の詳細設定が表示されます
  (種類ごとの設定と、汎用のプロパティ一覧)。
- タイムラインのヘッダで開始カメラを選べます。

作成したアニメーションを動画ファイルとして出力するには、
**Rendering &gt; Movie rendering...** を使います (→ [レンダリングウィンドウ](rendering-window.md))。

!!! note
    アニメーションのプロパティを編集している最中は、分子ビューはリアルタイムには追従しません。
    再生して確認してください。

## Trajectory

**File &gt; Open MD Trajectory...** で読み込んだ MD トラジェクトリを再生します。
タイムライン上にフレームのブロックが表示され、再生・コマ送り・シークができます。
