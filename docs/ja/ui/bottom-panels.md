# 下部パネル

ウィンドウ下部のパネルは、既定では 4 つのタブを持ちます。

!!! info "撮影予定"

<!-- TODO(screenshot): 下部パネルの 4 タブ (Console / Output / Sequence / Animation)。Sequence タブで残基が選択されている状態 -->

| タブ | 内容 |
|---|---|
| **Console** | コマンドライン (→ [Console](../reference/plugins/console/index.md)) |
| **Output** | ログ表示 |
| **Sequence** | 分子のアミノ酸・塩基配列の表示と選択 |
| **Animation** | アニメーションのタイムライン編集 |

[プラグイン](../reference/plugins/index.md)を有効にすると、次のタブが加わります。
**Console** タブも Console プラグインの一部で、無効にすると表示されなくなります。

| タブ | 内容 | プラグイン |
|---|---|---|
| **Trajectory** | MD トラジェクトリの再生 | MD Tools |

## Output

アプリケーションのログを表示します。ファイルの読み込み結果やエラーメッセージがここに出ます。

- ++cmd+a++ (Edit &gt; Select All) でログ全体を選択し、コピーできます。

## Sequence

読み込まれている分子の配列を、チェインごとに 1 行の格子で表示します。
分子ごとの切り替えはなく、シーン内のすべての分子のチェインが並びます。

### 操作

| 操作 | 動作 |
|---|---|
| クリック | その残基の選択を切り替え、分子ビューの表示をその残基の位置に移動します |
| ドラッグ | 始点から終点までの残基の選択を切り替えます |
| ++shift++ + クリック | 直前にマークした位置からクリック位置までを選択します |
| 右クリック | 下記のメニューが開きます |

### 右クリックメニュー

| 項目 | 動作 |
|---|---|
| Toggle sel | その残基の選択を切り替えます |
| Around 3 / 5 / 7 / 10 | 選択範囲から指定距離以内の原子を選択します |
| Around Byresid 3 / 5 / 7 / 10 | 同上。ただし残基単位で選択します |
| Unselect all | 選択をすべて解除します |
| Invert sel | 選択を反転します |
| Copy sequence | 配列を 1 文字表記でクリップボードにコピーします (対応する 1 文字表記がない残基は `*`) |
| Center here | その残基を分子ビューの中心に持ってきます |

左側の名前列と配列の格子の境界はドラッグで幅を変えられます。

!!! warning "既知の問題: 選択の反映が遅れます"
    選択を変更してから分子ビューのハイライトが更新されるまで、体感で 0.5 秒ほどの遅れが出ることがあります。
    調査中の既知の問題です。

## Animation

アニメーションのタイムラインを編集します。1 つのアニメーション要素が 1 本の帯として表示され、
帯の追加・移動・コピー &amp; ペーストや再生を行えます。詳しくは
[Animation パネル](animation-panel.md) を参照してください。

## Console

CueMol の操作をコマンドで実行するコマンドラインです。ツールバーで PyM console に切り替えると、
`fetch 1crn` のような PyMOL のコマンドもそのまま打てます。ChX console では、`open 1crn` のような
ChimeraX のコマンドを打てます。

このタブは **Console** プラグインの一部で、**既定で有効**です
(→ [Console](../reference/plugins/console/index.md))。下部パネルの先頭のタブで、ほかのタブを
選ぶまでは前面に表示されます。

## Trajectory

**File &gt; Open MD Trajectory...** で読み込んだ MD トラジェクトリを再生します。
タイムライン上にフレームのブロックが表示され、再生・コマ送り・シークができます。

**Open MD Trajectory...** では、トポロジーのファイル (`.gro` / `.prmtop` / `.psf`) と、
座標・トラジェクトリのファイルを順に並べて開きます。

開いている分子に、あとからトラジェクトリを付けることもできます。トラジェクトリのファイル
(`.xtc` / `.dcd` / `.trr` / `.nc`) か座標のファイル (`.rst7` / `.inpcrd` / `.restrt` / `.coor`) を
ウィンドウにドロップすると **Attach Trajectory** ダイアログが出て、原子数の合う分子から付け先を選べます。

- 普通の分子を選ぶと、その分子はトラジェクトリに変換され、元の座標が最初のフレームになります。
- 既にトラジェクトリになっている分子を選ぶと、フレームが後ろに足されます。
- 重ね合わせなどで動かした分子、編集した分子、元のファイルが無い分子は選べません。
- トポロジーだけのファイル (`.prmtop` / `.psf`) は、**Open File...** で座標の無い分子として開けます。
  座標は、そのあと座標やトラジェクトリのファイルをドロップして付けます。

このタブは **MD Tools** プラグインの一部で、**既定では無効**です。
Settings &gt; Plugins &gt; Installed で有効にしてください
(→ [プラグイン](../reference/plugins/index.md))。
