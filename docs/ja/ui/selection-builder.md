# 選択ビルダー

**選択ビルダー**は、[選択式](../reference/selection.md)を書かずに GUI の操作で
選択を組み立てるためのウィジェットです。次の場所から使えます。

- **Selection パネル** — パネル内に常設されています (→ [サイドパネル](side-panels.md))
- **選択式の入力欄全般** — New Renderer ダイアログ、分子表面の生成・重ね合わせなどの
  ツールダイアログ、Color パネルの Paint の選択セルなど、選択式を入力する欄であれば
  ▼ ボタンから、同じものがポップオーバーとして開きます

ビルダーの操作結果は常に**選択式**として入力欄に反映されます。生成された式は
そのまま手で直せるので、文法を覚える近道にもなります。

## タブの構成

| タブ | 役割 |
|---|---|
| [Named](#named) | 定義済みの選択をクリック 1 回で適用 |
| [History](#history) | 過去に使った式をクリック 1 回で適用 |
| [Term](#term) | 条件 (項) を 1 つ作り、現在の選択と合成 |
| [Mod](#mod) | 現在の選択そのものを変換 |

Named / History は「できあいの式を選ぶ」操作、Term / Mod は「選択を組み立てる・
加工する」操作です。

## Named

定義済みの選択が 3 つの節に分かれて並び、クリックすると**現在の選択を置き換えて**
即座に適用されます (ポップオーバーの場合はそのまま閉じます)。

Selected
:   対象の分子にいま適用されている選択式

Scene
:   シーンに保存された名前付きの選択定義

Global
:   全シーン共通の定義。`protein` / `water` などの組み込みの選択は
    ここに並びます

## History

過去に適用した選択式の履歴です (最大 100 件)。クリックで再適用します。
履歴はアプリケーションに保存され、選択を適用するすべての操作 (Selection パネル、
インスペクタや New Renderer ダイアログの選択欄、シーンツリー・配列パネル・右クリック
メニューの選択、矩形 / 投げ縄選択、Molecular structure パネル) から記録されて共有されます。
全体 (`*`) と空の選択は記録されません。Term / Mod タブでの合成の途中経過も記録されません。

## Term

キーワードと値で条件 (項) を 1 つ作り、**適用ボタン**で現在の選択と合成します。

| ボタン | 意味 |
|---|---|
| **Set** | 項で選択を置き換える |
| **Add** | 項を選択に加える (和) |
| **Sub** | 項を選択から除く (差) |
| **Intsec** | 項と選択の共通部分にする (積) |

選択が空のときは、値の欄で ++enter++ を押すだけで Set が適用されます。

キーワードには次のようなものがあります。値の欄はキーワードに応じて変わり、
チェイン名・残基名・原子名・元素は読み込んだ分子から**候補が自動補完**されます。

| キーワード | 意味 | 値の指定 |
|---|---|---|
| Named / History | 定義済み選択・履歴を項として使う | 一覧から選ぶ |
| hier | チェイン・残基・原子の階層指定 | 3 つの欄 (例: `A` / `2:3` / `CA`) |
| chain | チェイン名 | 候補から選ぶか入力 |
| resid | 残基番号 | 番号・範囲 (`2:7` など) |
| resn / name / elem | 残基名 / 原子名 / 元素 | 候補から選ぶか入力 |
| Altloc | 別配座 (altloc) の ID | |
| bfac | 温度因子 | 比較演算子と値 |
| rprop | 残基のプロパティ | プロパティ名と値 |
| all / none | 全体 / 空 | 値なし |

Named / History をキーワードとして使うと、「定義済み選択との共通部分を取る」
「履歴の式を現在の選択から除く」といった合成ができます。

## Mod

現在の選択そのものを変換します。項は取りません。

| ボタン | 変換 |
|---|---|
| **Invert** | 選択を反転する |
| **Byres** | 一部でも選択されている残基の全体まで広げる |
| **Sidech** / **Mainch** | 側鎖 / 主鎖の部分だけにする |
| **Arnd** | 選択の周囲の指定距離以内にある原子に置き換える (Around) |
| **Expn** | 選択に周囲の原子を加える (Expand) |

Arnd / Expn の距離は、隣のドロップダウンからプリセット (3〜10 Å) で選びます。

## 原子数の表示

適用ボタンの脇には、その操作を適用した場合に選択される**原子数**が表示され、
結果を予想しながら操作できます。9999 を超える値は `12k` / `1.2M` のように
省略表記され、ポインタを載せると正確な値が表示されます。
