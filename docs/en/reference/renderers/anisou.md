# anisou (thermal ellipsoids)

An ORTEP-style Renderer that draws anisotropic temperature factors (ANISOU) as ellipsoids.
Target Object: molecule (MolCoord). It is derived from ballstick, and the atom and bond settings
are the same as in [ballstick](ballstick.md).
