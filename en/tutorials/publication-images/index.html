    論文用の高解像度画像を書き出す¶

    作成したシーンを、論文や発表資料に使える品質の画像として書き出す手順を追います。 タンパク質のリボン図を作る で仕上げたシーンを題材にしますが、 どのシーンでも手順は同じです。

    撮影予定

    このページには操作の流れを示すスクリーンショットを追加予定です。

    1. 2 つの出力方法と使い分け¶

    方法 特徴 向いている用途
    Rendering > Export scene > PNG image... 画面表示と同じ描画をそのまま書き出す。速い 作業中の記録、スライド、確認用
    Rendering > Image rendering... (レンダリングウィンドウ) レイトレーシングによる高品位な描画。陰影・輪郭線の品質が高い 論文の図、ポスター

    まず Export scene で構図を確かめ、最終版をレンダリングウィンドウで仕上げる、 という流れが手早く確実です。仕上がった画像は、プレゼンテーションソフトや図版作成 ソフトに貼り付けて組み図にするのが通常の使い方です。

    2. 画面のまま PNG に書き出す¶

    Rendering > Export scene > PNG image... を選ぶと、保存先の指定に続いて オプション画面が出ます。

    • サイズと解像度 (DPI) を指定できます
    • 背景の透過を有効にすると、背景が透明な PNG になります (スライドの重ね合わせに便利です)

    DPI は画像のピクセル数には影響しません。書き出した PNG を他のソフトウェアに貼り付けて 印刷するときの紙面上の実寸を決める値です (例: 1200×1200 ピクセルを 600 DPI で 書き出すと、印刷時の実寸は 2×2 インチ = 約 5 cm 角になります)。

    そのほかの出力形式 (POV-Ray SDL / STL / MQO など) は Rendering メニュー を参照してください。

    3. レイトレースで仕上げる¶

    Rendering > Image rendering... を選ぶと、独立したレンダリングウィンドウが開き、 静止画 (Still) モードになります。ウィンドウはモードレスなので、開いたまま メインウィンドウで視点を調整できます (→ レンダリングウィンドウ)。

    1. 下部の実行バーで、Target にレンダリングしたいビューを選びます。 Backend は既定の Umbreon のままで構いません
    2. Image タブで出力サイズを選びます。プリセット (例: 1200×1200 (600dpi)) から選ぶか、 Custom で幅・高さを直接指定します
    3. Render タブの Quality セクションで、Lighting (陰影の付け方) を Raytrace only にします。今回のような cartoon の図は、これで十分きれいに仕上がります。 Supersampling (輪郭を滑らかにする設定) は既定のままで構いません
    4. Start Render を押すとレンダリングが始まり、進捗が表示されます

    陰影に奥行き感を出すなら Global Illumination

    Lighting を Global Illumination (既定) にすると、大域照明による陰影づけで 奥行き感のある仕上がりになります。ただし、cartoon だけの図では効果は小さめです。 分子表面のような込み入った形状の図で試してみてください。

    各品質項目の意味と使い分けは レンダリング を参照してください。

    CueMol2 との違い

    CueMol2 の高品位出力は外部の POV-Ray を呼び出す方式でしたが、CueMol3 では内蔵 レイトレーサの Umbreon が既定になり、外部プログラムの用意もパスの設定も不要です (→ レンダリングウィンドウ)。

    4. 結果を確認して保存する¶

    レンダリングが完了すると、結果画像がウィンドウ左上の画像領域に表示されます。

    • 画像領域のツールバーの Save で PNG ファイルとして保存します
    • Copy でクリップボードにコピーできます
    • 矢印ボタンで過去のレンダリング結果の履歴をさかのぼれます。履歴には実行時の設定も 一緒に記録されており、Use settings を押すとその設定に戻せます

    構図や品質が気に入らなければ、メインウィンドウで調整して Start Render し直します。 設定は結果の履歴に残るので、試行錯誤しながら比較できます。

    レンダリングウィンドウの設定はシーンに保存されます

    設定はシーンファイルと一緒に保存され、次にシーンを開いたときにも残ります。 設定の変更は Undo で戻せます。過去の設定に戻りたいときは結果の履歴の Use settings を使ってください (→ レンダリング)。
