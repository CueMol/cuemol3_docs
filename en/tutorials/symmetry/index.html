    対称分子・単位格子を表示する¶

    結晶中で対称操作により生じる隣の分子 (対称分子) と単位格子の枠を表示して、 結晶パッキングを確かめる手順を追います。題材は前のチュートリアルと同じ リゾチーム (PDB ID: 1QIO) です。 電子密度マップを重ねて表示する の続きとして進めても構いません。

    撮影予定

    このページには操作の流れを示すスクリーンショットを追加予定です。

    1. 結晶構造を読み込む¶

    File > Get PDB... で 1QIO を取得します (座標のみで構いません)。 Renderer は cartoon など、分子の輪郭がわかるものを選びます。

    2. 結晶学的情報を確認する¶

    左サイドパネルの Crystal > Symmetry パネルを開きます (→ サイドパネル)。

    1. Object で対象 (1QIO) を選びます
    2. 格子定数 (a / b / c / α / β / γ) と空間群が表示されます

    PDB から取得した構造には結晶学的情報が含まれているため、通常はそのまま 次のステップに進めます。

    表示された値が実際と違うときは

    PDB ファイルによっては、ここに表示される値が意図したものと違っていることがあります。 その場合や、対称性の情報がないファイルを読み込んだ場合は、パネルの Change... から 結晶系と空間群を設定し直せます (→ サイドパネル)。

    3. 単位格子を表示する¶

    パネルの Unit cell ボタンを押すと、単位格子の枠がシーンに追加されます。 左サイドパネルの Explorer > Scene ツリー (シーンツリー) には *unitcell という Renderer として現れ、目のアイコンで 表示・非表示を切り替えられます。

    4. 対称分子を表示する¶

    パネルの Symm mol ボタンから表示範囲を選びます。

    • 20 Å / 50 Å / 100 Å / 200 Å — 現在のビュー中心から、その距離以内にある対称分子を 表示します。視点を動かすと表示は自動で追従します
    • Unit cell — 単位格子 1 つ分の対称分子を表示します

    対称分子はシーンツリーに *symm という Renderer として追加され、 元の Renderer と同じ表示方法・色で描かれます。*symm は元の Renderer の表示を 対称操作して映しているだけで、鏡に映った像のように実体 (座標データ) を持ちません。 対称分子をいくつ表示しても、元の Object は変化していません。

    1QIO の空間群 P43212 には 8 つの対称操作があるため、Unit cell を選ぶと 単位格子あたり 8 分子が表示されます。

    まず 20 Å で接触している分子だけを確かめ、パッキング全体を見るときに Unit cell や大きな距離に切り替える、という使い方が見通しやすいです。

    5. 対称分子を独立した Object にする¶

    表示された対称分子の 1 つを、座標を持つ独立した Object として取り出せます。 接触面の解析や、対称分子だけ色を変えた図を作りたいときに使います。

    1. 分子ビューで、対称分子の原子を右クリックします (Navigate ツールのとき)
    2. メニューの先頭に対称操作 (symop: ...) が表示されるので、対称分子を 指していることを確かめます
    3. Create SYMM mol... を選びます
    4. 新しい Object の名前と Renderer の種類を指定して Create を押します

    対称操作を適用した座標を持つ新しい分子 Object が作られます。以降は通常の Object と同じように Renderer の追加や色の設定ができます。操作は Undo で 取り消せます。

    同じメニューの Center at SYMM atom では、クリックした対称分子の原子にビュー中心を 移せます。よく似た名前の Center at this atom は対称操作する前の原子 (実体) が 対象なので、対称分子を見ているときに選ぶと視点が離れた場所へ飛んでしまいます。

    6. 表示を調整・解除する¶

    • 表示範囲を変えるには、もう一度 Symm mol から選び直します
    • 対称分子や単位格子を消すには、シーンツリーで *symm / *unitcell の Renderer を 削除するか、目のアイコンで非表示にします

    次のステップ¶

    • 電子密度マップを重ねて表示する — 同じ 1QIO で密度を確かめる
