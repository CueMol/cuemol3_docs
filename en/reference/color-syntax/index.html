    色の記法¶

    色は通常カラーピッカーで指定しますが、文字列で直接記述することもできます。 シーンファイル (.qsc) やスタイルファイル中の色は、ここで説明する記法で書かれています。

    テキストでの色入力について

    CueMol3 の GUI はカラーピッカーによる指定が中心ですが、 より細かく調整したい場合は、ここに書かれている記法で指定することも可能です。とくに修飾子を使用した色の指定はGUIからはできません。

    HTML 表記¶

    HTML や CSS で使用する # を用いた色の表記法と同じです。

    6 桁表記¶

    #UVWXYZ

    U〜Z は 0〜9 の数字あるいは A〜F のアルファベットで、 UV が赤、WX が緑、YZ が青の強度を表します。

    例:

    #1234AB

    Red=0x12 (=18/255)、Green=0x34 (=52/255)、Blue=0xAB (=171/255)。

    #FFFFFF

    Red=0xFF、Green=0xFF、Blue=0xFF で白色を表します。

    3 桁表記¶

    #XYZ

    X は 0〜9 の数字あるいは A〜F のアルファベット。#XXYYZZ と等価です。

    例:

    #CCC

    Red=0xCC (=204/255)、Green=0xCC、Blue=0xCC で灰色を表します。

    RGB 表記¶

    rgb(X,Y,Z)

    X、Y、Z は 0〜1 の実数値で、それぞれ赤、緑、青の強度を表します。

    例:

    rgb(1.0, 0.5, 0.5)

    ピンク色になります。

    透過度 alpha つき表記¶

    rgba(X,Y,Z,W)

    X、Y、Z、W は 0〜1 の実数値。W が不透明度を表し、0 で完全に透明になります。

    HSB 表記¶

    hsb(X,Y,Z)

    X は 0〜360 の実数値で色相を表します (0 が赤で 180 が水色)。 Y、Z は 0〜1 の実数値で、飽和度 (saturation) と輝度 (brightness) を表します。

    透過度 alpha つき表記¶

    hsba(X,Y,Z,W)

    W が不透明度を表し、0 で完全に透明になります。

    名前表記¶

    <_a-z0-9+- からなる文字列>

    スタイルファイル中で定義されている色名で色を指定します。大文字小文字の区別はありません。 システムの既定スタイルファイルでは、HTML / CSS で使用できるのと同種の色名が 定義されています (CSS Color Module Level 3)。

    例:

    antiquewhite

    #faebd7 と同じ色になります。

    分子色表記¶

    $molcol

    分子 Object を参照する Renderer の色指定で使用できます。分子構造の Renderer のほか、 分子表面 (molsurf / dsurface / dsurf2) と等値面 (isosurf) の Solid coloring でも使えます。 対応する分子 Object 側で指定されている色を参照するようになります。

    分子 Object 側の着色を変えると、$molcol を指定した Renderer の色も追従します。 複数の Renderer で同じ着色を共有したいときに使います。 → Coloring

    修飾子¶

    以上の色指定の後ろに波かっこ ({}) で指定します。 複数の修飾子を指定する場合はセミコロンで区切ります。

    <色指定>{<修飾子1>;<修飾子2>;...}

    修飾子はキーと値からなります。

    修飾子 := <キー> : <値>

    キーには以下のものがあります。キーの種類によって指定できる値の種類が決まっています。

    material
    質感を指定します。値は質感を表す文字列 → マテリアル
    alpha
    透過度を指定します。値は 0〜1 の実数値
    mod_h
    色相の変化。値は任意の実数値
    mod_s
    飽和度 (saturation) の変化。値は任意の実数値
    mod_b
    輝度 (brightness) の変化。値は任意の実数値

    rgb 表記、hsb 表記、# 表記、色名表記などいずれでも使用できますが、 material 以外は色名表記・分子色表記以外で使用する意味はあまりありません。

    例:

    rgb(1,0,0){material: shadow; alpha: 0.5}

    赤色に対し、material を shadow (陰影付けなしのべた塗り) に、透明度を 0.5 に 変更したものを指定します。

    $molcol{mod_s: -0.2}

    分子色に対し、saturation (1 で原色、小さくなるほど白っぽくなる) を 0.2 減少させた ものを指定します。すなわち、分子側で指定した着色より少々白っぽい色で着色されます。
