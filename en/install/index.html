    Installation¶

    CueMol3 is a development build

    CueMol3 release assets can be downloaded by anyone from GitHub Releases, but they are work-in-progress versions. The assets are not signed with a certificate that identifies the publisher (Developer ID / Authenticode) and are not notarized, so the OS shows a security warning on first launch and a manual step is required to get past it.

    If you need a stable version for daily work or for preparing papers, use the stable release of CueMol2. See the CueMol2 documentation site for how to get it.

    Code signing status of the release assets¶

    OS Signing Warning at launch
    macOS Ad-hoc signature only (codesign --sign -). No Developer ID signature or notarization A Gatekeeper warning is shown → how to bypass it
    Windows None (Authenticode signing is future work) A SmartScreen warning is shown → how to bypass it
    Linux None No warning

    An ad-hoc signature does not pass Gatekeeper

    The macOS release assets are ad-hoc signed at build time. This is required to make the app launchable on Apple Silicon (an unsigned bundle is rejected as "damaged"), and it does not identify the publisher. Therefore the Gatekeeper warning is still shown for files downloaded from the web, as before.

    Download¶

    CueMol3 release assets are published on the Releases page on GitHub (alongside the CueMol2 release assets in the same releases).

    • Latest release — In the Assets section at the bottom of the page, download the file whose name starts with CueMol3- (files starting with cuemol2_... are CueMol2 release assets)
    • Release list and release notes — Downloads of past versions, and detailed changes for each release (for just the highlights, see the release history)

    The development build can also be obtained in the following ways.

    • Artifacts generated by the CI (build2.yml) of the GitHub repository (requires a GitHub login)
    • Building the package from source yourself

    Release assets¶

    OS Release asset (example: version 2.3.15.530) Installer format
    macOS (Apple Silicon / arm64) CueMol3-2.3.15.530-macOS-arm64-Installer.dmg Disk image
    Windows (x64) CueMol3-2.3.15.530-Windows-x64-Setup.exe NSIS wizard-style installer
    Linux (x64) CueMol3-2.3.15.530-Linux-x64.AppImage / CueMol3-2.3.15.530-Linux-x64.deb AppImage / Debian package

    The file name contains the target OS and the version, which includes a 4-digit build number. Files with Installer / Setup in the name are installers.

    The x86-64 builds require an AVX2-capable CPU

    The Windows / Linux x86-64 builds are compiled with AVX2 instructions. Supported CPUs are Intel Haswell / AMD Zen and later (roughly 2013 onward). On older CPUs, the app crashes when a molecular surface is generated.

    macOS (Apple Silicon) and ARM builds are not affected.

    File associations¶

    CueMol3 registers the file formats it can handle (16 types, including .qsc / .pdb / .cif / .mol2 / .ccp4) with the OS. CueMol3 appears in "Open With" on macOS, "Open with" in Windows Explorer, and "Open With" in Linux file managers.

    The registration is as a candidate only. CueMol3 does not take over the default application, so settings such as opening .qsc with CueMol2 and .pdb with another application remain as they are.

    On Linux, the .deb package registers the associations. For the AppImage, this depends on your desktop integration tool.

    External tools¶

    Movie encoding (ffmpeg) and electrostatic potential calculation (APBS / PDB2PQR) use external programs. If they are bundled with the release assets, they can be used as they are; for builds that do not bundle them, the executable paths must be specified in Settings.

    Ray tracing is performed by the built-in Umbreon, so no external program is needed.

    → Configuring external tools

    Uninstallation¶

    OS Procedure
    macOS Delete /Applications/CueMol3.app
    Windows Uninstall CueMol3 from "Apps & features / Add or remove programs"
    Linux (AppImage) Delete the .AppImage file
    Linux (.deb) Remove it with a package manager, for example sudo apt remove cuemol3
