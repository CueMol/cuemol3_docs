    Side panels¶

    The side panel on the left of the window switches between views using the activity bar at the far left. Clicking the selected icon again closes the side panel.

    Activity bar layout¶

    Icon View Panels
    Explorer Scene structure and display settings Scene / Color
    View Camera and viewpoint control Camera / View
    Selection Molecule selection Molecular structure / Selection
    Crystal Crystallographic information Symmetry / Density map
    Actions Recording and replaying operations History / Actions
    Gear (at the bottom) Opens the Settings tab (not a side panel)

    Explorer¶

    Scene panel (scene tree)¶

    Shows the contents of the scene as a tree. It corresponds to the workspace panel of CueMol2.

    • Node types: scene / Object / Renderer / Renderer group / style set
    • Toggling visibility: The eye icon on each row shows or hides it. A row that is not drawn because a parent node is hidden has a grayed-out icon.
    • Selection: Click to select; Cmd / Ctrl + click selects multiple rows. Shift + click selects a range from the previously selected row, in the order rows appear on screen (the contents of collapsed nodes are not included). The anchor does not move, so repeated Shift + click extends or shrinks the range from the same anchor. Shift + Cmd / Ctrl + click adds a range without replacing the current selection.
    • Keyboard: Up / Down move one row at a time, and Home / End move to the first / last row. Adding Shift extends the selected range, and Shift + Cmd / Ctrl extends it in addition to the current selection. Left / Right collapse / expand a row; when it cannot be collapsed or expanded any further, the focus moves to the parent row / the first child row.
    • Renaming: Press F2 or choose Rename... from the context menu to edit the name in place. Enter or moving the focus away confirms, and Esc cancels. Clicking a row only selects it and does not start editing the name.
    • Reordering: Drag and drop to change the order or the group membership.
    • Double-click: Shows the contents in the property inspector.
    • Right-click: Opens a menu for each node type (see below).

    The toolbar at the top of the panel has Add / Focus / Delete / Property buttons. Focus and Property are unavailable while multiple nodes are selected. Delete removes all selected nodes and can be undone in one step with a single Undo. The Del / Backspace keys do the same.

    Main context menu operations¶

    Target Main operations
    Scene Background color (White / Black), toggling color proofing, renaming, pasting an Object
    Object Specifying a selection, renaming, copy & paste, creating a new Renderer / Renderer group, setting colors, Save As, regenerating molecular surfaces
    Renderer Renaming, copy & paste (pastes into the same Object and the same group), setting colors, applying / creating / editing styles, changing the selection, generating a surface Object, changing the Renderer type, editing the interaction list
    Renderer group Show / hide (applies to its members), renaming, copy & paste, creating a new Renderer
    Style set Create / copy & paste / delete, toggling read-only, reading and writing files, style editor

    When multiple nodes are selected, copy is available in addition to show, hide and delete. Selecting a Renderer group targets its member Renderers. Copying is not possible when nodes of different types are mixed, or when two or more Objects are selected.

    Copy & paste can also be done with the shortcuts of the Edit menu (→ Edit menu).

    Creating a Renderer¶

    Use New Renderer in the context menu of an Object row or a Renderer group row to choose the Renderer type and target.

    • Choosing a preset creates a group of several predefined Renderers at once.
    • Creation is performed immediately with default values; fine adjustments are made afterwards in the inspector. To cancel, use Undo.

    Color panel¶

    Sets the Coloring of each Renderer. Choose a Renderer at the top (Renderers that can handle colors and their parent Objects are listed; when you select an Object or a Renderer in the scene tree, this list follows), then choose a Coloring type, and the settings for that type are shown below. The button for choosing the type shows the current type of that Renderer (Paint / Solid / CPK / B-factor / Rainbow / Potential / Multi-gradient).

    Type Settings
    Solid Specifies a single default color
    Paint Specifies pairs of a selection and a color in a table. Rows can be added, deleted, cleared and reordered, and Cut / Copy / Paste are available
    CPK Color for each element (C / N / O / S / P / H / others)
    Rainbow Mode, quantity to vary, start and end hue, brightness, saturation
    B-factor Mode (B-factor / occupancy / distance), lower and upper colors, lower and upper values (editable only when Auto is set to Manual)
    Electrostatic potential Target potential map, whether to color by SAS, low / middle / high values and colors
    Multi-gradient Edit the stops (color breakpoints) directly on the map histogram and the gradient bar

    The Paint table supports multiple selection. Cmd / Ctrl + click adds a row to or removes it from the selection, and Shift + click selects a range. Delete, Cut and Copy act on all selected rows. Reordering (Move up / Move down) is available when exactly one row is selected. Rows can also be reordered by dragging. Dropping a row below the last row moves it to the end. Rows can also be moved and selected with the same keys as the scene tree (Up / Down / Home / End and their combinations with Shift).

    The toolbar above the table has four buttons: add a row (Add), reorder (Move up / Move down), and delete (Delete). Delete all and Cut / Copy / Paste are in the right-click menu of a row. The selected rows can also be deleted with the Del / Backspace keys. The boundary between the Selection column and the Color column can be dragged to change the column width.

    Clicking a row only selects it. To edit a cell, start with any of double-clicking the cell, Enter, F2, or Edit selection... in the right-click menu, and confirm with Enter or cancel with Esc. For colors, click the color swatch to open the color picker. Because the displayed rows have no text input field, Cmd+C / Cmd+V / Cmd+Z act on rows, not on text.

    A Paint Cut can be undone in one step with a single Undo. Paste is unavailable when the clipboard is empty. Pasted rows keep the order in which they were copied.

    View¶

    Camera panel¶

    A list of cameras (saved named viewpoints). Click a row to select it, and use the toolbar or the right-click menu to operate on it. When there are no cameras, (no cameras) is shown.

    Screenshot planned

    The toolbar at the top of the panel has six buttons.

    Button Action
    New camera from view Creates a new camera from the current view. A dialog asks for the name
    Save from view Overwrites the selected camera with the current view
    Save from view with show/hide Same as above. The show / hide state is also saved
    Apply to view Restores the view of the selected camera
    Apply to view with show/hide Same as above. The saved show / hide state is also restored
    Delete Deletes the selected camera
    • Double-click: Applies the camera, including its show / hide state.
    • Renaming: Press F2 or choose Rename... from the right-click menu to edit in place.
    • Deleting: The Del / Backspace keys also delete it.
    • Reordering: Drag rows to change the order. Dropping a row below the last row of the list moves it to the end. The order is saved in the scene file (.qsc).
    • __current: A special camera that records the view at the time the scene was saved. It is pinned to the top of the list and cannot be moved by dragging.
    • Row badges: A camera that holds a show / hide state has an eye icon, and a camera loaded from a camera file has a link icon.

    In addition to the above, the right-click menu offers copy & paste, loading, reloading and saving camera files (.cam), and editing and clearing display flags (→ Camera). Right-clicking on an empty area opens a menu with only New, Paste and loading a camera file.

    Creating a camera with an existing name overwrites it

    Running New camera from view with the same name as an existing camera overwrites that camera without confirmation.

    View panel¶

    Controls the viewpoint numerically. It corresponds to the fake dial (View panel) of CueMol2.

    Section Contents
    Rotation Rotation about X / Y / Z. Dragging rotates relatively
    Translation Translation
    Zoom / Slab Zoom, slab (width of the visible depth), distance
    Projection Projection mode (Perspective / Orthographic) and the center mark

    Note

    Changes of the view are not subject to Undo. The background color is a scene setting, so set it from the Scene menu or the inspector, not from this panel.

    Selection¶

    Molecular structure panel¶

    Shows a molecule as a chain → residue → atom hierarchical tree and builds selections.

    • Choose the target molecule at the top.
    • The tree is loaded when a node is expanded.
    • Multiple selection is supported (Cmd / Ctrl + click, Shift + click).
    • With Select / Center / Zoom on the toolbar, the chosen range can be made the current selection / brought to the center / zoomed in on.

    Selection panel¶

    A dedicated panel for displaying and editing the selection of a molecule.

    • When you choose the target molecule in Molecule, the current selection of that molecule is shown in the Selection field as a selection expression. Operations in the panel are applied to the selection immediately and can be undone with Undo.
    • The selection builder (four tabs: Named / History / Term / Mod) lets you build a selection without writing an expression. You can apply a named selection or a history entry with one click, combine conditions (Set / Add / Sub / Intsec), and transform the current selection (Invert / Byres / Sidech / Mainch / Arnd / Expn). Each operation shows the number of atoms that would result if it were applied (→ Selection builder).
    • The Selection field can also be edited by hand. The expression is validated as you type, and a warning is shown if it is invalid. Apply a hand-typed expression with the Select button.
    • The history is saved in the application and shared with the selection fields of Renderers and elsewhere.

    Differences from CueMol2

    The hierarchical editor (Hierarchical / Terminal / Around-Expand) of the CueMol2 selection panel has been replaced by the selection builder.

    Crystal¶

    Symmetry panel¶

    Handles crystallographic symmetry.

    • When you choose the target Object (molecular coordinates / density map), the lattice type, space group and cell constants are shown.
    • Change... changes the crystal system and the space group. When "restriction by symmetry" is enabled, the input of cell constants is linked according to the constraints of the crystal system.
    • Symm mol displays symmetry mates. The range can be chosen from 20 / 50 / 100 / 200 Å or the unit cell.
    • Unit cell displays the frame of the unit cell.

    Density map panel¶

    Adjusts the display of density map Renderers (contour / isosurface, etc.).

    • Choose a Renderer and adjust the transparency / contour level / display extent with the sliders.
    • The level can be specified either in a unit that depends on the map type (σ for crystallographic maps, the top % of grid point values for cryo-EM maps) or as an absolute value (switch with the ▼ menu). The value in the other unit is shown below Level. A cryo-EM map is in absolute values from the moment it is loaded.
    • Redraw updates the center of the display to the current view center. Cell displays the unit cell.
    • When the whole map is displayed (the Region of the Renderer is Full map), the Extent slider and Redraw have no effect (→ contour).

    Actions¶

    Handles the recording of performed operations and their replay. For details, see Recording and replaying operations (Actions).

    History panel¶

    Shows the Undo history of the active scene, one step per row. A step that contains two or more operations can be expanded to list the operations performed. From the toolbar you can move to the state of the selected row (Go to step), copy it as commands (Copy as commands), save it to a qax file (Save as qax), or save it to the Actions panel (Save to Actions). Double-clicking a step shows its contents read-only in the inspector.

    Actions panel¶

    Lists the Presets bundled with the app and the User Actions you saved. Select one and press Run to apply it to the Object selected in the scene tree.
