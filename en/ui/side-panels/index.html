    サイドパネル¶

    ウィンドウ左側のサイドパネルは、左端のアクティビティバーで用途を切り替えます。 選択中のアイコンをもう一度クリックするとサイドパネルが閉じます。

    撮影予定

    アクティビティバーの構成¶

    アイコン ビュー 含まれるパネル
    Explorer シーンの構成と表示設定 Scene / Color / View
    Selection 分子の選択 Molecular structure / Selection
    Crystal 結晶学的な情報 Symmetry / Density map
    歯車 (最下部) Settings タブを開きます (サイドパネルではありません)

    Explorer¶

    Scene パネル (シーンツリー)¶

    シーンの内容をツリーで表示します。CueMol2 のワークスペースパネルに相当します。

    • ノードの種類: シーン / Object / Renderer / Renderer グループ / カメラ / スタイルセット
    • 表示の切り替え: 各行の目のアイコンで表示・非表示を切り替えます。 上位のノードが非表示のために描かれていない行は、アイコンがグレー表示になります。
    • 選択: クリックで選択、Cmd / Ctrl + クリックで複数選択できます。 Shift + クリックでは、直前に選んだ行から画面に並んでいる順で範囲を選択します (折りたたまれたノードの中身は含まれません)。起点は動かないので、Shift + クリックを 繰り返せば同じ起点から範囲を伸縮できます。Shift + Cmd / Ctrl + クリックでは、 今の選択を置き換えずに範囲を追加します。
    • キーボード: Up / Down で 1 行ずつ、Home / End で先頭・末尾に 移動します。Shift を併用すると選択範囲が伸び、Shift + Cmd / Ctrl では 今の選択に加える形で伸びます。Left / Right は行を折りたたむ / 展開し、 それ以上たためない・開けないときは親の行 / 最初の子の行に移ります。
    • 名前の変更: F2 か、右クリックメニューの Rename... でその場で名前を編集します。 Enter かフォーカスを外すと確定、Esc で取り消します。行のクリックは選択だけを行い、 名前の編集には入りません。
    • 並べ替え: ドラッグ & ドロップで順序やグループへの所属を変更できます。
    • ダブルクリック: カメラ行ではそのカメラをビューに適用します。その他の行では プロパティインスペクタ に内容を表示します。
    • 右クリック: ノードの種類ごとのメニューが開きます (下記)。

    パネル上部のツールバーには Add / Focus / Delete / Property のボタンがあります。 複数選択中は Focus と Property は使えません。Delete は選択しているノードすべてを 削除し、1 回の Undo でまとめて戻せます。Del / Backspace キーでも同じです。

    右クリックメニューの主な操作¶

    対象 主な操作
    シーン 背景色 (White / Black)、カラープルーフィングの切り替え、名前の変更、Object の貼り付け
    Object 選択範囲の指定、名前の変更、コピー & ペースト、Renderer / Renderer グループの新規作成、色の設定、Save As、分子表面の再生成
    Renderer 名前の変更、コピー & ペースト (同じ Object・同じグループの中に貼り付けます)、色の設定、スタイルの適用・作成・編集、選択範囲の変更、表面 Object の生成、Renderer 種類の変更、相互作用リストの編集
    Renderer グループ 表示・非表示 (メンバーに連動)、名前の変更、コピー & ペースト、Renderer の新規作成
    カメラ 新規作成 / 名前の変更 / 削除 / コピー & ペースト、カメラファイルの読み書き、ビューへの適用、表示フラグの編集
    スタイルセット 新規作成 / コピー & ペースト / 削除、読み取り専用の切り替え、ファイルの読み書き、スタイルエディタ

    複数のノードを選んでいるときは、表示・非表示・削除に加えてコピーが行えます。 Renderer グループを選ぶとメンバーの Renderer が対象になります。種類の異なるノードが 混ざっている場合と、Object を 2 つ以上選んでいる場合はコピーできません。

    コピー & ペーストは Edit メニューのショートカットからも行えます (→ Edit メニュー)。

    Renderer の新規作成¶

    Object 行や Renderer グループ行の右クリックメニューの New Renderer から、 Renderer の種類と対象を選んで作成します。

    • プリセットを選ぶと、あらかじめ定義された複数の Renderer をまとめたグループが一度に作られます。
    • 作成は既定値で即座に行われ、細かい設定は作成後にインスペクタで調整します。 取り消したいときは Undo で戻せます。

    Color パネル¶

    Renderer 単位の Coloring を設定します。上部で Renderer を選び (色を扱える Renderer と、 その親の Object が並びます。シーンツリーで Object や Renderer を選ぶと、ここも追従します)、 続いて Coloring の種類を選ぶと、その種類に応じた設定欄が下に表示されます。

    種類 設定内容
    Solid 既定色を 1 色指定します
    Paint 選択範囲と色の組を表で指定します。行の追加・削除・全削除・並べ替えと、Cut / Copy / Paste ができます
    CPK 元素ごとの色 (C / N / O / S / P / H / その他)
    Rainbow モード、変化させる基準、開始・終了の色相、明度、彩度
    B-factor モード (B-factor / 占有率 / 距離)、下限・上限の色、下限値・上限値 (Auto が Manual のときのみ入力可)
    静電ポテンシャル 対象のポテンシャルマップ、SAS で色付けするか、低 / 中 / 高の値と色
    Multi-gradient マップのヒストグラムとグラデーションバー上で、ストップ (色の区切り) を直接編集します

    Paint の表は複数選択できます。Cmd / Ctrl + クリックで行を選択に加える / 外す、 Shift + クリックで範囲を選びます。削除・Cut・Copy は選んだ行すべてに効きます。 並べ替え (Move up / Move down) は 1 行だけ選んでいるときに使えます。 行の移動と選択は、シーンツリーと同じキー (Up / Down / Home / End と Shift の併用) でも行えます。

    ツールバーにあるのは行の追加 (Add row)・削除 (Remove row)・並べ替え (Move up / Move down) の 4 つで、Delete all と Cut / Copy / Paste は行の右クリックメニューにあります。Selection 列と Color 列の境界は ドラッグして幅を変えられます。

    行のクリックは選択だけを行います。セルの編集は、そのセルのダブルクリック / Enter / F2 / 右クリックメニューの Edit selection... のいずれかで始め、Enter で確定、 Esc で取り消します。色は、色見本をクリックすると色の選択が開きます。 表示中の行にはテキスト入力欄が無いため、Cmd+C / Cmd+V / Cmd+Z は テキストではなく行に対して働きます。

    Paint の Cut は 1 回の Undo でまとめて戻せます。Paste はクリップボードが空のときは 選べません。貼り付けた行はコピーしたときの順序を保ちます。

    View パネル¶

    視点を数値で操作します。CueMol2 のフェイクダイヤル (View パネル) に相当します。

    セクション 内容
    Rotation X / Y / Z の回転。ドラッグで相対的に回します
    Translation 平行移動
    Zoom / Slab ズーム、スラブ (表示する奥行きの幅)、距離
    Projection 投影方式 (Perspective / Orthographic) と中心マーク

    Note

    視点の変更は Undo の対象外です。 背景色はシーンの設定なので、このパネルではなく Scene メニュー や インスペクタから設定します。

    Selection¶

    Molecular structure パネル¶

    分子をチェイン → 残基 → 原子の階層ツリーで表示し、選択を作ります。

    • 上部で対象の分子を選びます。
    • ツリーは展開したときに読み込まれます。
    • 複数選択に対応しています (Cmd / Ctrl + クリック、Shift + クリック)。
    • ツールバーの Select / Center / Zoom で、選んだ範囲を選択状態にする / 中心に持ってくる / 拡大表示する、といった操作ができます。

    Selection パネル¶

    分子の選択を表示・編集する専用パネルです。

    • Molecule で対象の分子を選ぶと、Selection 欄にその分子の現在の選択が 選択式として表示されます。パネルでの操作は選択に即座に反映され、Undo で戻せます。
    • 選択ビルダー (Named / History / Term / Mod の 4 タブ) で、式を書かずに選択を 組み立てられます。定義済み選択・履歴のワンクリック適用、条件の合成 (Set / Add / Sub / Intsec)、現在の選択の変換 (Invert / Byres / Sidech / Mainch / Arnd / Expn) ができ、各操作には適用した場合の原子数が表示されます (→ 選択ビルダー)。
    • Selection 欄は手でも編集できます。入力中に式の妥当性が検証され、誤りがあれば 警告表示になります。手入力した式は Select ボタンで適用します。
    • 履歴はアプリケーションに保存され、Renderer の選択欄などと共有されます。

    CueMol2 との違い

    CueMol2 の選択パネルにあった階層型エディタ (Hierarchical / Terminal / Around-Expand) は、 選択ビルダーに置き換わりました。

    Crystal¶

    Symmetry パネル¶

    結晶学的な対称性を扱います。

    • 対象の Object (分子座標 / 密度マップ) を選ぶと、格子の種類・空間群・格子定数が表示されます。
    • Change... で結晶系と空間群を変更できます。「対称性による制限」を有効にすると、 格子定数の入力が結晶系の制約に従って連動します。
    • Symm mol から対称分子を表示します。範囲は 20 / 50 / 100 / 200 Å または単位格子から選べます。
    • Unit cell で単位格子の枠を表示します。

    Density map パネル¶

    密度マップの Renderer (contour / isosurface など) の表示を調整します。

    • Renderer を選び、透明度 / 等高線レベル / 表示範囲をスライダで調整します。
    • レベルは、マップの種類に応じた単位 (結晶学的マップは σ、クライオ電子顕微鏡マップは 格子点の値の上位 %) と絶対値のどちらでも指定できます (▼ メニューで切り替え)。 もう一方の単位での値が Level の下に表示されます。 クライオ電子顕微鏡マップは、読み込んだ時点で絶対値になっています。
    • Redraw で表示の中心を現在のビュー中心に更新します。Cell で単位格子を表示します。
    • マップ全体を表示している場合 (Renderer の Region が Full map) は、 Extent スライダと Redraw は効きません (→ contour)。

    確認対象: CueMol3 2.3.14.525
