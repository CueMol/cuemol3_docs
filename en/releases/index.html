    更新履歴¶

    リリースごとの主な変更点です。お使いのバージョンは Help > About CueMol3 で確認できます。

    詳細は GitHub のリリースノートにあります

    このページは、ふだん使ううえで知っておくとよい点だけをまとめたものです。 修正の一件一件や内部の変更まで含む完全な記録は GitHub の Releases にあります。

    CueMol3 と CueMol2 は同じリリースで一緒に配布されるため、リリースノートには CueMol2 (UXP 版) の変更も含まれています。

    2.3.14.525 (2026-09-12)¶

    3D ビューの操作¶

    • 描かれた形状のとおりにクリックが当たるようになりました。 cartoon / ribbon / tube では 帯の中央をクリックしても当たらず、残基の CA の近くしか拾えていませんでした。矩形 / 投げ縄 選択と対称分子は、これまでどおり原子の位置で判定します → ピッキングとホバー表示
    • ポインタの下にあるものが分子ビューの左下に表示され、その場で強調されるようになりました。 チェインと残基 (原子単位の Renderer では原子名も)、それが属する Object と Renderer が 出ます。強調表示のためにシーンを描き直さないので、アンビエントオクルージョンや アンチエイリアシングの蓄積は巻き戻りません。Settings > Input > Mouse & Navigation の GPU Picking / Hover Info / Hover Highlight で切り替えられます → 設定項目

    描画 (レンダリング)¶

    • 半透明が重なった部分で、暗いものが明るく反転する不具合が修正されました。 半透明の 表面越しの黒いエッジ線が白く描かれていました。画素ごとに合成する Per-pixel transparency が既定になります。半透明が 1 枚しか掛かっていない画素は 従来と同じ絵で、変わるのは重なった部分だけです → レンダリング
    • ウィンドウを覆ったり最小化したりするとレンダリングが数倍遅くなる不具合が修正されました。 一度遅くなるとアプリケーションを再起動するまで戻りませんでした。レンダリング中は システムがスリープしないようにもなりました
    • レンダリングウィンドウが、レンダリングをまたいで表示倍率とスクロール位置を保つように なりました。 履歴を行き来しても保たれるので、2 つの結果を同じ倍率で見比べられます。 + / - / 100% / Fit は表示領域の中心を基準に拡大縮小します → レンダリングウィンドウ
    • 大域照明の光の配分の段を引き直しました。 段が動かすのは正面からの光と照り返しの配分 だけになり、キーライトの強さはどの段でも変わらなくなりました → レンダリング

    画面と操作¶

    • 分子表面で Solid coloring が効くようになりました。 色に $molcol を選んでも半透明の 灰色になり、dsurface / dsurf2 では Solid coloring を選んでも CPK のままでした → Coloring
    • リストの行をクリックしても、名前の変更やセルの編集に入らなくなりました。 シーンツリーでは選択済みの行をもう一度クリックすると名前の変更が始まってしまい、Paint の 表ではクリックするとテキスト入力欄にフォーカスが入るため Cmd+C / Cmd+V / Cmd+Z がそちらに吸われていました。編集は F2 ・ダブルクリック・右クリック メニューから始めます。シーンツリーの右クリックメニューに Rename... が加わりました → サイドパネル
    • Paint の行のコピー & ペーストが、選んだ行に効くようになりました。 複数行を選んでから 右クリックすると、選択が 1 行に戻ってしまっていました
    • 選択の Named の先頭に all (*) が並ぶようになりました。 一覧の高さは、Selection パネルではパネルの残りいっぱい、ポップオーバーでは開いた側の空きに合わせます → 選択ビルダー

    既存のシーンで見え方が変わることがあります

    • 以前のビルドで保存したシーンの GI lighting は Custom と表示されます。 段の値が 変わったため、保存されている値がどの段とも一致しません。段を選び直すと新しい値に なります
    • 半透明の合成が既定で画素ごとになります。 半透明が 1 枚しか掛かっていない画素は 同じ絵になり、2 枚以上重なった画素だけが変わります (それが修正の内容です)。 blendpng や POV-Ray と揃えたいときは Transparency を OFF にしてください

    2.3.13.523 (2026-09-06)¶

    描画 (レンダリング)¶

    • レンダリングウィンドウの設定がシーンに保存されるようになりました。 これまでは 設定がメモリ上にしかなく、すべてのシーンで共有され、ウィンドウを閉じると失われて いました。シーンファイルに書き込まれ、シーンごとに復元されます。設定の変更は Undo の 対象で、レンダリングウィンドウ内でも Cmd+Z が効きます。結果の履歴からは Use settings でそのときの設定に戻せます → レンダリング
    • 大域照明の光の配分が見直されました。 Global Illumination では開けた面が明るく平坦に なり、白いチューブの陰影が消えていました。Quality に GI lighting の 5 段階が加わり、 0 はレイトレースと同じ配光、4 (既定) は正面光をキーライトと照り返しに移した配光です。 すべての方式に効く Lights (Light intensity / Flash fraction) が加わり、GI intensity / GI environment はウィンドウから外れ、GI quality は GI samples (8 / 32 / 64 / 256) の 選択になりました → レンダリング
    • Renderer どうしが交わる線 (Contact edges) を、エッジ線の設定が異なる Renderer の間に 描くようになりました。 ribbon に刺さる ballstick の結合などの交線です。エッジ線の設定 (種類・太さ・色) が同じ Renderer はひとまとまりとして扱われ、その間には描かれません。 すべての Renderer が同じエッジ設定 (既定のままなど) のシーンでは、これまでどおり交線は 描かれません → レンダリング
    • Silhouette の輪郭が、フォグで薄れた面の奥でも描けるようになりました。 Umbreon が 分子ビューと同じ奥行きで描画を打ち切るようになり、輪郭を描き始める深さを Outline far depth で指定します。Crease angle は折れ線として描く角度の段階 (Off / 15〜120°) になり、POV-Ray 専用だった Edge rise は Umbreon の設定から外れました
    • Umbreon のエッジ線で、大きく拡大すると原子の内側に斑点状の線が描かれる不具合が 修正されました。 ballstick などの結合の端が原子の球とちょうど同じ面にあったため、 エッジ線の検出がそこを細かな段差と誤認していました
    • コマンドライン (cuetty --render) と Python モジュールが、シーンに保存された設定で 描画するようになりました。 設定のないシーンは既定値 (Global Illumination、1200×1200) で 描画されます。--width / --height は保存されたサイズを上書きします → レンダリング

    密度マップと分子表面¶

    • 等高線レベルの単位が、マップの種類に応じたものになりました。 結晶学的マップでは σ、 クライオ電子顕微鏡マップでは格子点の値の上位何 % かで、既定はそれぞれ 1.1σ と上位 1 % です。 Reset to default でクライオ電顕マップの既定に戻るようになり (従来は 1.1σ に戻って いました)、Density map パネルの Level はどちらの単位でも絶対値でも指定でき、 もう一方の値が下に表示されます。Map type を変えると Renderer のスタイル (Default / Cryo-EM) も入れ替わります → DensityMap
    • マップを開いても視点が原点に飛ばなくなりました。 モデルの上に 2Fo-Fc マップを開くと、 視点が原点に移動してマップも原点の周りにしか描かれませんでした。ファイルを開くダイアログに View after loading (Auto / Set map center / Move view center) が加わりました。BRIX / mmCIF / QDF / X-PLOR のマップに、分子と同じ原子選択の欄が出なくなりました → File メニュー
    • マップの種類がインスペクタに表示されます。 DensityMap の Properties タブに Density map セクション (Map type の変更と Effective kind)、マップの Renderer に Map kind が加わりました。等値面には Cap mode (Auto / On / Off) が付き、既定の色が 飽和した青から明るい灰色になりました → isosurf
    • dsurface / dsurf2 で Multi-gradient が使えるようになりました。 molsurf と同じく、 静電ポテンシャルによる着色、ストップの編集、シーンへの保存ができます → Coloring
    • APBS elepot calculation... の Charge method がドロップダウン (Method) になりました → 分子表面を静電ポテンシャルで着色する

    画面と操作¶

    • アニメーションの時刻を、タイムコードの桁ごとに編集できるようになりました (Blender / After Effects 風)。桁をクリックしてドラッグ、Up / Down、数字の打ち込み、Enter で 式の入力ができます。インスペクタの Start time / Duration はドラッグ中にストリップが追従し、 1 回の Undo で戻せます。Animation パネルの現在時刻も打ち込んで移動できます。開始時刻の 基準が循環したり、名前が重複・欠落したりする指定は理由を示して拒否され、解決できない要素は 斜線付きで表示されて直すまで再生できません → 時刻の入力
    • New Tab ダイアログで、新しいシーンの表示設定を決められるようになりました。 アンチエイリアシング / アンビエントオクルージョン / 背景色 / CMYK プルーフィングを指定でき、 確定した値が以後の新しいシーン (起動時やファイルのドロップで作られるものを含む) の既定に なります → File メニュー
    • 重ね合わせたあとに原子のクリックがずれる不具合が修正されました。 tube / ribbon / cartoon で、原子が移動前の位置で選ばれていました
    • Paint の着色が Renderer に効くようになりました。 Color パネルは Renderer を選んでいても Object に書き込んでいたため、ribbon / cartoon / tube では何も起きませんでした。対象は シーンツリーの選択に追従し、Paint の Default が二次構造ごとの標準の塗り分けになりました (従来 "Default" と表示されていたスタイルは Molecule color) → サイドパネル
    • Renderer グループの名前を変えるとアプリケーションが固まる不具合が修正されました。 Generic タブの Name の default チェックを入れると、グループが名無しになっていました。 Name と Selection (sel) は既定値に戻せなくなり、Generic タブは名前を変えても開いたままに なります → プロパティインスペクタ
    • 選択の履歴が、選択を適用するすべての操作から記録されるようになりました。 インスペクタの選択欄、New Renderer、シーンツリー / 配列パネル / 右クリックメニューの選択、 矩形 / 投げ縄選択、Molecular structure パネルが対象です。件数は 100 件 (従来 40 件) に なりました → 選択ビルダー
    • Windows / Linux で、シーンツリーや Paint の表に対する Ctrl+C / Ctrl+V などが 効くようになりました。 テキスト入力欄の外ではメニューのショートカットが働いていませんでした → キーボードショートカット
    • そのほか: ダークテーマの補助的な文字が暗すぎて、シーンツリーの開閉マークなどが無効に 見えていたのが直りました。atomintr のラベルのフォントは、インストールされているフォントから 選ぶ形になりました。Scene のインスペクタはすべてのセクションを同時に表示します。 Windows / Linux のアプリケーションアイコンが新しくなりました。

    配布物¶

    • パッケージが約 150 MB 小さくなりました。 同梱済みの npm パッケージが重複して入って いたこと、未使用の libpython、ネイティブバイナリのシンボルテーブルを取り除きました。 macOS では .app が 580 MB から 414 MB、DMG が 226 MB から 197 MB になりました
    • Electron 42.5.1 になりました

    既存のシーンで見え方が変わることがあります

    • 2.3.11.507 / 2.3.12.517 で保存したクライオ電子顕微鏡マップの等高線レベル。 レベルの数値が σ ではなく上位 % として読まれます。Density map パネルでレベルを 動かしていたシーンは見た目が変わるので、レベルを一度調整してください。動かして いなかったものは既定 (上位 1.1 %) になります。結晶学的マップは変わりません
    • エッジ線の設定が同じ Renderer はひとまとまりとして扱われます。 Edge type が Silhouette のとき、まとまりの外周だけが描かれるため、すべてのチェインが同じエッジ設定の シーンでは、チェインどうしが重なる部分の輪郭が描かれなくなります。エッジ設定が異なる Renderer の間には、交線 (Contact edges) が新たに描かれます

    2.3.12.517 (2026-08-31)¶

    ファイルを開く¶

    • 圧縮された .pdb.gz / .cif.gz が開けるようになりました。 拡張子の照合が 最後のドット以降しか見ていなかったため、対応する読み込み処理が見つからず開けません でした。同じ理由で、名前にドットを含むフォルダに Object を保存すると、 選んだ形式と違う形式で書き出されることがありました → File メニュー
    • 大きな GROMACS の .gro ファイルが読めるようになりました。 残基番号は 5 桁で 書かれるため 99999 の次が 0 に戻り、溶媒の最初の残基がタンパク質の残基 1 に 混ざって、読み込み自体が途中で止まっていました。
    • BRIX / DSN6 マップの等高線レベルが決まらない問題が修正されました。 統計値の 計算が誤っていたため σ が求まらず、レベルが決まりませんでした。DSN6 は値の範囲も 誤っていました。

    Renderer とプロパティ¶

    • New Renderer の一覧に disorder と atomintr が並ぶようになりました。 disorder は 作成した時点で、シーンにある主鎖 Renderer が Target に設定されるので、そのまま 描画されます → disorder
    • 数値をドラッグして端から端まで動かせるようになりました。 従来は変化の速さが 一定で、エッジ線の太さのように範囲の狭い設定は端まで動かすのに 400 ピクセル以上の ドラッグが必要でした。Shift で細かく、Esc でドラッグの取り消しができます → プロパティインスペクタ
    • ポリゴンの分割数 (Detail) が段階の選択になりました。 数値を打ち込む代わりに 2 の冪から選びます。
    • 分子表面や等高線の着色を元に戻せるようになりました。 dsurface / dsurf2 / contour を静電ポテンシャルや Multi-gradient に切り替えると、以後どの着色を選んでも 表示が変わらなくなっていました → Coloring
    • インスペクタから開いた選択ビルダーにも、原子数が表示されるようになりました → 選択ビルダー

    画面と操作¶

    • シーンツリーと Paint の表をキーボードで操作できるようになりました。 Up / Down / Home / End での移動と、Shift を併用した範囲選択、 シーンツリーでは Left / Right での開閉ができます → サイドパネル
    • Renderer を別の Renderer に貼り付けられるようになりました。 同じ Object の 同じグループの中に貼り付けられ、右クリックメニューに Paste Renderer が 加わりました → サイドパネル
    • ノードの名前を変更している途中の Backspace で、そのノードが削除される 不具合が修正されました。
    • New Renderer やファイルを開くダイアログで、シーンに定義した名前付きの選択が 効くようになりました。 これまでは選択が無視され、全原子を表示する Renderer が 作られていました → 選択式の文法
    • Scene メニューの Background に色見本が付き、Use color proofing にチェックが 付くようになりました → Scene メニュー

    安定性¶

    • 保存していないシーンを失う 2 つの経路を塞ぎました。 ウィンドウを閉じるときの 「Save changes?」の確認に 10 秒以上かかると強制的に閉じられていたこと、および CueMol3 を 2 つ起動すると、後から起動したほうが先に起動したほうの作業ファイルを 消していたことです。
    • File > Reload Scene がシーンを二重にしなくなりました。 読み込む前にシーンを 空にしていなかったため、すべての Object が 2 つずつになっていました。 開けなかったシーンファイルは、空のタブを残さずエラーを表示します → File メニュー
    • アプリケーションが異常終了する 2 つの不具合が修正されました。 プリセットの Renderer グループごとコピーした分子を新しいシーンに貼り付けたときと、 他の要素が時刻の基準にしているアニメーション要素を削除したときです。
    • 共通ライブラリの点検で 132 件の不具合が修正されました。 CueMol2 と共通の部分で、 原子名の照合 (name C1' が C1* と命名された原子にマッチするようになりました → 選択式の文法)、二次構造の判定、 PDB の MODEL の扱い、Undo / Redo、壊れたファイルの読み飛ばしなどが含まれます。

    2.3.11.507 (2026-08-27)¶

    密度マップ¶

    • クライオ電子顕微鏡のマップに対応しました。 ファイルのヘッダからマップの種類を 判別し、クライオ電顕マップではマップ全体を表示します。従来はビュー中心の周りの 立方体だけを表示していたため、箱の端を越えると反対側の密度が折り返して描かれていました。
    • 拡大すると表示が細かくなります。 全体を細かく描くと面の数が膨大になるため、 全体は粗く描き、拡大した部分だけを細かく描き直します (Level of detail / Refine on zoom)。等値面でも等高線メッシュでも働きます。
    • 大きなマップを開けるようになりました。 メモリの使い方を改めたことで、一辺 1300 格子 ほどのマップも読み込めます。CCP4/MRC を開くときは、ダイアログにマップの大きさと必要な メモリが表示され、大きすぎる場合は Subsample (格子の間引き) が提案されます。
    • 判別の結果と表示範囲は手で変えられます。 ファイルを開くときの Map type で 結晶学的マップかクライオ電顕マップかを指定でき、表示範囲は Renderer の Region で Box around center (中心の周りだけ) と Full map (全体) を選べます。
    • MRC の ORIGIN を読むようになりました。 原点が 0 でないマップが、そこに当てはめた モデルと正しく重なるようになりました。
    • クライオ電顕マップは、読み込んだ時点で見える状態になります。 等値レベルが自動で 決まり、マップ全体が画面に収まるように視点も合わせられます。
    • gpu_mapmesh が描画されるようになりました。 シェーダが動いていなかったため、 これまでは何も表示されていませんでした。ただし線の太さを変えられず contour より遅いため、Renderer の新規作成の 選択肢からは外れています → gpu_mapmesh

    既存のシーンで見え方が変わることがあります

    外部の CCP4/MRC ファイルを参照しているシーンで、そのマップがクライオ電顕マップと 判別された場合、中心の周りだけの表示から全体の表示に変わります。元に戻すには、 Renderer の Region を Box around center にするか、マップの Map type を Crystallographic にしてください (プロパティインスペクタの Generic タブから 変更できます)。

    ファイルを開く¶

    • 手元の mmCIF ファイルが開けるようになりました。 最近の PDB の mmCIF はヘッダが長く、 座標が数百 KB 先から始まるため、形式を判別できず開けないことがありました → File メニュー

    画面と操作¶

    • シーンツリーの複数選択が実際に働くようになりました。 Shift + クリックの範囲選択が これまで反応していませんでした。Delete ボタンは選んだノードすべてを削除するようになり、 Del / Backspace キーでも削除できます → サイドパネル
    • Paint の表も複数選択できるようになりました。 Cmd / Ctrl + クリックと Shift + クリックで選び、削除・Cut・Copy が選んだ行すべてに効きます。ツールバーは 行の追加・削除と並べ替えの 4 つになり、Delete all と Cut / Copy / Paste は 行の右クリックメニューに移りました → サイドパネル
    • ダイアログの中でコピー & ペーストができるようになりました (macOS)。 ダイアログを 開いている間はアプリケーションメニューが無効になっていたため、Get PDB... の入力欄 などに Cmd+V で貼り付けられませんでした。
    • アンビエントオクルージョンの Medium / High が軽くなりました。 視点を動かしている間は 半分の解像度で計算し、止めると元の解像度で描き直します。書き出す画像は常に元の解像度です → Scene
    • 待機カーソルがちらつかなくなりました。 すぐ終わる処理では出なくなりました。
    • 数値の設定がスライダーになりました。 レイトレーサのアンビエントオクルージョン (サンプル数・距離・強さ・直接光の割合)、分子表面 Renderer の Detail、 Tools > Mol surface generation... の Probe radius です。

    2.3.10.504 (2026-08-26)¶

    描画¶

    • インク画風のレンダリングを作り込めるようになりました。 Umbreon (NPR) バックエンドに Detail タブが加わり、ハッチングのレイヤ (線の角度・間隔・太さ、 点の大きさなど) と陰影の付き方を編集できます。Mark width が網点や点描の スタイルにも効くようになりました → NPR (インク画風レンダリング)

    分子表面¶

    • 新しい生成アルゴリズム (MeshMS) を選べるようになりました。 生成・再生成の ダイアログの Algorithm で切り替えます。既定の Auto のままで構いません → MolSurfObj (分子表面)
    • 密度だけを変える再生成が速くなりました。 密度に依存しない計算が再利用されます。

    編集・コピー¶

    • CueMol2 との間でコピー & ペーストができるようになりました。 OS のクリップボードを 経由するようになったためです。Renderer・Object・カメラ・スタイル・Paint の行を、 一方のアプリでコピーしてもう一方に貼り付けられます → Edit メニュー
    • Cmd+C / Cmd+X / Cmd+V がフォーカスに応じて働くようになりました。 テキスト入力欄ではテキスト、シーンツリーではノード、Paint の表では行に作用します。 シーンツリーの Cut は新しく追加されたものです。
    • Cmd+Z がテキスト入力中にシーンを巻き戻さなくなりました。
    • Edit > Clear undo data が動作するようになりました。

    画面と操作¶

    • シーンツリーで Shift + クリックの範囲選択ができるようになりました。 複数選択したままコピーも行えます → サイドパネル
    • Paint の表に Delete all と Cut / Copy / Paste が加わりました。
    • プロパティインスペクタの Generic タブで、色・ベクトル・時刻の値を編集できる ようになりました → プロパティインスペクタ
    • ウィンドウのタイトルに、開いているシーンとビューの名前が出るようになりました。
    • 動作しなかったツールバーの Save ボタンと、Tools > Performance measure は 取り除かれました。

    分子ツール¶

    • Create SYMM mol を 3D ビューから使えるようになりました。対称分子の原子を 右クリックすると、その対称コピーを新しい分子として取り出せます → 対称分子・単位格子を表示する
    • Mol morphing animation のダイアログが使えるようになりました。対象を MorphMol に 変換してから、PDB ファイルやシーン中の分子をフレームとして追加します → アニメーションを作って動画に出力する

    配布物¶

    • ファイル名から対象の OS と役割が分かるようになりました (例: CueMol3-2.3.10.504-macOS-arm64-Installer.dmg) → インストール
    • Windows と Linux でもファイルの関連付けが登録されるようになりました。 エクスプローラーの「プログラムから開く」やファイルマネージャの "Open With" に CueMol3 が並びます → ファイルの関連付け

    Windows / Linux の x86-64 版は AVX2 対応の CPU が必要になりました

    Intel Haswell / AMD Zen 以降 (おおむね 2013 年以降) の CPU が必要です。 これより古い CPU では、分子表面を生成したときに異常終了します。 macOS (Apple Silicon) は影響を受けません。
