    開発状況と未実装機能¶

    このページは CueMol3 2.3.14.525 時点のスナップショットです

    CueMol3 は開発が進行中です。ここに書かれている制限や不具合が、 お使いのバージョンではすでに解消されている場合があります。

    CueMol3 の配布物は GitHub の Releases からダウンロードできますが、開発途上のバージョンです。 安定した動作が必要な場合は CueMol2 をご利用ください (→ インストール)。

    一部のみ実装されている機能¶

    機能 現状
    Renderer 種類ごとの詳細設定 プロパティインスペクタの Properties タブには共通設定 (Common) のセクションと、Renderer 種類ごとの専用セクションがあります。そこに現れない入れ子のプロパティ (cartoon の断面形状など) は Generic タブから編集してください
    コード署名 macOS はアドホック署名のみ (Developer ID 署名・notarization なし)、Windows は未署名です。いずれも初回起動時に手動での回避操作が必要です → インストール

    既知の問題¶

    症状 内容
    Sequence パネルの選択反映が遅い 配列パネルで選択を変えてから分子ビューのハイライトが更新されるまで、体感で 0.5 秒ほどの遅れが出ることがあります
    Molecular structure パネルの初回展開が重い ツリーを最初に展開したときに引っかかりを感じることがあります (残基数が多くなくても発生します)
    ポインティングデバイスの自動判別の誤り スクロールの特徴からの推定のため、マウスとトラックパッドを取り違える場合があります。Settings で明示的に指定してください
    密度マップの Renderer 行を Focus すると原点に飛ぶ シーンツリーで密度マップの Renderer (contour / isosurf) の行を選んで Focus を押すと、視点がマップではなく原点に移動します。マップの Object 行を Focus してください

    動作を確認できている主な機能¶

    CueMol2 (UXP 版) の GUI から移植対象としていた機能は、2.3.10.504 ですべて移植済み、 または移植しない判断が確定しました (移植しなかったものは → 機能の統合・改名・廃止)。参考として、実装が完了している主な範囲を挙げます。

    • ファイル / シーンの読み書き、Get PDB によるネットワーク取得、最近使ったファイル、 OS からのドラッグ & ドロップとファイルの関連付け
    • シーンツリー (表示切り替え / 名前変更 / 並べ替え / 複数選択 / 範囲選択 / 右クリックメニュー)
    • OS のクリップボードを介したコピー & ペースト (CueMol2 との間でもやりとりできます)
    • Renderer の作成 (プリセットを含む) と、インスペクタでの設定編集
    • Coloring (Solid / Paint / CPK / Rainbow / B-factor / 静電ポテンシャル / Multi-gradient)
    • 選択 (選択式・分子構造ツリー・配列パネル・矩形 / 投げ縄ツール)
    • 計測 (距離 / 角度 / 二面角) と結合の追加・削除
    • 分子表面の生成・切断・再生成 (MeshMS / BALL の 2 つのアルゴリズム)、相互作用解析、 二次構造の再割り当て、分子の重ね合わせ
    • 対称性の変更と対称分子・単位格子の表示 (Create SYMM mol を含む)、密度マップの表示調整
    • APBS による静電ポテンシャル計算 (外部ツールの設定が必要)
    • アニメーションのタイムライン編集と再生、モーフィングアニメーションの作成
    • レンダリングウィンドウでの静止画・動画出力 (既定は内蔵レイトレーサ Umbreon。 インク画風の NPR 出力も選べます)
    • Export scene (PNG / Umbreon / POV-Ray SDL / STL / MQO)

    不具合の報告¶

    問題を見つけた場合は GitHub リポジトリ の Issue でご報告ください。
