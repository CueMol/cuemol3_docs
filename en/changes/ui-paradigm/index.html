    操作パラダイムの変更¶

    CueMol3 で最も大きく変わったのは、設定をどこで指定するかという点です。

    CueMol2 の方式とその問題¶

    CueMol2 の GUI は、ほぼすべての機能が同じ形をしていました。

    メニューやボタンを押す → モーダルダイアログが開く → 全項目を入力する → OK で実行

    この形をそのまま持ち込むと、次の不便が残ります。

    • 結果を見ながら調整できない。ダイアログが分子ビューを隠し、操作もブロックします。
    • 同じ設定が 2 か所に現れる。Object を作るときのダイアログの項目と、 作った後のプロパティの項目が重複します。
    • 後から直すのに、もう一度同じダイアログを開き直す必要があります。

    CueMol3 の方針¶

    CueMol3 では、「すべてモーダルダイアログ」をやめ、操作の性質に応じて置き場所を変える方針にしました。

    操作の性質 CueMol3 での形 例
    永続する対象の設定を編集する 常設のプロパティインスペクタ Renderer / Object / シーンの設定
    選択肢が 1〜3 個の軽い指定 ポップオーバー (その場に開く小さなパネル) 計測ツールのラベルセット選択、結合の一覧と削除
    分子ビュー上での操作を伴う ツールモード + 補助パネル 距離・角度・二面角の計測、結合の追加
    項目が多い一度きりの処理 専用のウィンドウ / パネル レンダリングウィンドウ
    開く・保存する流れの途中の指定 モーダルダイアログ (従来どおり) ファイルを開くときの形式オプション、シーン保存時のオプション
    一度きりの確認・破壊的操作 モーダルダイアログ (従来どおり) 未保存シーンを閉じるときの確認、原子の削除

    モーダルダイアログが全廃されたわけではありません。流れを止めることに意味がある場面では 今でもモーダルを使います。

    「既定値で即作成し、Undo を安全網にする」¶

    CueMol3 の中心的な原則です。

    CueMol2 では、Renderer を 1 つ作るのにもダイアログですべての項目を決めてからでないと作れませんでした。 CueMol3 では次のようにします。

    1. 作るのに最低限必要なことだけを軽い UI で尋ねます (Renderer の種類、対象の Object など)。
    2. あとは既定値で即座に作成します。
    3. 細かい調整は、作成後にインスペクタで結果を見ながら行います。
    4. 気に入らなければ Undo (Cmd+Z / Ctrl+Z) で丸ごと取り消せます。

    「間違えたら Undo で戻せる」ことが前提にあるので、作る前にすべてを決めておく必要がありません。

    プロパティインスペクタが唯一の設定場所¶

    永続する対象 (Renderer・Object・シーン) の設定は、プロパティインスペクタが唯一の場所です。 作成用のダイアログに同じ項目を並べることはしません。

    • 変更は即座に分子ビューへ反映されます (OK / Apply ボタンはありません)。
    • 取り消したいときは Undo です (Cancel ボタンはありません)。
    • シーンツリーで別の要素を選べば、インスペクタの表示もそちらに切り替わります。

    → プロパティインスペクタ

    一度きりの処理は設定を覚えます¶

    書き出しやレンダリングのように「一度きりだが項目が多い」処理では、最後に使った設定を記憶し、 次回に初期値として使います。動画出力の出力先やフレームレートなどがこれにあたります。

    まとめ: CueMol2 の操作をどこで行うか¶

    CueMol2 での操作 CueMol3 での操作
    Renderer のプロパティダイアログを開く シーンツリーで Renderer を選ぶ → 右のインスペクタ
    ダイアログで設定して OK インスペクタで値を変える (即反映)
    ダイアログで Cancel Cmd+Z / Ctrl+Z で Undo
    Mol bond editor ダイアログ ツールパレットの Add Bond ツール
    Options プリファレンスウィンドウ Settings タブ
    POV-Ray rendering ダイアログ レンダリングウィンドウ (静止画モード)
    Animation rendering ダイアログ レンダリングウィンドウ (動画モード)
